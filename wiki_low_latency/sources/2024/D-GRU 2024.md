## 1. 他们为什么这么做？（motivation）

### 1.1 任务与对象

单通道语音增强，面向「算力与内存都受限的嵌入式平台」。论文的部署动机分两层（p.1 §1）：

- **内存侧**：U-Net 系架构（[2]–[7]）之所以在抑噪同时保住质量与可懂度，主要靠 encoder-decoder 之间的 **skip connections**；但这些连接要求把中间特征图**存下来**，「requiring memory that is not easily available on mobile platforms」。
- **算力侧**：RNN 类架构（FullSubNet [8, 9]、TaErLite [10]、dual-path [11, 12] / multi-path [13]）已能用更少硬件资源达到与 U-Net 相当的增强性能，band splitting [14, 15] 与 frame skipping [16] 又进一步压低了成本。

于是本文要动的是**第三笔账**：这些 RNN 模型在**推理期**仍然是「每一步把全部神经元都更新一遍」。论文的判断是：既然自然输入高度时间自相关、隐状态**变化缓慢**（引 [18]），那每一步就没必要更新全部神经元。

输入表示沿用三个既有骨干各自的口径（见 §4.1），不是本文重新设计的。论文明确说明这是在一个**回归任务**（语音增强）上验证 DG-RNN，而不是分类任务——这一点在 §6 里被用来与 Skip RNN 系列划界。

### 1.2 论文动机

论文的出发点是**一个被忽略的算力冗余**：

> 隐状态的**慢变**特性意味着，相邻两步之间只有一部分神经元的分量发生了有意义的变化。全量更新等于把「没变的那部分」重算了一遍。

- 已有降低 RNN 成本的手段（更小的网络、剪枝、量化、蒸馏）都是**训练期定型**的，推理期算力是常数，不随输入内容变化。
- 而「动态计算」这条线上的既有方法（Delta RNN、Phased LSTM、Skip RNN）要么是**输入驱动**的、要么**每步更新的神经元数不固定**、要么**整步跳过全部神经元**——三者在**硬件实时约束**下都有各自的致命问题（详见 §2 与 §6）。

论文给出的答案是：把「这一步更新哪些神经元」变成一个**由 RNN 自己免费算出来的、每步数量固定**的决策。这就是 **DG-RNN** 框架，以及它最漂亮的实现 **D-GRU**。

> [!note] 本篇的"省算力"是**推理期**的，不是训练期的
> 这一句看似废话，但它决定了本篇该和谁比。它与剪枝/量化/蒸馏**正交**（那三者改的是权重或位宽，本篇改的是「这一步算不算」），却与 Skip-DPCRN 那类「推理期状态跳过」**正面竞争**——两者的差别只在"跳的粒度"（见 §2.2）。

## 2. 之前的人怎么做不了？（limitation → gap）

| 路线 | 做法 | 为什么在本篇的判据下不够 |
|---|---|---|
| U-Net 系 [2]–[7] | CNN encoder-decoder + 时序建模层 + skip connections | skip connections 要缓存中间特征图 → 移动端内存吃紧（p.1 §1） |
| FullSubNet [8, 9] / TaErLite [10] | 用 RNN 替代 U-Net，硬件资源更省 | 性能相当，但推理期仍是**每步全量更新** |
| dual-path [11, 12] / multi-path [13] | 用小 RNN 在多个维度上复用，显著降参数量 | 降的是**参数量**，不是每步的更新量 |
| band splitting [14, 15] / frame skipping [16] | 分带、跳帧，进一步降算力 | 训练期定型或整帧级，不提供"每步固定比例"的神经元级稀疏 |
| Delta RNNs [18, 26, 27] | 只在输入变化超过阈值时更新神经元（**输入驱动**） | 论文把它定位为「另一条正交的路」而非竞品，并提议未来与 DG-RNN 统一到一个框架（p.4 §6） |
| Phased LSTM [28] | 只在振荡周期的特定相位更新，**每步更新数不固定** | 每步算力动态变化（p.4 §6） |
| Skip RNN [29, 30, 31] | **整步跳过全部神经元**的更新，**算力随步变化**；且主要在**分类任务**上验证 | 每步算力动态变化；回归任务（如语音增强）上的表现尚待研究（p.4 §6） |
| 本篇 gap | —— | **能不能让每一步的更新量都固定成一个可预设的比例 $P$，从而既省算力又让每步算力恒定可预测？** |

论文对阈值型 select gate（Eq. 8）的自我否定是理解这个 gap 的关键，原文（p.2 §3.2）：

> "However, this approach results in varying numbers of neurons that require updating in each step, leading to dynamically changing computation loads per step. For practical implementations, the hardware still needs to be capable of doing all the compute for updating of all neurons in order to satisfy the real-time processing constraint."

也就是说：**只要每步的更新量不固定，硬件就必须按"全部神经元都更新"的最坏情况预留能力，省下来的算力在 deadline 上兑现不了。** 这句话直接点出了 Skip-DPCRN 那类"平均省 33%、峰值只降 15%"方法的痛点（对照见 [[wiki_low_latency/sources/2022/Skip-DPCRN 2022]] §4.3 与 [[wiki_low_latency/concepts/2207.11108-inference-skipping-parallel-rnn]]）。

### 2.1 严格因果与延迟账本

| 状态语义 | D-GRU 的跳步是**神经元级**：$h_t$ 在每个时间步都存在并向后传递，只有部分分量保持 $h_{t-1}$（Eq. 9） | 时间步链**不断裂** → 不产生 Skip-RNN 那种"输出冻结"；但**长流状态漂移未报告**（见 §2.2） |

**判定结论**：D-GRU 记为本库的 **`paper-claimed-causal`**——理由是论文只有一句 "three strong causal speech enhancement models" 的**集合声明**，既没有逐层 padding/state certificate，也没有 STFT 帧锚定说明。它**不能**标 `strict_causal`。

> [!warning] 本篇的延迟账本是**空的**——这一点必须与结论一起读
> 本库其他论文至少会给出一个（哪怕未拆分的）延迟数字：[[wiki_low_latency/sources/2022/Skip-DPCRN 2022]] 给了 48 ms total latency、[[wiki_low_latency/sources/2026/LaCo-SENet 2026]] 给了逐层可复算的 Eq. (3)、[[wiki_low_latency/sources/2026/RT-Tango 2026]] 给了 8 ms。
> **D-GRU 一个都没有。** 它只报 MACs（M/s），而 MACs 是**吞吐/能耗**指标，不是延迟指标。所以：
> - 无法回答"它满足约 2 ms 硬约束吗"——**论文没有提供任何可用于回答这个问题的数据**；
> - 10 ms hop 本身已经意味着每 10 ms 才能更新一次输出（若前端按常规因果流式实现），这是本库关注的量级信息，但论文**没有把 hop 与延迟联系起来**；
> - 「每步算力恒定」这条设计性质，在缺少 p99/wall-clock 的情况下仍然只是**MAC 计数层面的论证**（见 §5 第 3 条）。

### 2.2 关键分析：D-GRU 的"跳步"是神经元级的，不是时间步级的

这是本篇最容易被误读、也是它区别于 Skip-DPCRN 的**本质**。两条路线都叫"跳过更新"，但跳的对象完全不同：

~~~text
Skip-RNN（引文 [29][30][31]）：跳「整个时间步」
  门是标量：g_t ∈ {0, 1}          ← 整层共用一个门
  s_t = g_t · s̃_t + (1 − g_t) · s_{t−1}
  g_t = 0 时 → 该层输出完全等于上一步 → 串行宿主里 mask 停更 → 音频伪影（引文 [20] TinyLSTM 的失败）

D-GRU（本篇）：跳「部分神经元」，时间步照常推进
  门是长度 J 的向量：g_t ∈ {0,1}^J   ← 每步恰好 A = (P/100)·J 个 1
  h^j_t = z^j_t·c^j_t + (1−z^j_t)·h^j_{t−1}   if g^j_t = 1
  h^j_t = h^j_{t−1}                            if g^j_t = 0
  → h_t 仍然存在、仍然完整地传给 t+1；只是它的部分分量等于上一步的对应分量
~~~

由此推出三条对本库有用的结论：

1. **不需要并行 RNN 宿主。** [[wiki_low_latency/sources/2022/Skip-DPCRN 2022]] 的核心洞察是「Skip-RNN 需要 parallel RNN 宿主才不出伪影」（其页面 §4.6 的 [!note] 把这条写成引用时的必备前提）。D-GRU **没有这个前提**：Table 1 里那个 GRU 骨干就是 **FC → 2 层 GRU → FC 的纯串行结构**，D-GRU 直接作用其上，P=50% 时 PESQ 与基线完全持平（2.58 vs 2.58）。这是两条路线最硬的结构性差异。
2. **不存在"输出冻结"。** 每一步都有 $A$ 个神经元被刷新，输出掩蔽持续变化，因此不会出现 Skip-RNN 在串行宿主上的台阶/断裂伪影。
3. **但漂移风险换了形式，而且论文没测。** Skip-RNN 的漂移是"整层停更 N 步"；D-GRU 的漂移是"**某些分量长期陈旧**"——如果某个神经元的 $z^j_t$ 长期偏低，它就可能长期进不了 top-A，其分量永久停留在旧值。论文自己在解释 P=25% 的退化时点出了这个机制（p.3 §5）：

> "infrequent updates of some neurons might result in inaccurate representations of the current state, introducing internal noise and worsening the speech enhancement."

这句话等于承认了**状态表征会因长期不更新而失真**，但论文**没有报告任何长流实验**（无 state reset、无 warm-up、无长流漂移曲线）。对约 2 ms 级的实时长流场景，这是一个**已知风险、未知量级**的缺口。

> [!question] 神经元级稀疏对"状态传递"的影响：论文只给了一句定性解释
> 严格说，D-GRU **不改变状态的传递结构**（$h_t \to h_{t+1}$ 的连接一直在），它改变的是**状态的刷新率**。因此本库的判定是：**因果性不受影响**（不引入未来依赖），但**状态语义受影响**（部分分量可能是若干步前的值）。
> 论文对这一点的处理只有上面那句 "introducing internal noise"，**没有量化**：没给"神经元被选中的间隔分布"、没给"长期未更新神经元的占比"、也没给长流下的性能衰减曲线。这三项都是可以直接补的实验。

## 3. 这个做法核心 trick 是什么？

### 3.1 一个 idea，两个设计选择

核心 idea **只有一个**：把"这一步更新哪些神经元"变成一个由 RNN 自己算出来、且**数量固定**的决策。围绕它有两个设计选择，缺一不可：

~~~text
                 DG-RNN 框架：h^j_t = F^j(x_t, h_{t−1}) if g^j_t = 1 else h^j_{t−1}
                            │
                  select gate  g_t = B(G(x_t, h_{t−1}))   ← 通用形式，G 可以是任意网络
                            │
        ┌───────────────────┴────────────────────┐
        ▼                                        ▼
  选择 ①  用 z_t 当重要性分数               选择 ②  固定 A，不用阈值
  （D-GRU：G 退化为"取 z_t"，零额外参数）    （每步算力恒定，硬件可预测）
        │                                        │
        └───────────────────┬────────────────────┘
                            ▼
        成本 = 常规 GRU 的 (1 + 2P/100)/3，参数增量 = 0
~~~

![[wiki_low_latency/assets/2408.12425/2408.12425-page2-dgrnn-update-process.png]]

> 图注：原论文第 2 页页面渲染，用于核对 **Figure 1** 与 Eq. (1)–(11)。**(A) Conventional RNN**：$h_{t-1}$ 与 $x_t$ 全连接，隐藏状态中**所有神经元**每步都被更新。**(B) Dynamic Gated RNN (DG-RNN)**：先由 `Select Gate Calculation` 用 $\{h_{t-1}, x_t\}$ 算出二值 select gate $g_t$（图中顶部 `0 0 1` 三个格子，1 表示该神经元本步要更新）；标 1 的神经元走正常 RNN 更新（图中橙色、蓝色实心圆），标 0 的神经元**直接保留 $h_{t-1}$ 的值**（图中灰色/虚线圆）。注意 (A) 与 (B) 的箭头拓扑相同——**变的只是"要不要算"，不是"连到谁"**。同页下半部分含 Eq. (1)–(11) 全文，本页公式均以此渲染图为准。图片为 PDF 页面复制，不是 AI 重画。

### 3.2 Trick ①：select gate 与 DG-RNN 隐状态（Eq. 1–2）

通用形式下，select gate 由当前输入与上一步隐状态经一个网络算出，再二值化：

$$
g_t = \mathcal{B}\big(\mathcal{G}(x_t,\ h_{t-1})\big), \tag{1}
$$

符号解释：

- $\mathcal{G}(\cdot)$：计算 select gate 的神经网络（D-GRU 里它退化成"直接取 $z_t$"，见 §3.4）；
- $\mathcal{B}(\cdot)$：二值化算子；
- $g_t$：长度 $J$ 的二值向量，$J$ 是神经元总数。

DG-RNN 的隐状态按逐神经元的方式更新：

$$
h^j_t =
\begin{cases}
F^j(x_t,\ h_{t-1}), & \text{if } g^j_t = 1,\\
h^j_{t-1}, & \text{if } g^j_t = 0.
\end{cases} \tag{2}
$$

- $h^j_t$：第 $j$ 个神经元在 $t$ 步的状态；
- $F^j(\cdot)$：该神经元的更新函数（在 D-GRU 里就是 GRU 的更新式）。

论文另定义**神经元更新百分比**：

$$
P_t = \frac{\sum_{j=1}^{J} g^j_t}{J}\times 100,
$$

并明确点出：**$P$ 是决定省多少算力的最重要参数**——「Note that $P$ is the most important parameter in determining cost savings; reducing $P$ as much as possible without compromising accuracy will lead to lower costs.」（p.2 §2）

论文同时给 select gate 加了一条**轻量化约束**：「the select gate generation process should be lightweight to not negate the advantages of sparse update.」——这正是 D-GRU 能做到零额外参数的动机来源。

### 3.3 Trick ②（铺垫）：常规 GRU 的四条更新式（Eq. 3–6）

$$
r_t = \sigma\big(W_{ir}x_t + b_{ir} + W_{hr}h_{t-1} + b_{hr}\big), \tag{3}
$$

$$
z_t = \sigma\big(W_{iz}x_t + b_{iz} + W_{hz}h_{t-1} + b_{hz}\big), \tag{4}
$$

$$
c_t = \tanh\big(W_{ic}x_t + b_{ic} + r_t * (W_{hc}h_{t-1} + b_{hc})\big), \tag{5}
$$

$$
h_t = z_t * c_t + (1 - z_t) * h_{t-1}. \tag{6}
$$

- $r_t, z_t, c_t$：reset gate、update gate、candidate hidden state；
- $\sigma$：Sigmoid；$*$：Hadamard 积（逐元素乘）；
- 下标 $ir/iz/ic$ 表示"input → gate"的权重矩阵，$hr/hz/hc$ 表示"hidden → gate"的权重矩阵。

**Eq. (6) 是整个方法的关键伏笔。** 它说明 $h_t$ 是 $h_{t-1}$ 与候选态 $c_t$ 的**加权平均**，权重由 $z_t$ 逐元素决定：

- $z^j_t \to 1$ ⇒ $h^j_t$ 主要被 $c^j_t$ **替换**（该神经元本步变化大）；
- $z^j_t \to 0$ ⇒ $h^j_t \approx h^j_{t-1}$（该神经元本步几乎不变）。

所以 **$z^j_t$ 本身就是模型学出来的"这个神经元本步该变多少"的信号**。这就是 Trick ③ 的立足点。

### 3.4 Trick ③（本文最漂亮的一点）：用 $z_t$ 直接导出 select gate，零额外参数

D-GRU 只更新 $z_t$ 中**最大的前 $A$ 个**神经元：

$$
g^j_t =
\begin{cases}
1 & \text{if } z^j_t \text{ is among the top-}A\text{ largest elements of } z_t,\\
0 & \text{otherwise},
\end{cases} \tag{7}
$$

$$
A = \frac{P}{100} \times J,
$$

- $A$：需要更新的神经元个数；
- $P$：**预设的、跨步恒定的**更新百分比（不是每步重算的 $P_t$）。

**为什么这是"零额外参数"的：** select gate 不再需要 Eq. (1) 里那个独立的 $\mathcal{G}(\cdot)$，而是**直接复用 GRU 本来就要计算的 $z_t$**（Eq. 4）。$z_t$ 的计算无论如何省不掉（它既要用于 Eq. 6，又要用于 top-A 选择），所以 select gate **没有引入任何新权重**。论文把这个性质写在贡献列表里：「the D-GRU utilizes the update gate of conventional GRU to derive the select gate, **without the introduction of additional parameters**.」（p.1 §1）

**为什么 top-A 而不是阈值（Eq. 8）：** 论文明确给出了被否掉的替代方案：

$$
g^j_t =
\begin{cases}
1 & \text{if } z^j_t > \theta^j,\\
0 & \text{if } z^j_t \le \theta^j.
\end{cases} \tag{8}
$$

否掉它的理由（p.2 §3.2，原文已引于 §2）是**算力恒定性**：阈值法的更新数随步变化，硬件仍须按最坏情况预留全部算力。论文同时声明「The performance of the threshold based select gate will be discussed in future work.」——**即 Eq. (8) 从未被评估过**，这是一个明确的、可补的消融（见 §4.5）。

> [!note] top-A 是**全局**选择，不是分层/分组选择
> Eq. (7) 说 "among the top-$A$ largest elements of $z_t$"——$z_t$ 是**该层全部 $J$ 个神经元**的向量，所以 top-A 在整个隐向量上取，**不保证每个子空间/每个特征通道都被覆盖**。
> 这带来一个论文没有讨论的推论：**更新预算会在层内自由流动**——某些步可能整组地集中在少数几个通道上。它既是灵活性（模型自己决定把算力花在哪），也是风险（连续多步被"冷落"的通道会积压陈旧值）。

### 3.5 Trick ④：被跳过的神经元连 $r$、$c$ 都不算（Eq. 9–11）

结合 Eq. (2) 与 Eq. (6)，D-GRU 中单个神经元的隐状态更新为：

$$
h^j_t =
\begin{cases}
z^j_t * c^j_t + (1 - z^j_t) * h^j_{t-1} & \text{if } g^j_t = 1,\\
h^j_{t-1} & \text{if } g^j_t = 0.
\end{cases} \tag{9}
$$

而 $g^j_t = 0$ 时，$r^j_t$ 与 $c^j_t$ 的计算**被完全跳过**：

$$
r^j_t =
\begin{cases}
\sigma\big(w^j_{ir}x_t + b^j_{ir} + w^j_{hr}h_{t-1} + b^j_{hr}\big) & \text{if } g^j_t = 1,\\
\text{(skipped)} & \text{if } g^j_t = 0,
\end{cases} \tag{10}
$$

$$
c^j_t =
\begin{cases}
\tanh\Big(w^j_{ic}x_t + b^j_{ic} + r^j_t * \big(w^j_{hc}h_{t-1} + b^j_{hc}\big)\Big) & \text{if } g^j_t = 1,\\
\text{(skipped)} & \text{if } g^j_t = 0.
\end{cases} \tag{11}
$$

注意 Eq. (10)(11) 里 $h_{t-1}$ 仍是**完整的**上一步隐状态（全部 $J$ 个分量都作为矩阵乘的输入），被裁剪的是**输出行数**（只算 $A$ 行而不是 $J$ 行）。这就是"$P\%$ 的计算量"的确切含义。

### 3.6 成本公式：$(1+2P/100)/3$ 的完整推导

论文的推导只有一句（p.3 §3.3）：

> "Following Eqs. (10, 11), we require $P$ percent of the original computation costs associated with the reset gates and candidate hidden states. Since the computation for the update gate $z$ cannot be saved, the total computation of the D-GRU is $(1 + 2P/100)/3$ of that in the conventional GRU."

本页把它的记账逻辑展开（这是理解全部数字的钥匙）：

| 分量 | 常规 GRU 的成本 | D-GRU 的成本 | 能否省 |
|---|---:|---:|---|
| reset gate $r_t$（Eq. 3） | 1 单位 | $P/100$ 单位 | 能省（Eq. 10） |
| update gate $z_t$（Eq. 4） | 1 单位 | **1 单位** | **不能省**——top-A 选择需要完整的 $z_t$ |
| candidate $c_t$（Eq. 5） | 1 单位 | $P/100$ 单位 | 能省（Eq. 11） |
| **合计** | **3 单位** | $1 + 2P/100$ 单位 | —— |

$$
\boxed{\ \frac{\text{cost(D-GRU)}}{\text{cost(GRU)}} = \frac{1 + 2P/100}{3}\ }
$$

代入论文测试的四个档位：

| $P$ (%) | $(1+2P/100)/3$ | 论文表述（p.3 §4.1） |
|---:|---:|---|
| 100 | $3/3 = 1$ | 100% |
| 75 | $2.5/3 = 0.8333$ | 83.33% |
| 50 | $2/3 = 0.6667$ | 66.66% |
| 25 | $1.5/3 = 0.5$ | 50% |

**select gate 的额外开销**：论文指出 top-A 选择的复杂度是 $O(J)$（引 [19]，即 Cormen 等《Introduction to Algorithms》——经典线性时间选择算法，注意**不是排序**，排序会是 $O(J\log J)$），并称它「negligible compared to other costs of updating the GRU equations」（p.3 §3.3）。

> [!note] 本页独立复算：Table 1 的全部 MAC 数字可由这条成本公式精确重建
> 设某骨干的 non-GRU 层算力为 $C_{\text{ng}}$、GRU 层算力为 $C_{\text{g}}$，则该模型在给定 $P$ 下的总算力应为
> $$C_{\text{total}}(P) = C_{\text{ng}} + C_{\text{g}}\cdot\frac{1 + 2P/100}{3}.$$
> 逐行代入 Table 1（第 3 页渲染图核对）：

### 3.7 三个被测试的骨干（p.3 §4.1）

论文把 D-GRU 套在「three strong causal speech enhancement models」上：

| # | 骨干 | 结构 | 输入 / 输出 | 损失 | 参数量 |
|---:|---|---|---|---|---:|
| 1 | **GRU** [20] | FC + 2 层 GRU + FC；第一层 FC 与两层 GRU 的输出维均为 **320** | 输入带噪**幅度谱**；末层 FC 输出 **IRM** [20] | 增强幅度谱与目标幅度谱的 **MSE** | 1.34 M |
| 2 | **MPT** [15] | 2 个 MPT block，每块含 **4 个 GRU**；输入/输出维 **24 / 48** | 输入带噪**幅度谱**；输出 **IRM + magnitude deep-filtering 系数** [21] | 幅度谱 MSE | 0.28 M |
| 3 | **时频域 DPRNN** [11] | 4 个 dual-path block，每块 **3 个 GRU**；每个 GRU 的输入输出维均 **64** | 输入**复数谱**；**直接输出**估计干净语音的**复数谱** | 幅度 MSE 与复数谱 MSE 的**平均** | 0.35 M |

论文自己强调这三个骨干都**已经是为极低算力/极小体积设计的轻量模型**，因此「these characteristics pose a challenge in demonstrating the benefits of the D-GRU」（p.3 §4.1）——也就是说，**在已经压得很紧的模型上还能再省，是本文对普适性的论证方式**。

> [!note] 三个骨干的"causal"是论文的集合声明，不是逐层证明
> 论文用一句话把三个骨干都归为 causal，但**没有给出任何一个的 padding / 状态 / 帧锚定清单**。三个模型里 DPRNN 尤其需要注意：dual-path 结构通常隐含**块级**处理，而论文**没有报告 chunk 长度**——这直接决定了它是否存在块级 look-ahead（见 §2.1）。

> **(a) PESQ 在 $P=75$ 处非单调上翘。** GRU 从 2.58 → **2.62**、DPRNN 从 2.85 → **2.88**（都是 $P=75$ 高于 $P=100$）。论文只笼统写 "slight differences"，**没有评论这个上翘**，也没有做统计检验之外的解释。同时 DPRNN 的 SISNR 反而从 18.08 掉到 17.71、DNSOVAL 从 3.29 掉到 3.26——即**PESQ 与 SISNR/DNSOVAL 的方向不一致**。
> **(b) DNSMOS 只报了 OVL。** 指标列里的 `DNSOVAL` 来自 DNSMOS [24]，但论文**没有分别报告 SIG 与 BAK**。因此本库无法评估 D-GRU 的 **SIG–BAK trade-off**——这是 [[wiki_low_latency/concepts/低 SNR 人声保留评估]] 要求的核心字段之一（见 §5）。

论文的解读（p.3–4 §5）：

- **$P \ge 50\%$ 时三个骨干的全部配对都不显著** → 「33% of the computation costs from the GRUs can be saved」，整体算力降到 **69% / 75% / 71%**。
- **$P=25\%$ 的显著退化只出现在 GRU 与 DPRNN**（GRU 100 vs 25：p=0.035；DPRNN 100 vs 25：p=0.042）。论文对其机理的解释是：

> "the observed degradation is more likely due to the inherent limitations of the D-GRUs, where updating only a limited number of neurons may lead to **failures in capturing input changes**. Additionally, **infrequent updates of some neurons** might result in inaccurate representations of the current state, **introducing internal noise** and worsening the speech enhancement."

- **MPT 为什么不显著**：论文归因于「the presence of **more non-GRU layers** in the model, which might compensate for inaccuracies in the information modeled by the D-GRUs, **albeit with a sacrifice of less computation savings**」——即 MPT 的非 GRU 层占比高（25.4%，见 §3.6 复算），能兜住 D-GRU 的精度损失，但代价是它**本来就省得少**（P=50 只降到 75% vs GRU 69%）。

> [!note] 这是本篇最有信息量的一条，因为它给出了**机制层面的可预测模式**
> Table 2 不只是"掉点"，而是呈现出一个自洽的结构：
> - **省算力多的骨干（GRU，non-GRU 仅 7.6%）先崩**；
> - **省算力少的骨干（MPT，non-GRU 25.4%）不崩**；
> - DPRNN 居中（14.3%），在 $P=25$ 处刚好越过显著线（p=0.042）。
> 即：**D-GRU 的退化幅度与"骨干里 GRU 层承担的建模职责比例"正相关**。这个读法把三个骨干的三组 p 值串成了一条连续的解释链，比论文原文"more non-GRU layers"的一句话更完整。

### 4.4 低 SNR 验证（Figure 2）

论文在 {−5, 0, 5} dB 三档各 150 条上重复了同一套对比，结论是：

> "It reveals a consistent trend observed in results on the DNS test set and further demonstrates that **even under lower SNR, the dynamic GRU-based models maintain similar PESQ scores compared to the conventional GRU when $P \ge 50\%$**.」（p.4 §5）

即：**低 SNR 下趋势一致，$P \ge 50\%$ 时 PESQ 与常规 GRU 相当。** 但——

- 论文**没有给出这三档的任何数值表**，只有柱状图；
- 论文**没有对低 SNR 子集做显著性检验**（Table 2 只针对 DNS 主测试集）；
- −5 dB 是本篇的最低 SNR，**没有更低的档位**，也没有噪声类型分层。

### 4.5 缺失的消融（论文自己承认的）

**阈值型 select gate（Eq. 8）从未被评估。** 论文在 §3.2 给出该式并说明其算力缺陷后，明确写「The performance of the threshold based select gate will be discussed in future work.」（p.2）

这是本篇**最重要的缺失对照**：Eq. (7) 的 top-A 与 Eq. (8) 的阈值法共享同一个"用 $z_t$ 选神经元"的机制，唯一的差别是**数量是否固定**。论文为了算力恒定性直接选择了 top-A，却**没有给出任何证据说明这个选择在质量上付了多少代价**。要论证"固定比例"的合理性，最直接的实验就是同时训练一个阈值版并比较 PESQ–MACs 曲线——这个实验论文没做。

## 5. 这个方向还剩什么问题没解决？（future work / limitation）

**论文自己承认/隐含的：**

1. **阈值型 select gate 的性能未讨论**（p.2 §3.2 明确留给 future work）。这是唯一被点名的、与主方法机制同源的对照缺失。
2. **希望把 DG-RNN 与 Delta RNN 统一到一个框架**（p.4 §6）：「It would be interesting to integrate both models in a unified framework in future work.」——即承认"神经元级固定比例"与"输入驱动阈值"是两条可互补的路，而非互斥。
3. **希望把方法推广到其他模态与任务**（p.4 §7）：「our aim is to investigate the applicability of these models to other modalities and tasks.」
4. 论文指出既有动态计算模型「have been tested primarily on **classification** tasks, and their performance on **regression** tasks, such as speech enhancement, remains to be studied.」（p.4 §6）——本文正是来填这个空白的。

**本页读出的隐藏问题（本库关注）：**

5. **延迟账本是空的。** 论文**只报 MACs，完全没报 RTF，也没有给出任何延迟数字**——无 window−hop、无 $W/2$、无端到端、无逐层 look-ahead 说明。因此：
   - 无法判断它是否接近约 2 ms 硬约束；
   - 已知的只有 hop = 10 ms（= 100 帧/s）这个前端参数，而论文**没有把它与延迟关联**；
   - 按本库口径，D-GRU 的时延字段应全部记 `unreported`，**不得**由 10 ms hop 反推任何"算法延迟"结论。
6. **「算力下降」被当作结论，但没有任何 wall-clock / 能耗证据。** 这是本篇最大的方法学缺口：
   - top-A 选择是一个**数据相关**的算子。在 SIMD/向量化硬件上，"只更新 $A$ 个神经元"意味着**不规则的内存访问（gather/scatter）**、**无法向量化的行选择**、以及**分支/掩码开销**。论文只论证了 $O(J)$ 的选择复杂度"可忽略"，**完全没有论证稀疏更新在真实硬件上能兑现成比例的时间或能耗节省**。
   - 论文自己批评阈值法时说"硬件仍须按最坏情况预留全部算力"——这个批评同样适用于它自己的 top-A 方案：**若硬件不能高效地做 A 行矩阵乘，top-A 的"恒定算力"在墙钟时间上也兑现不了**。论文没有回应这个对称的质疑。
7. **「每步算力恒定」是 MAC 计数层面的性质，不是测量结果。** 本库把它记为设计保证而非实测保证：
   - 在 MAC 口径下，$P$ 固定 ⇒ 每步算量恒定 ⇒ **平均值 = 峰值**（这一点比 Skip-DPCRN 强，后者峰值只降约 15%）；
   - 但论文**未报告 p99、未报告 per-step wall-clock、未报告峰值 RAM/SRAM**，所以这个"恒定"从未被测量过。
   - 对照 [[wiki_low_latency/sources/2022/Skip-DPCRN 2022]] §4.3 与 [[wiki_low_latency/concepts/2207.11108-inference-skipping-parallel-rnn]] §⑤：Skip-DPCRN 是"平均省 33%、峰值只降 15%"；D-GRU 在设计上**消除**了这个平均/峰值落差，但**没有用测量证明**它。
8. **状态漂移风险被承认但未量化。** 论文自己写 "infrequent updates of some neurons might result in inaccurate representations... introducing internal noise"，但**未报告**：神经元被选中间隔的分布、长期未更新神经元的占比、长流（分钟级）下的性能衰减、state reset/warm-up 策略、以及"冷启动时 $h_0$ 全零 + top-A 选择"的行为。对 10 ms hop、100 帧/s 的实时长流，这些是必须回答的问题。
9. **人声保留维度几乎空白。** 指标只有 PESQ / ESTOI / SISNR / **DNSOVAL**。**未报告**：DNSMOS 的 **SIG 与 BAK 分项**（因此无法看 SIG–BAK trade-off）、false-suppression、voiced energy 保留、F0/formant/prosody continuity、ASR WER、SPP/VAD 校准、以及任何按噪声类型（babble / 竞争说话人 / 瞬态 / 未见噪声）的分层。
   - 一个**可见的信号**：$P=25$ 时 DPRNN 的四个指标**同时**退化（PESQ 2.85→2.72、ESTOI 92→91、SISNR 18.08→17.28、DNSOVAL 3.29→3.24），说明退化是系统性的而非单一指标波动。但**四个指标的具体含义不同**（PESQ 感知质量 / ESTOI 可懂度 / SISNR 波形保真 / DNSOVAL 综合听感），论文**没有给出任何一个"人声是否被抑制"的专门指标**，因此本库无法判断这 0.13 的 PESQ 与 1 点 ESTOI 的下降里，有多少来自噪声残留、有多少来自语音损伤。
10. **训练细节不足以完全复现。** 论文未报告：优化器、学习率、batch size、训练步数/epoch、随机种子数、数据增强、验证集划分、三个骨干各自的输入维度（320-point FFT 对应 161 个频点，论文未明写）、DPRNN 的 **chunk 长度**、MPT block 的内部结构、以及 IRM/deep-filtering 系数的具体损失权重。
11. **统计检验的配对性存疑（本页读出的方法学疑点）。** 论文用 **Mann-Whitney U 检验**，理由是非正态。但非正态只说明"该用非参数检验"，**不说明"该用非配对检验"**：
    - 三个骨干在四档 $P$ 上使用的是**同一批 150 条测试语音**，因此 $(P=100, P=25)$ 的 PESQ 是**逐句配对的**观测；
    - Mann-Whitney U 假设两组样本独立，把它用在配对数据上会**损失配对信息、降低检验效力**（即更不容易显著）；
    - 更合适的是 **Wilcoxon 符号秩检验**（配对非参数检验）。
    - 论文**未说明是否做了配对处理**。若确实是未配对检验，那么"$P=25$ 显著退化"的结论是**偏保守**的（真实差异可能更早、更强），这反过来会让"$P \ge 50\%$ 不显著"的结论也变得**偏保守**——即"$P \ge 50\%$ 安全"的结论方向上仍是稳的，但**所有 p 值都不宜按原样引用**。见下方 [!question]。
12. **多重比较未校正。** 3 个骨干 × 6 个配对 = **18 次检验**，论文未做 Bonferroni/FDR 校正。以 $\alpha=0.05$ 计，期望假阳性约 0.9 个——而实际显著的只有 **5 个**（按 Table 2 加粗格统计：GRU 3 个、DPRNN 2 个、MPT 0 个）。这不足以推翻结论，但引用 p 值时应注明未校正。

> [!contradiction] 摘要/引言说"省 50% 算力"，正文 §5 说"省 33%"——两处口径冲突
> - **摘要**：「maintain similar speech intelligibility and quality metrics comparable to the baseline GRU based models **even with an average 50% reduction in GRU computes**.」
> - **§1 贡献列表**：「Results show minimal impact on speech quality and intelligibility with a **50% reduction in GRU computation costs** even under −5 dB SNR.」
> - **§3.3 公式**：$\text{cost(D-GRU)}/\text{cost(GRU)} = (1+2P/100)/3$ ⇒ $P=50$ 时是 **66.66%**，即**只省 33.33%**。
> - **§4.1**：「the effective computation cost for the D-GRU at each $P$ are [100%, 83.33%, **66.66%**, 50%]」——与 §3.3 一致。
> - **§5**：「**33%** of the computation costs from the GRUs can be saved」——与 §3.3/§4.1 一致。
> - **§7 结论**：「updating only **50% of the GRU neurons** at each step can still achieve the same speech enhancement results.」——这里 50% 指的是**神经元比例**。
>
> **判定**：摘要与 §1 的"50% reduction in GRU computes / computation costs"是把「**$P=50$，即更新 50% 的神经元**」误写成了「省 50% 算力」。按本文自己的公式，$P=50$ 的真实算力节省是 **33.33%**。
> **处置**：本库一律采用 **33%**（与 Eq. (3.3)、§4.1、§5 一致，且可被 Table 1 独立复算验证）；引用摘要的 "50% reduction" 时必须注明这是**神经元比例**而非算力节省。这正是「50% 神经元」与「50% 算力」极易混淆的地方——而混淆的代价是把方法的价值夸大了约 1.5 倍。

> [!question] 存疑：Mann-Whitney U 是否适用于配对数据
> 见上文第 11 条。论文只给了一句理由「due to the non-normality of the test data」，**未说明检验是否按配对处理**，也未给出效应量、置信区间或每档的样本统计量。
> 本页不推翻 Table 2 的结论方向（"$P\ge50\%$ 不显著"在更严格的配对检验下方向不变），但建议：**引用这些 p 值时不要当作精确数值**；若要做跨论文的显著性对比，应先确认检验类型与是否校正多重比较。

| **同分支竞品（dual-path 家族）** | [[wiki_low_latency/sources/2021/DPCRN Low-Latency Direction 2021]]、[[wiki_low_latency/entities/DPCRN]]、[[wiki_low_latency/concepts/2107.05429-dual-path-recurrent-context]] | 本文第三个骨干是**时频域 DPRNN**（引文 [11] Luo et al.），与 DPCRN 同属 dual-path 家族。**关键对照**：Skip-DPCRN 正是拿 DPCRN 当宿主；本文的 DPRNN 骨干则是 DPRNN 本尊。两者合起来可以回答"dual-path 结构上，跳步（整步）与跳神经元（部分）哪个更划算"。另注：本文**未报告 DPRNN 的 chunk 长度**，而 chunk 长度直接决定其块级 look-ahead。 |
| **跨分支类比（同为"利用时间冗余降算力"）** | [[wiki_low_latency/sources/2024/SlowFast-SSM 2024]]、[[wiki_low_latency/entities/SlowFast-SSM]]、[[wiki_low_latency/concepts/2411.02019-slowfast-ssm]] | SlowFast-SSM 用**双速率分支 + 状态转移调制**利用时间冗余；D-GRU 用**隐状态慢变**跳过部分神经元更新。两者都建立在"相邻时刻的状态高度相关"这一假设上，但一个改的是**状态更新的速率**（跨帧）、一个改的是**状态更新的宽度**（层内）。 |
| **同分支竞品（低时延时频掩蔽）** | [[wiki_low_latency/sources/2023/FSB-LSTM 2023]]、[[wiki_low_latency/entities/FSB-LSTM]]、[[wiki_low_latency/concepts/2304.08707-full-sub-band-modeling]] | 都是低复杂度时频域 RNN 增强。**算力口径的关键差异**：FSB-LSTM 与 DeepFilterNet2 报的是**固定 MACs**；D-GRU 报的也是固定 MACs（因为 $P$ 固定）——这一点与 Skip-DPCRN 的**输入相关平均 MACs** 不同。因此 D-GRU 的 MACs **可以**与固定算力模型横比，而 Skip-DPCRN 的不行。 |
| **同分支竞品（因果时域）** | [[wiki_low_latency/sources/2021/On TasNet Low-Latency SE 2021]]、[[wiki_low_latency/entities/On-TasNet]]、[[wiki_low_latency/concepts/2103.14882-causal-tasnet]] | 因果 learned-filterbank 路线，关心因果性与低时延；D-GRU 走时频掩蔽/复数谱路线。两者可作为"时域 vs 时频"的因果账本对照——但 D-GRU **没有自己的延迟账本**，无法直接对账。 |
| **延迟账本口径** | [[wiki_low_latency/concepts/严格因果与算法延迟]]、[[wiki_low_latency/concepts/低时延前端与延迟账本]] | D-GRU 是这两页的**极端负面样本**：不但没有逐层 causal certificate，连一个（哪怕未拆分的）延迟数字都没有。适合作为"**只有 MACs 没有延迟**"这类记录的反面示例。 |
| **最严因果口径（尺子）** | [[wiki_low_latency/sources/2026/LaCo-SENet 2026]]、[[wiki_low_latency/entities/LaCo-SENet]] | LaCo-SENet 给出逐层 padding 分配式 + 状态选择算子 + SSU 消融，是本库因果审计的最高标准。用它的尺子量 D-GRU：**STFT 帧锚定未报告、三个骨干的 padding 全部未报告、DPRNN chunk 长度未报告**——因此连"逐层可核验"这一关都过不了。D-GRU 的 `paper-claimed-causal` 判定正是按这把尺子给的。 |
| **人声保留缺口** | [[wiki_low_latency/concepts/低 SNR 人声保留评估]]、[[wiki_low_latency/sources/2023/Uncertainty-Aware Speech Enhancement 2023]]、[[wiki_low_latency/entities/Uncertainty-Aware-SE]]、[[wiki_low_latency/sources/2022/Hybrid Continuity Loss 2022]] | D-GRU 的指标里**只有 OVL 没有 SIG/BAK**，且无 false-suppression / ASR WER / F0 / voiced energy 证据。这些页面提供了本篇缺失的验收字段。 |

## 7. 一句话总结"江湖地位"

> **2024 | 推理期算力压缩 / 神经元级动态计算 | 提出 DG-RNN 框架与零额外参数的 D-GRU——直接复用 GRU 的 update gate $z_t$ 做 top-A 选择，每步只更新固定比例 $P$ 的神经元，在三个本身已为极低算力设计的因果骨干（GRU 1.34 M / MPT 0.28 M / DPRNN 0.35 M）上验证 $P\ge50\%$ 时 PESQ 差异统计不显著，GRU 算力省 33%、整体模型算力降到 69%/75%/71% → 它是"动态算力"这条线上**唯一把每步算量做成常数**的方法，因而构成 Skip-DPCRN（引文 [31]，整步跳过 + 算力随步波动）的正面对立命题；但它**只报 MACs、完全没有延迟/RTF/wall-clock 证据**，top-A 稀疏在真实硬件上的 gather/scatter 收益从未测量，阈值型 select gate 从未评估，长流状态漂移未测，人声保留维度几乎空白——因此它证明了"固定比例的神经元级稀疏在质量上可行"，**没有证明它在硬件上能兑现成延迟或功耗的收益**。**
