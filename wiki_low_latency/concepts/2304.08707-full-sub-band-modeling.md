# 2304.08707 全带-子带集成的低时延建模

## 定义

这里的“全带-子带集成”指：在一个过完备的 D × T × F 时频表示上，顺序组合两个互补的递归块（full-band block 后接 sub-band block）。full-band block 将频率压缩为 frame-level embedding，让一个 LSTM 同时看到所有下采样频率；sub-band block 只保留若干下采样频率序列，并用跨 sub-band 共享的 LSTM 沿时间细化。两个块都上采样后以 residual connection 加回输入，形成贯穿网络的 information highway。

它继承 [[wiki/concepts/全带与子带模型]] 的“全局频谱结构 + 局部频率细节”分工，但 2304.08707 的具体实现是在多麦克风复数 STFT 上做 complex spectral mapping，而不是直接预测幅度 mask。

## 机制与公式

多麦克风混合与时频表示为：

$$
y[n]=s[n]+v[n],\qquad y[n],s[n],v[n]\in\mathbb{R}^{P},
$$

$$
Y(t,f)=S(t,f)+V(t,f)\in\mathbb{C}^{P}.
$$

输入将 P 个麦克风的 RI 分量堆叠为 2P × T × F，前端 Conv2D 映射为 D × T × F。full-band 频率压缩的关键尺寸是：

$$
Q=\left\lceil\frac{F-I}{J}\right\rceil J+I,
\qquad
A=E\left(\frac{Q-I}{J}+1\right),
$$

随后经历 PReLU、causal global layer normalization、H-unit LSTM、linear H → A，再 reshape 与 Deconv2D 恢复。sub-band 对应：

$$
Q'=\left\lceil\frac{F-I'}{J'}\right\rceil J'+I',
$$

并将 ((Q'-I')/J' + 1) 个频率序列交给共享的 H'-unit LSTM。I,J 与 I',J' 是频率 kernel/stride；E,E' 是 Conv2D 通道；D 是 T-F embedding 维数；H,H' 是 full/sub-band LSTM hidden units。

## 为什么对低时延有用

1. 所有卷积的时间 kernel size 为 1，不用为 causal convolution 缓存过去帧；时间依赖交给单向 LSTM。
2. 运行时主要缓存 LSTM 的 hidden/cell states；论文报告 FSB-LSTM 的 streaming buffer 为 46.2 KB。
3. 频率下采样让 sub-band LSTM 只处理 26 个 sub-bands，而不是在每个原始频率上运行一个昂贵模块。
4. Deconv2D 用 linear layer + 频率维 overlap-add，论文报告 MAC 约为典型插零转置卷积实现的 1/J；此 overlap-add 不等于 iSTFT 的时间 overlap-add。

## 论文配置与结果证据

| 项目 | PDF 明确值 |
|---|---|
| 默认前端 | iWS=16 ms、HS=2 ms、oWS=4 ms；256-point DFT，129 维复数谱；算法延迟 4 ms |
| 网络 | B=3，D=32，E=8，I=8，J=4，H=256，E'=64，I'=5，J'=5，H'=64 |
| 规模 | 1.96M 参数；GMAC/s 为 3.37（6ch）、3.31（2ch）、3.30（1ch） |
| 6ch 结果 | SI-SDR 7.8 dB、PESQ 2.61、eSTOI 0.830 |
| 2ch 结果 | SI-SDR 4.9 dB、PESQ 2.20、eSTOI 0.753 |
| 1ch 结果 | SI-SDR 3.1 dB、PESQ 1.92、eSTOI 0.688 |
| hop 消融 | FB-LSTM 控制在 HS=1 ms/oWS=2 ms 时为 SI-SDR 8.0 dB、PESQ 2.54、eSTOI 0.821、4.65 GMAC/s |

这里的 2 ms 是 FB-LSTM 控制的 oWS，不应写成 FSB-LSTM 已完成 2 ms 直接验证。论文也没有提供 RTF、目标芯片 wall-clock、p99 或 deadline 通过率，所以 GMAC/s 与 buffer 只能作为计算预算，不能替代部署证据。

## 与相关方法的边界

- [[wiki/sources/2021/FullSubNet 2021]]：同样融合 full/sub-band，但主要是单通道幅度/掩蔽路线；FSB-LSTM 在 RI 多通道谱上使用残差高速路和下采样 sub-band LSTM。
- [[wiki_low_latency/sources/2023/GCFSnet 2023]]：同属低时延多通道/助听器语境；GCFSnet 的核心是本侧复数 filter-and-sum 与延迟跨耳特征，不能把两者的 GMAC、时延或质量数字直接横比。
- [[wiki/concepts/STFT与频谱图]]：提供本方法的 STFT/复数谱输入背景。
- [[wiki_low_latency/index]]：本概念属于“约 2 ms、strict causal、噪声抑制 + 人声保留”的低时延方向；本文的人声保留只被 SI-SDR/PESQ/eSTOI 间接覆盖，仍缺专门指标。
