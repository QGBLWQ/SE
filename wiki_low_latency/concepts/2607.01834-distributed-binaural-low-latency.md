# 2607.01834 - 分布式双耳低时延增强的五件套

## 定义

这里的「五件套」指 RT-Tango 在**同一个两阶段分布式骨架上**叠加的五类可复用机制。它们各自独立成立，组合起来才满足「分布式双耳 + 严格因果 + 低算力」的联合约束：

1. **两阶段分布式融合**：每耳本地估计 mask + 空间滤波，只把**耳侧压缩信号**跨耳传输，再由对侧 MN-DNN 精修。
2. **非对称 STFT**：长分析窗保频率分辨率、短合成窗降重建延迟，把「频率分辨率预算」和「算法延迟预算」解耦。
3. **分组循环（GRNN）**：把频率轴切成 $G$ 组分别递归，把循环复杂度从 $O(H^2)$ 降到 $O(H^2/G)$，用 representation rearrangement 恢复跨组信息。
4. **时间稀疏化（FRS）**：固定间隔复用 mask，而不是每帧推理，也不用 learned gate。
5. **在线 SCM（EMA 递归）**：把 SDW-MWF 需要的空间协方差矩阵改成递归指数滑动平均，支持流式。

这套组合的价值不在于任何单项的原创性（论文自身也把非对称 STFT 归于 [20,21]、GRNN 归于 [18]、ERB 压缩归于 GTCRN [11]），而在于**把它们装进分布式双耳框架并给出干净的消融**。迁移时应逐项评估，而不是整体照搬。

## 机制一：两阶段分布式融合

~~~text
Stage 1（本耳）  mask_1 = SN-DNN(ERB(本耳 STFT))
                w_1    = SDW-MWF(本耳 SCM, mask_1)
                传给对侧：耳侧压缩信号
Stage 2（本耳）  mask_2 = MN-DNN(ERB(本耳 STFT), 对侧交换表征)
                w_2    = SDW-MWF(SCM, mask_2)  →  iSTFT  →  本耳输出
~~~

设计含义：**空间滤波主路径不等待对侧**，对侧信息只影响第二阶段的 mask 估计。这与 [[wiki_low_latency/concepts/低比特率双耳特征链路]] 提出的原则一致（低时延主路径只读当前本地观测，迟到的辅助信息进辅助支路）。

> [!question] 论文未量化的部分
> RT-Tango 论文**没有报告**跨耳链路传输的比特率、延迟、丢包/抖动处理，也没有做链路量化消融。相比 GCFSnet 明确训练 4–12 ms 随机延迟与 4–16 bit 量化，「分布式」这一卖点的通信维度在本文中是**未闭环**的。

## 机制二：非对称 STFT——解耦频率分辨率与算法延迟

核心关系（**论文未给出显式公式，仅文字描述**）：

$$
\text{长分析窗 } aW \Rightarrow \text{高频率分辨率},
\qquad
\text{短合成窗 } sW \Rightarrow \text{低重建延迟}.
$$

直觉是：普通 STFT-iSTFT 用等长分析/合成窗，要对一个输出样本完成 OLA，可能必须等到后续重叠帧完成，于是长窗的频率分辨率换来长算法延迟。非对称配置让每帧 iDFT 后只保留**尾部较短片段**参与 OLA，从而把延迟压到 $sW$ 量级。

RT-Tango 的窗配置消融（Table 5，RT-Tango，32 ms 分析窗固定）：

| aW (ms) | sW (ms) | Window | SI-SDR L/R | SI-SAR L/R |
|---:|---:|---|---:|---:|
| 32 | 32 | sqrtHann | 4.4 / 4.7 | 5.0 / 5.0 |
| 32 | 8 | sqrtHann | 1.2 / 1.8 | 1.4 / 1.9 |
| 32 | 8 | **asyHann** | 3.7 / 4.3 | 4.3 / 4.5 |
| 32 | 4 | asyHann | 3.4 / 4.0 | 3.9 / 4.1 |

可复用结论：**低延迟的瓶颈在重建前端，而不在模型**。同样的网络、同样的离线 SCM，仅把窗型从 sqrtHann 换成 asyHann，8 ms 合成窗下的 SI-SDR 就从 1.2 dB 回到 3.7 dB。任何约 2 ms 系统都应先做窗型/窗长扫描。

与 [[wiki_low_latency/concepts/2204.09911-short-asymmetric-stft]] 的差异：2204.09911 把同类双窗配置明确标为 `low_look_ahead / frame_online`，并额外使用 future-frame prediction；RT-Tango 只取「长分析窗 + 短合成窗」这一半，却声明 strictly causal。**两者对因果性的判定口径冲突**，采信前需核对帧锚定与 look-ahead。

## 机制三：分组循环网络 GRNN

论文给出的唯一显式推导是复杂度量级：循环层计算量随隐状态维度 $H$ 近似二次增长，把特征空间切成 $G$ 组、每组 $H/G$，则

$$
G \cdot O\!\left(\left(\frac{H}{G}\right)^{2}\right) = O\!\left(\frac{H^{2}}{G}\right).
$$

动机是语音频谱依赖的**局部性**：频带内邻近区域依赖更强。跨组依赖由 **representation rearrangement [18]** 交换，用以恢复全局频谱建模。注意该式只描述循环层量级，未含 FC 与 rearrangement 的常数开销。

**关键可复用发现：分组敏感度在不同阶段不对称。**

| 消融 | DNN (SN+MN) MMACs/frame | SI-SDR L/R | 结论 |
|---|---:|---:|---|
| Tango-RNN | 1.06 | 4.7 / 5.0 | 基线 |
| + GRNN SN=2 | 0.69 | 4.7 / 4.9 | — |
| + GRNN SN=8 | 0.59 | 4.7 / 4.9 | **SN 分组几乎免费**（−44% 算力，不掉点） |
| + GRNN MN=2 | 0.74 | 4.7 / 4.9 | MN 只能到 G=2 |
| + GRNN MN=8 | 0.64 | 3.8 / 4.1 | **MN 分组 G=8 掉 0.8–1 dB** |

论文解释：第二阶段要融合跨耳表征，跨频带全局依赖更强，因此不能像第一阶段那样激进分组。**迁移规则：任何多阶段/多分支架构都必须分阶段做分组消融，不能把「G 越大越好」当全局结论。**

## 机制四：时间稀疏化——FRS 优于 learned gating

**Fixed-Rate Skipping (FRS)**：按固定间隔执行 mask 估计器，中间帧复用上一次 mask。RT-Tango 取 SN-DNN 1/4、MN-DNN 1/2（SN 跳 75% 帧、MN 跳 50% 帧）。

对比对象是 learned skip gates（SkipRNN [19]、TinyLSTM [3]），它们每帧评估门控来决定是否更新递归状态。消融结果：

| 消融位置 | 方法 | SI-SDR 变化（左耳） | 结论 |
|---|---|---|---|
| SN-DNN | FRS 1/2、1/4 | 4.5 → 4.4 / 4.3 dB | 0.2 dB 内保持 |
| SN-DNN | SkipRNN / TinyLSTM | 4.5 → 4.4 / 4.3 dB | 达到 80% skip 率，但门控每帧有开销 |
| MN-DNN | FRS 1/2、1/4 | 4.5 → 4.4 / 4.3 dB | 0.2 dB 内保持 |
| MN-DNN | SkipRNN / TinyLSTM | 4.5 → **3.8 / 3.3 dB** | **明显有害** |

**反直觉但很有工程价值的负结果**：在超高帧率低延迟场景下，learned gating 反而不划算——门控每帧都要算，且对需要跨耳融合的 MN-DNN 有害。FRS 被选中的理由是**稳定性 + 可预测的算力节省**：4 ms hop 下把 DNN 成本从 67.5 降到 28.08 MMACs/s。

可迁移性：若目标是约 2 ms 前端（帧率≈500 frames/s），门控开销与状态更新频率成正比，FRS 的优势会更明显。

> [!note] 表内 0 的含义
> 消融表中 FRS 的「w/ Skip」列为 0，指非更新帧**不再执行 DNN**，不含 mask 复用逻辑、缓存读取与帧对齐的开销。

## 机制五：在线 SCM 的 EMA 递归更新

SDW-MWF 需要空间协方差矩阵。RT-Tango-OS 用递归 EMA 在线更新，**α = 0.995**，4 ms 输入率下**每 8 帧更新一次** → 有效间隔 32 ms（≈31 次/s）。

> [!warning] 原文未给出该式，仅文字描述
> 论文只写「updated online using a recursive exponential moving average (EMA)」并给出 α 与更新节奏，**没有给出**递归更新方程、初始化、正则化或逆矩阵更新方式。标准 EMA 形式为
> $$\hat{\mathbf R}_{\Phi\Phi}(t) = \alpha\,\hat{\mathbf R}_{\Phi\Phi}(t-1) + (1-\alpha)\,\mathbf\Phi(t)\mathbf\Phi^{H}(t),$$
> 但**该式并非论文所写**，此处仅作理解参考，不作为论文证据。同理，论文对 SDW-MWF 只给引用 [17] 与一句功能描述，**未给出代价函数或滤波形式**。

### 可复用的验收要求：在线统计必须按冷启动评测

> [!warning] 本文最重要的方法论缺口
> 论文原文：*"As online SCM estimation requires an adaptation period, RT-Tango-OS was evaluated in steady state by repeating each mixture a sufficient number of times to allow for convergence. The metrics are computed on the final repetition."*
>
> 这等于给系统**无限长的 warm-up**。真实助听器流式部署没有「把同一句话重复 N 遍再开始」的机会——用户第一句话必须直接被处理。因此该页建议把下面这条固化为本库对**任何在线递归统计方法**的验收要求：
>
> 1. 报告收敛前曲线（第 1 帧到收敛帧的指标变化）；
> 2. 报告收敛所需帧数/时间；
> 3. 报告 α（或遗忘因子）的敏感性；
> 4. 冷启动指标与稳态指标**分开报告**。
>
> 只有稳态指标、没有冷启动曲线的在线统计结果，**不能**用于流式部署论证。

## 证据中的收益

| 模型 | Hop | Total MMACs/s | SI-SDR L/R | SI-SIR L/R | PESQ L/R |
|---|---:|---:|---:|---:|---:|
| Unprocessed | − | − | −0.6 / −4.6 | 0.0 / −4.0 | 1.14 / 1.10 |
| Tango（CNN） | 16 ms | 605.98 | 4.2 / 4.4 | 20.8 / 24.1 | 1.61 / 1.64 |
| Tango-RNN | 16 ms | 67.20 | 4.7 / 5.0 | 21.6 / 25.0 | 1.66 / 1.70 |
| Tango-RNN + GRNN(8,2) | 16 ms | 18.22 | 4.5 / 4.8 | 21.3 / 24.8 | 1.66 / 1.70 |
| **RT-Tango** | 4 ms | 33.41 | 4.4 / 4.7 | 20.8 / 24.6 | 1.66 / 1.71 |
| **RT-Tango-OS** | 4 ms | 35.14 | 2.9 / 3.8 | 20.5 / 24.7 | 1.54 / 1.63 |
| GTCRN（4 ms 对照） | 4 ms | 197.5 | 6.0 / 4.0 | 16.6 / 13.8 | 1.52 / 1.36 |

读法：RT-Tango-OS **保住了 SI-SIR**（20.5/24.7 ≈ 离线 20.8/24.6），说明空间抑制能力未被在线化破坏；掉的是 **SI-SDR/SI-SAR**（4.4/4.7 → 2.9/3.8），论文归因于非对称 STFT 先引入、在线 SCM 再放大。SI-SIR 保持 + SI-SDR 下降的组合，意味着**抑制够了但重建变差**（引入伪影/目标失真），这正是需要人声保留专项指标（false-suppression、F0/prosody、ASR WER）才能定性判断的情形——而论文没有报告这些。

## 时延账本与迁移边界

| 项目 | 论文证据 | 本 Wiki 判定 |
|---|---|---|
| 分析窗 / 合成窗 | 32 ms / 8 ms（asyHann） | 长窗 + 短窗解耦；帧锚定未报告 → 若中心对齐则含 look-ahead |
| hop / 帧率 | 4 ms，≈250 frames/s | 更新率明确 |
| 算法延迟 | RT-Tango-OS 论文口径 8 ms | **记账依据未给**；不能当作已推导值 |
| look-ahead | 未报告 | `low_look_ahead` 未能排除 |
| 时间因果 | 论文声明 strict causal | 论文级声明，无逐层 certificate |
| 在线统计 | EMA α=0.995，每 8 帧，32 ms 有效间隔 | 递归形式因果；**评测口径含无限预热** |
| 每帧算力 | 0.49 MMACs/frame（DNN 0.27 + SDW-MWF 0.22） | 单节点；不含 FFT/iFFT |
| 运行时 | 未报告 RTF | 未验证 |
| 端到端 | ADC/DMA、I/O、DAC、capture-to-playback、underrun 未报告 | 未验证 |

迁移边界：这套五件套可以迁移到约 2 ms 单/双通道系统，但必须

1. 重新做窗型/窗长扫描（2 ms 级 sW 远短于本文 8 ms，asyHann 是否仍稳需要验证）；
2. 按冷启动报告在线 SCM；
3. 补 false-suppression / F0 / prosody / ASR WER 与 −10 dB、babble、竞争说话人分层；
4. 补目标 DSP 的 p99、峰值内存、量化与 underrun；
5. 若保留分布式，补跨耳链路比特率/延迟/丢包消融。
