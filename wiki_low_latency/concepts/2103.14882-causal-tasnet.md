# 2103.14882 - 因果 TasNet 的短 hop、内域分离与混叠假说

## 简洁定义

这个概念来自 On TasNet：在 waveform-domain TasNet 中，低时延并不只由 window length 决定，**hop/encoder stride、causal convolution、归一化和 inner-domain 的 row-wise 处理必须一起审计**。论文的 2/1 ms、64/32 ms、64/1 ms 对照显示 hop 是更敏感的旋钮；作者将大 hop 的退化解释为可能的 aliasing，但没有把该解释做成因果证明。

本概念页同时区分三个层次：

1. learned inner-domain 让目标与噪声更可分；
2. cLN + causal convolution 提供论文所称 essentially causal 的配置；
3. 1 ms frame hop 是论文的低时延线索，不是设备端 capture-to-playback deadline。

## 关键公式与符号

### 任务公式

论文明确给出的单通道混合为：

$$
x_i \in \mathbb{R}^{L},\qquad v \in \mathbb{R}^{L},\qquad
y=\sum_{i=1}^{I}x_i+v .
$$

网络估计目标为：

$$
\hat{x}_i=f_{\mathrm{DNN}}(y,\theta).
$$

| 符号 | 物理意义 |
|---|---|
| x_i | 第 i 个无噪时域语音目标 |
| v | 加性噪声 |
| y | 单麦克风观测波形 |
| I | 目标语音/说话人数量；I=1 是增强，I=2 是分离验证 |
| L | 任务定义中的信号段长度；不要自动等同于配置字符串中的 L16 |
| theta | DNN 参数 |

### TasNet 流程的符号化重写

论文以 Figure 1 和文字描述 encoder、scalar weighting separator、decoder。为了连接低时延审计，可将过程记为：

$$
\mathbf{w}_t=E\!\left(y_{t:t+L_e-1}\right),\qquad
\mathbf{d}_{i,t}=\mathbf{w}_t\odot\mathbf{m}_{i,t},\qquad
\hat{x}_i=D\!\left(\{\mathbf{d}_{i,t}\}_t\right).
$$

这里 E 是 learned encoder，w_t 是 inner-domain 表示，m_i,t 是逐点 scalar weight，d_i,t 是加权表示，D 是 learned decoder。这个式组是依据论文流程做的**符号化整理**，不是 PDF 中额外编号的方程。

### Inner-domain overlap

论文将 overlap 定义为：目标和噪声都对其有显著贡献的 inner-domain coefficients 数量，占全部 coefficients 数量的比例。可写成：

$$
\mathrm{overlap}
=
\frac{\#\{\text{coefficients with significant target and noise contributions}\}}
{\#\{\text{all coefficients}\}}.
$$

该式是对论文文字定义的形式化复述。overlap 低可以解释为什么 scalar weights 更容易抑制噪声而不伤害目标，但不能直接等同于 false-suppression rate。

## 三种因果性配置

| 配置 | future 信息来源 | 论文证据 | Wiki 判定 |
|---|---|---|---|
| non-causal convolution + gLN | gLN 使用 entire signal；卷积本身 non-causal | Section 2.1 | non_causal |
| non-causal convolution + cLN | convolution 需要依赖 kernel length 的 look-ahead | Section 2.1 | non_causal / low_look_ahead |
| causal convolution + cLN | 论文称 essentially causal；latency 由 frame hop 决定，多数实验为 1 ms | Section 2.1 | paper_claimed_causal |

### 为什么还不能称 strict_causal

PDF 没有逐层写出 padding、decoder overlap/add、卷积缓存、归一化统计、warm-up、state reset 或每个输出样本的最后可读输入样本，也没有报告流式 batch=1 或长流运行。因此本页把最后一行标为 paper_claimed_causal，而不是 strict_causal。要升级标签，仍需实现级 dependency certificate。

## hop 与 aliasing 的机制链

论文的现象证据是：

| Window / hop | Test set | Processed STOI | Processed PESQ | Processed SI-SDR |
|---|---|---:|---:|---:|
| 2 / 1 ms | 2bal | 0.93 | 2.66 | 12.4 |
| 64 / 32 ms | 2bal | 0.79 | 1.71 | 4.8 |
| 64 / 1 ms | 2bal | 0.93 | 2.78 | 12.5 |
| 2 / 1 ms | ssn | 0.93 | 2.60 | 11.4 |
| 64 / 32 ms | ssn | 0.87 | 2.07 | 8.2 |
| 64 / 1 ms | ssn | 0.93 | 2.60 | 11.0 |

作者的解释是：separator 的 convolution 独立处理 inner-domain 的 rows；每个 row 是按 hop decimation 的输入版本；没有 anti-aliasing filter 时，较大 hop 会把 aliasing components 带入表示。因而 64/32 退化而 64/1 恢复，提示 hop 比 window 更关键。

证据等级应写成：

- **观测事实**：改变 hop 后 Table 2 指标显著变化，改回 1 ms 后 64 ms window 的指标恢复；
- **作者假说**：较大 hop 引入更强 aliasing；
- **尚未验证**：没有 anti-aliasing 对照、aliasing energy 测量或 cross-row separator 消融；
- **后续关联**：论文引用的跨 row/长序列方向可参阅 [[wiki/sources/2020/DPRNN 2020]]，但不能把后续模型的分数回填为本文证据。

## 对人声保留的意义与边界

低 inner-domain overlap 提供了一个合理机制：目标和噪声更容易在表示维度上分开，scalar weighting 有机会更少误伤目标。Figure 2（原 PDF 第 3 页）中，作者报告 competing speaker 和 ssn 的 overlap 降低比 bus 更明显；bus 的低通性质使 STFT 已经相对有效。

但这仍然不是独立的 speech-preservation scorecard。本文没有报告：

- false-suppression 或 over-suppression；
- DNSMOS SIG/BAK/OVL；
- SPP/VAD calibration；
- ASR WER；
- F0、formant、prosody continuity；
- voiced-energy retention；
- 主观听感测试。

此外，训练 SNR 是 [-10,10] dB 均匀采样，测试表只给 0 dB；不能根据训练范围臆造 -10、-5、0、5 dB 的分层结果。

## 延迟、复杂度与 deadline 证据边界

| 字段 | 本文 PDF 证据 | 不能推出的结论 |
|---|---|---|
| 采样率 | 8 kHz | 不能外推到 full-band |
| short setting | 2 ms window / 1 ms hop | 不能直接推出端到端 2 ms |
| causal latency | frame hop，多数实验为 1 ms | 不能推出 capture-to-playback 1 ms |
| 模型大小 | 3.5M parameters | 不能推出 MAC/s、FLOPs 或内存 |
| receptive field | Table 1: 1.53 s；Section 2.1: 15,310 samples | 两者不应擅自合并；receptive field 也不等于算法延迟 |
| runtime | 未报告 CPU/GPU、RTF、p50/p95/p99 | 不能判断 deadline 是否稳定通过 |
| streaming/deployment | 未报告 batch=1、warm-up、state reset、underrun/overrun、recovery | 不能声称部署就绪 |
