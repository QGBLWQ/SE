# 低时延前端与延迟账本

## 定义

低时延前端与延迟账本把 window、hop、look-ahead、模型计算、I/O buffer 和 deadline 分开记录，防止把论文中的一个 latency 数字误读成端到端实时保证。

## 最小字段

| 字段 | 问题 |
|---|---|
| algorithmic latency | 需要多少未来样本/帧才能输出 |
| computation latency | batch=1 的 p50/p95/p99 是否赶得上 hop |
| system latency | capture、DMA、线程、DAC/playout 还增加多少 |
| speech preservation | 过抑制、弱辅音、气声、有声周期是否被单独测量 |
| failure handling | deadline miss、丢包、状态 reset、warm-up/flush 怎么处理 |
