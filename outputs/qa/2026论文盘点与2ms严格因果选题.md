# 问题

基于目前库内 2026 年论文，选最可行且最可能形成论文的方向。范围：`wiki/sources/2026/` 五篇、`wiki_array/sources/2026/` 五篇、`wiki_low_latency/sources/2026/` 六篇，共 16 篇；最后一篇推荐系统论文仅是跨域方法参照。以下数字是论文及本库 source 页记录，不是本次复现实验；数据集、通道数和硬件不同，禁止横向排 SOTA。主目标沿用 [[wiki_low_latency/index]]：单通道 16 kHz 起步，严格因果、约 2 ms 算法延迟，低 SNR 抑噪兼顾人声保留，并另测端侧 deadline。

## 首选可证伪 idea

**严格因果 2 ms 下的“误抑制风险约束”增强**：测试极短时帧低 SNR 下，模型对弱辅音、气声和语音起止点的不确定性是否使激进掩蔽伤害可懂度；让小因果头从当前和历史特征估计“当前增益将误删语音”的风险，仅在高风险时提高 gain floor 或放慢衰减/加快恢复。训练时可用干净语音和全句 teacher 生成风险标签，但部署只允许因果特征与固定大小历史状态；**不是**推理时用未来语义、也不是无条件提高 floor。此机制需先以固定 floor、普通 SPP、单独 continuity loss 为对照；否则只是已知模块拼接。其与既有 [[outputs/experiments/低时延不确定性感知人声保留基线]] 一致，新增检验重点是“同等噪声残留下，条件化保护是否真的比固定留噪更少误删弱语音”。

**先验障碍**：[[wiki_low_latency/sources/2022/STFT-Domain Very Low Algorithmic Latency 2022]] 已声称 2 ms（未来帧目标预测，不是未来观测读取），故“达到 2 ms”本身并不新；[[wiki_low_latency/sources/2024/Ultra-Low Latency Speech Enhancement Comprehensive Study 2024]] 已做 3 ms 对照，证明短窗技巧在真实数据可能不稳定。创新必须来自约束下**语音误抑制的可验证净改善**，而非重新命名非对称窗、SPP 或 floor。

**最小实验**：选 16 kHz 单通道、每 32 样本输出一次的短因果 filterbank/前端，配小单向 GRU；逐样本记最新可读输入、窗口/OLA、状态缓存和 32 样本释放时刻，先证明真正的 2 ms 算法账本与 chunk=1 稳态运行。按 `基线 → 固定 floor → SPP floor → 风险头（相同模型/算力）→ 训练期连续性损失` 消融；另设条件错配/随机监督与无目标语音纯噪测试。对同一数据及噪声，匹配 BAK 或残余噪声后比较误抑制、弱辅音召回、STOI/eSTOI、ASR WER、SIG、PESQ/SI-SDR，按 −10/−5/0/5 dB、babble/竞争说话人/瞬态/未见噪声报告多种子区间。额外测 QAT/int8 与 float32 及冷启动/长流/state reset；在目标硬件 batch=1 测完整前后端 p50/p95/p99、deadline miss、峰值 RAM、功耗。若同等 BAK 下弱语音不改善，或者量化后/真机 p99 不达标，就不能以“2 ms 可部署且保人声”为论文主张。

**可行性与发表风险**：实验设计和复用数据/公开基线较直接，但真实 2 ms 端侧 deadline 及低 SNR 误删改善尚未验证，不存在基于本库即可量化的“中稿概率”。如没有目标硬件，结论只能是算法级严格因果与桌面流式实测，不能写耳戴端侧部署。纯补做验证而没有风险头相对强 floor 的稳健净收益，贡献偏弱。

**备选**：若主目标允许切换到多通道定位，可做 NeuralMUSIC 在几何失配/故障下的可靠协方差估计，先和经典 MUSIC/SRP、诊断引导 TTA 在相同麦位/故障设置对照；公开代码有利于起步，但与单通道 2 ms 课题完全不同，不混作同一 paper。
