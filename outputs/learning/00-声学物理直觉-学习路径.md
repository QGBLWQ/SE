## Section 1: 声音是什么

### 直觉建立

声音的本质是**空气的振动**。

- 一个物体振动（比如声带、扬声器振膜）→ 推动旁边的空气 → 空气被压缩 → 压缩区推动更远的空气 → 形成**纵波**
- 在**一个固定位置**（比如麦克风），你测到的是气压随时间的变化——一条波形曲线
- 这个波形可以分解为不同频率的正弦波（傅里叶变换——你已经会的）

关键认知：**声音有三个独立属性**
1. **频率**：音调高低。语音主要在 100Hz-8kHz
2. **幅度**：响度
3. **相位**：波到了"哪个位置"——后面会反复用到

### 数学补充

纯音（单一频率）可以写为：

$$p(t) = A \sin(2\pi f t + \phi)$$

- $f$：频率 (Hz)
- $A$：幅度
- $\phi$：初始相位
- 波长 $\lambda = c / f$，其中 $c \approx 343$ m/s (空气中的声速)

## Section 2: 声波怎么传播

### 直觉建立

声源发出声音后，声波在空间中**向外扩散**。

两种极端模型：

**球面波（近场）**：
- 像一个膨胀的气球，声能在球面上分布
- 离声源越远 → 球面越大 → 单位面积能量越小 → 声音越轻
- 声压**随距离衰减**（平方反比）
- **波前是弯曲的** → 同一个波到达不同麦克风时，入射角度不同

**平面波（远场）**：
- 当你在很远的地方看一个很小的区域，球面的那一小片≈平的
- **波前是平的** → 所有麦克风的入射角度相同
- 声源定位中**最常用的假设**（极大简化了几何关系）

什么时候用哪种？

| 条件 | 模型 |
|---|---|
| 声源距离 >> 阵列尺寸 | 平面波 ✅ |
| 声源很近（< 1m），阵列很大 | 球面波 |
| 大多数语音定位场景 | 平面波就够了 |

### 数学补充

远场条件：$r \gg 2L^2/\lambda$，其中 $r$ 是距离，$L$ 是阵列孔径。

实际上，大多数阵列声源定位都假设平面波——这不仅简化了数学，而且**即使有点误差，模型本身也足够鲁棒**。

## Section 3: 多麦克风为什么能判断方向

### 直觉建立

**这是整个声源定位方向最核心的物理直觉，请反复读三遍。**

想象两个麦克风，相距 $d$：

```
        声波 →
    ●────●  (麦克风1在前，麦克风2在后)
   Mic1  Mic2
```

声波先到达 Mic1，过一会儿才到达 Mic2。这个时间差 $\tau$ 就是 TDOA (Time Difference of Arrival)。

**关键几何关系**：

$$\tau = \frac{d \sin\theta}{c}$$

- 如果声源正对着阵列（$\theta = 0°$）→ $\sin\theta = 0$ → $\tau = 0$ → 同时到达
- 如果声源在侧面（$\theta = 90°$）→ $\sin\theta = 1$ → $\tau = d/c$ → 最大延迟
- 反过来：**测出 $\tau$，就能算出 $\theta$**

这就是声源定位最底层的原理。

**在频域看更清楚**：

时域的时间差 $\tau$，在频域表现为**相位差**：

$$\Delta\phi = 2\pi f \cdot \tau = 2\pi f \cdot \frac{d \sin\theta}{c}$$

所以：**不同麦克风之间的相位差模式直接编码了声源方向**。

这也是为什么 Chakrabarty 2017 可以直接把 STFT 相位扔进 CNN——相位本身已经包含了所有空间信息。

### 数学补充

考虑频率 $f$ 的纯音，从方向 $\theta$ 入射到间距 $d$ 的两个麦克风：

- Mic1 收到：$A\sin(2\pi f t + \phi)$
- Mic2 收到：$A\sin(2\pi f (t - \tau) + \phi) = A\sin(2\pi f t + \phi - \Delta\phi)$

其中 $\Delta\phi = 2\pi f \tau = 2\pi f \cdot \frac{d \sin\theta}{c} = \frac{2\pi d}{\lambda} \sin\theta$。

## Section 4: 空间混叠——为什么不能随便放麦克风

### 直觉建立

上一节我们假设**一个时间差对应一个角度**。但这里有个坑。

相位差 $\Delta\phi$ 的范围是 $2\pi$（因为相位是循环的：$2\pi$ 后回到原点）。但物理上的相位差可能超过 $2\pi$：

$$\Delta\phi = \frac{2\pi d}{\lambda} \sin\theta$$

当 $d > \lambda/2$ 时，$\Delta\phi$ 可能超过 $2\pi$ → 多个不同的 $\theta$ 产生**相同的**测量相位差。

**例子**：
- 4 kHz 的声音，$\lambda = c/f \approx 8.6$ cm
- 如果你的麦克风间距 $d = 5$ cm
- $d/\lambda \approx 0.58 > 0.5$ → **高频时存在角度模糊**

这就是**空间混叠**——本质上是空间采样不够密的问题，和时域的 Nyquist 采样定理是同一个道理。

**空间 Nyquist 准则**：$d \leq \lambda_{\min}/2$

### 数学补充

相位差的完整公式：

$$\Delta\phi_{\text{measured}} = \frac{2\pi d}{\lambda} \sin\theta \pmod{2\pi}$$

当 $\frac{2\pi d}{\lambda} |\sin\theta| > \pi$ 时，多个 $\theta$ 产生相同的 $\Delta\phi_{\text{measured}}$。

## Section 5: 房间改变了什么——混响

### 直觉建立

到目前为止，我们假设声波走**直线**从声源到麦克风。但在真实房间里：

```
声源 ──→ 直达声 (direct path) ──→ 麦克风 ✅ 有用信息
声源 ──→ 墙 → 麦克风 (1次反射) ──→ 麦克风 ❌ 干扰
声源 ──→ 墙 → 地板 → 麦克风 (2次反射) ──→ 麦克风 ❌ 干扰
... (几百上千条路径)
```

你收到的信号 = 直达声 + 成百上千条反射声（每条有不同的延迟和衰减）。

**关键参数：RT60**
- 房间混响时间的标准度量
- 定义：声音停止后，声压下降 60 dB 所需的时间
- 典型值：0.2s（消声室）→ 0.5s（办公室）→ 1.0s+（大教堂）

**混响对定位的影响**：

| 影响 | 说明 |
|---|---|
| 早期反射 (0-50ms) | 可能产生**虚假的相关峰**——看起来像另一个方向的声源 |
| 后期混响 | 相位关系被**随机化**——破坏了 TDOA 和子空间方法的假设 |
| 整体效果 | 低 RT60 → 简单，高 RT60 → 所有方法都退化 |

### 数学补充

房间脉冲响应 (RIR)：

$$h(t) = \sum_{k=1}^{K} \alpha_k \delta(t - \tau_k)$$

- $K$：包括直达声和所有反射的路径总数
- $\alpha_k$：第 $k$ 条路径的衰减系数
- $\tau_k$：第 $k$ 条路径的延迟
- 直达声对应最小 $\tau_k$，通常有最大的 $\alpha_k$

麦克风收到的信号 = 声源信号和 RIR 的卷积：

$$x(t) = s(t) * h(t) + n(t)$$

## Section 6: 回到问题——声源定位到底难在哪

### 直觉建立

把前五节的知识串起来，理解这个问题的**本质困难**：

| 难点 | 原因 | 谁受影响最大 |
|---|---|---|
| **噪声** | 低 SNR 时相位被噪声扰动 → 相位差测量不准 | TDOA / MUSIC / SRP-PHAT |
| **混响** | 反射产生虚假相位关系 → 看起来像多了几个声源 | 所有传统方法 |
| **多声源** | 多个声源的信号混在一起，相位是非线性混合 → 无法直接分解 | 几乎所有方法 |
| **空间混叠** | 高频时多个角度产生相同相位差 | 需要跨频率联合建模 |
| **真实世界** | 房间形状、温湿度、障碍物 → 无法纯靠公式精确建模 | 传统方法假设失效 |

### 为什么深度学习有优势

| 传统方法 | 深度学习 |
|---|---|
| 需要精确的物理假设（自由场、已知阵列几何） | **从数据中隐式学习**物理规律 |
| 每个模块独立设计（特征 → 估计） | **端到端联合优化** |
| 对未见条件泛化差 | **多条件训练**提升鲁棒性 |
| 多声源场景下表现急剧退化 | 可以通过数据增强+架构设计处理 |

### 动手练习（强烈推荐，各花 30 分钟）

```python
# 练习1：TDOA 直觉
# 生成两个正弦波，一个比另一个延迟 τ，算相关，找峰值
import numpy as np
f = 1000  # 1 kHz
fs = 16000
t = np.arange(0, 0.01, 1/fs)
s1 = np.sin(2*np.pi*f*t)
tau_samples = 5  # 延迟 5 个采样点
s2 = np.sin(2*np.pi*f*(t - tau_samples/fs))
# 计算互相关，找峰值位置
corr = np.correlate(s1, s2, mode='full')
lag = np.argmax(corr) - len(s1) + 1
print(f"估计延迟: {lag} 采样点, 真实: {tau_samples}")
```

```python
# 练习2：频率与相位差
# 同一个延迟下，不同频率的相位差不同
f1, f2 = 500, 4000
tau = 0.0001  # 0.1 ms 延迟
phi1 = 2*np.pi*f1*tau  # 低频 → 小相位差
phi2 = 2*np.pi*f2*tau  # 高频 → 大相位差（可能 >2π）
print(f"{f1}Hz → Δφ={phi1:.2f} rad")
print(f"{f2}Hz → Δφ={phi2:.2f} rad")
print(f"高频超过2π了吗？{phi2 > 2*np.pi}")
```
