# 实验：未来语义预测的轻量化替换

## 来源

[[wiki_low_latency/sources/2024/Tsunoo Causal SSL Semantic 2024]]（arXiv:2412.19248，ICASSP 2025）。

其最干净的结论是 Table IV 的条件对照：

| 场景 | 有语义预测 | 无语义预测 | $\Delta$ |
|---|---:|---:|---:|
| 因果（C1 vs C2） | 2.88 | 2.83 | **+0.05** |
| 非因果（N1 vs N2） | 3.14 | 3.14 | **0.00** |

即：**"预测未来"这条辅助监督的价值，恰好等于因果模型缺失的未来上下文所造成的信息缺口。**

## 假设

这个增益的来源是**信息**（未来音素的延续性），而不是**具体的 token 表示**。
因此可以用一个远超 1024 维码本的轻量目标（帧级 voicing / 能量 / 浊音-清音标志）替代它：

1. **算力**：预测目标从 1024 类 CE 降到 1–2 维 BCE，辅助分支的算力与参数量近乎归零。
   Tsunoo 论文对该分支算力**零量化**，所以这条对比必须自己测。
2. **风险规避**：把"预测音素身份"降级为"预测是否浊音 / 能量高低"，
   把**离散的身份错误**变成**连续量的回归误差**，理论上更能容忍预测偏差，
   从而降低"预测错音素 → 掩蔽依赖错误语义 → 抑制真实辅音"的 false suppression。
3. **可迁移性**：voicing / 能量是**语言无关**的，不需要预训练 SSL 的语音学知识，
   因此可以脱离 WavLM 使用——这对端侧更重要。

## 待验证的关键点

- **[!] 增益能否复现。** 原论文的 +0.05 **无方差、无置信区间、无显著性检验、单次运行**，
  且 PESQ 报告精度为 0.01。**必须在自建条件下先确认 +0.05 可复现**，否则整个实验的前提不成立。
- **[!] 增益是否来自"预测"本身而非"多任务正则"。** 需要设一个**随机目标**的对照臂
  （预测目标与未来无关，如打乱的 voicing）——如果它也涨 0.05，说明增益来自正则而非未来信息。
  这是本实验**最关键的消融**，原论文没有做。
- **[!] 预测距离 $N$ 的作用在轻量目标上是否一致。** 原论文 $N=1$ accuracy 最高（33.7%）但 PESQ 最低（2.81），
  $N=5$ 才最优（2.88），说明**信息量比准确率重要**。若换成 voicing，"预测多远"的拐点会移动到哪里？
- **[!] 低 SNR 下辅助任务是有害还是有益。** 论文只报 VoiceBank+DEMAND 的整体 PESQ，
  没有负 SNR 分层。**本实验必须补这一层**，因为它才是"预测错误 → 抑制真实辅音"的高发区。

## 与库中其他工作的组合可能

- **与蒸馏子群组合**：Tsunoo 的机制是"模型内部预测未来"，蒸馏是"外部 teacher 提供未来"。
  两者都在补因果模型的上下文缺口，但**成本结构完全不同**（前者增加推理时算力，后者只增加训练时算力）。
  可以设计对照：同一 student 骨干，分别用 `未来语义预测 MTL` / `离线 teacher 蒸馏` / `两者都用`，
  比较 PESQ 增益与**推理时算力增量**。这是一个干净的"补上下文缺口的三种支付方式"实验。
  参考：[[wiki_low_latency/concepts/2309.08144-two-step-distillation]]、
  [[wiki_low_latency/concepts/2408.04267-feature-distillation]]、[[wiki_low_latency/concepts/2608.12099-mamba-distillation]]。
- **不能与 PSMSE 直接组合**：PSMSE 不缓存跨帧状态（逐帧无状态映射 + OLA），
  而"预测未来语义"依赖跨帧的上下文连续性；在其上叠加前必须先确认状态语义。
  参考 [[wiki_low_latency/concepts/S2542660526001769-spiking-mamba-streaming]]。
- **与 DPCRN/DCCRN 组合**：Tsunoo 只用 noisy 相位且论文自认这是它与 SOTA 的差距所在。
  把它搬到复数域骨干（[[wiki_low_latency/entities/DPCRN]]、[[wiki_low_latency/entities/DCCRN]]）
  可以同时检验"语义先验"与"相位估计"是否互补或冗余。

## 风险与前置条件

> [!warning] 这个实验有两个前置条件，缺一不可
> 1. **必须先复现 +0.05。** 效应量小且无统计证据，若复现失败，整个方向不成立。
> 2. **必须先建立延迟账本。** Tsunoo 论文没有任何延迟数据，而它的因果 SSL 构造
>    （$c(X)=\{s(X_{\le t})_t\}$，Eq. 5）在流式下是**重算型**（$O(T^2)$ 量级），
>    如果沿用它的 SSL 前端，无论辅助任务多轻，端到端都到不了 2 ms 量级。
>    因此本实验**只借用"预测未来"这一辅助任务的设计原则**，
>    SSL 前端应换成短窗因果前端（见 [[wiki_low_latency/concepts/2204.09911-short-asymmetric-stft]]
>    与 [[wiki_low_latency/concepts/低时延前端与延迟账本]]）。
