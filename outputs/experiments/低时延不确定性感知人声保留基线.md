# 低时延不确定性感知人声保留基线

## 假设

在同一短窗、严格因果和 batch=1 约束下，增加一个低成本的 speech-presence/uncertainty 控制支路，并将其映射为 gain floor 或 attack-release 调制，可以减少低 SNR 下的弱辅音、气声和有声周期过抑制；代价应由 p99 计算与 deadline miss 量化。

## 设计

```text
short causal front-end
  → causal GRU / SlowFast-SSM
  → enhancement head + SPP/uncertainty head
  → gain floor / attack-release modulation
  → causal decoder
```

先做最小基线和逐项增量消融，不同时叠加多个复杂模块。训练参考窗可用于 loss，但部署路径必须只依赖当前/历史输入与缓存状态。

## 主要评估

- 延迟：算法延迟、compute p50/p95/p99、deadline miss、underrun/overrun、warm-up 和 state reset；
- 人声保留：低 SNR 分层的 false-suppression、弱辅音/音节边缘、voiced energy、F0/formant/prosody continuity、ASR WER；
- 质量权衡：PESQ、STOI/eSTOI、SI-SNR，以及 SIG–BAK–OVL 而非只报告单一平均分；
- 部署：batch=1、目标 runtime、峰值 RAM/SRAM、量化精度和长流稳定性。
