# 无参数时间稀疏化 × 脉冲稀疏性

## 假设

PSMSE 把算力压到 0.11 G/s 靠的是**表示层**的稀疏性（spike 事件驱动 + binary convolution），
但它仍在**每个帧**都跑一次完整前向。

RT-Tango 提供了另一条正交的省算力路径：**时间维度**的稀疏化——FRS 按固定间隔推理、中间帧复用上一次的 mask，
零参数、零额外 MAC、非更新帧的 DNN 成本为 0。

两条路径作用在不同的轴上（表示稀疏 × 时间稀疏），理论上可叠加。

## 设计

```text
noisy waveform
  → Conv1D encoder → BinaryConv bottleneck
  → 并行 SMC / SMR（PSMSE 不变）
  → 【新增】FRS 调度器：按 1/2、1/4、1/8 更新率决定是否执行 mask 估计
  → decoder + 输入残差
```

扫描 FRS 更新率 $\{1, 1/2, 1/4, 1/8\}$，记录 MACs–质量曲线。

## 主要评估

- **算力**：per-frame MACs（需先补测）与 G/s，按 FRS 率折算；
- **质量**：PESQ / STOI / CSIG / CBAK / COVL，与 FRS=1 基线逐点对照；
- **连续性**：帧边界不连续性 / 调制伪影——这是本实验最需要新造的指标，
  因为 PSMSE 无跨帧状态、只靠 50% OLA，跳帧复用的风险高于 RT-Tango 的有状态 RNN；
- **对照**：同时跑 learned gating（SkipRNN / TinyLSTM）作为反例，验证 RT-Tango 的
  「高帧率下 learned skipping 不划算」结论是否在 SNN 模型上复现。

## 为什么值得做

这是库中两条**独立省算力路线**的首次交汇。无论结果正负都有信息量：
- 正结果 → 得到「表示稀疏 × 时间稀疏」的可叠加设计；
- 负结果 → 说明 spike 稀疏性与时间稀疏性在效果上重叠（都在利用信号的稀疏结构），
  这本身是一个可写进 concept 页的结论。
