# 空间声学图与图复原定位

## 定义

这是本 `wiki_array/` 里一条清晰的方法分支：「**先把阵列信号变成一张有物理含义的空间图（spatial map），再用（通常是轻量的）学习网络对这张图去噪 / 复原 / 分割，最后从干净的图中读出 DOA 或位置**」。

空间图可以是：

- **SRP-PHAT 功率图**（稳健跟踪、DPD、机械故障、IcoCNN）
- **DAS 波束能量图**（Beamformed 360）
- **球面声强图 / likelihood 图**（DeepWave、SSLIDE、LAM 的 SAM）

## 为什么走这条路

| 对比 | 端到端回归（波形/谱→坐标） | 空间图 + 学习复原 |
|---|---|---|
| 中间表示 | 黑箱 | 可解释的方向—能量分布 |
| 对阵列/房间泛化 | 差，易过拟合 | 图由物理生成，泛化更好 |
| 参数量 | 全局建模，易大 | 局部卷积，可轻量（0.3M 级） |
| 物理先验 | 无 | 内嵌波束成形 / 互相关的物理约束 |

## 分支谱系

```
传统空间图 (SRP-PHAT / DAS / MUSIC)
        │
        ├── DeepWave (2019)         算法展开 + 图信号处理做去模糊成像
        ├── DPD (2020)              直达声 TF 筛选 → 加权 SRP-PHAT
        ├── Robust Tracking (2021)  因果 3D CNN 做时序图跟踪
        ├── SSLIDE (2021)           双 decoder 解耦定位与多径缓解
        ├── Icosahedral CNN (2023)  球面等变几何卷积 + soft-argmax
        ├── Mechanical Fault (2024) U-Net 图复原 + 插值搜索
        ├── Beamformed 360 (2025)   Attention U-Net 分割
        └── LAM (2025)              自监督重建 CSM（SAM 作为中间表示）
```

## 未解决

- **时序关联**：多数方法逐帧独立，运动/轨迹建模弱（Beamformed 360 的 F1 从单源 79 → 两源 68 就是证据）。
- **多源多峰**：单峰 argmax / 质心难扩展多源；与 ACCDOA 多源格式的结合是空白。
- **标签成本**：clean map / IRM / 分割 mask 依赖真值；[[LAM Self-Supervised DOA 2025]] 的自监督重建是一剂药，但尚未打通到有监督定位。
- **域差距**：模拟训练的图在真实混响 / 阵列下精度掉一档。
