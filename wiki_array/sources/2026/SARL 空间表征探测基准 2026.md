# SARL — Probing Spatial Structure in Pretrained Audio Representations

> Chen, Ding, Roman & Bello（NYU MARL，三位共同一作），Interspeech 2026 (accepted)。**一套诊断「空间预训练模型到底编码了哪些空间信息」的可复现 probing 基准**，而不是新的端到端 DOA 系统。
> 原文与代码：[arXiv:2606.05544](https://arxiv.org/abs/2606.05544)｜[GitHub](https://github.com/chuyangchencd/SARL)｜本地 PDF：`outputs/reports/2026-09-08-frontier/localization/03_sarl_benchmark_2606.05544v2.pdf`

```yaml
- 论文: SARL 空间音频表征探测基准 (2026)
  ├── 要解决什么问题: 预训练空间音频编码器"编码了哪些空间信息"不可知；现有评测是端到端任务式，混淆了表征质量与下游架构/监督
  ├── 核心方法: 合成受控单源空间场景 + 冻结 backbone 统一线性 probing（7 个源/房间任务）+ 配对扰动敏感度分析
  ├── 属于哪个分支: 表征诊断/探测基准（probing benchmark），不是 DOA 系统本身
  ├── 输入/输出: 音频(mono/stereo/binaural/FOA，重采样到各 encoder 原生率) → mean-pooled scene embedding → 线性 probe 输出 azimuth/elevation/distance/class/RT60/volume/shape
  ├── 关键trick: 冻结 backbone 只训线性层隔离表征质量；分箱 + Gaussian soft label + 基线归一化 φ(x;b)=(x-b)/(1-b)；配对敏感度 Δ=1-(s-μ)/(1-μ)
  ├── 数据集: 合成（ESC-50/MUSAN/UrbanSound8K 7 类×4000 + AudibleLight 源级 RIR + PyRoomAcoustics 房间级 RIR）
  ├── 对比了谁: 13 个 encoder（A-MAE/SELD-S/EnCodec/SR-VAE/BANC/GRAM-B/S-AST/SFD/W-JEPA/AVSA/EINv2/SELD-F/GRAM-F）
  ├── 性能上限: 无单一绝对 SOTA——全报告为相对随机基线的归一化提升；稳健结论是 source 因素 > room 因素、FOA 整体最强
  ├── 参数量: 不适用（评测既有模型；线性 probe 仅单层，由各 encoder 嵌入维决定、未单独报告）
  ├── 消融关键发现: 源-房间 gap 系统性存在；FOA 对 elevation/room 优势最明显；监督 SELD azimuth 强但 room 弱；SSL(GRAM) 更均衡；敏感度不单调跟踪 probing
  ├── 遗留问题(你的机会): 合成单源、mean pooling(丢时/频) 、线性 probe(只测线性可访问)、偏离原训练分布、pre-pooled feature 未测
  └── 跟哪篇像: HEAR/SUPERB/X-ARES/MARBLE(表征基准但单声道语义向) + 空间任务基准(DCASE/LOCATA)的"probing 化"
```

## 研究任务与对象

| 维度 | 详情 |
|------|------|
| **任务** | 表征探测（probing）：冻结 embedding 中哪些空间因素可被**线性**解码（不训练定位器本身） |
| **7 个任务** | 源级：azimuth / elevation / distance / 事件类别(class)；房间级：RT60 / 房间体积(volume) / 房间形状(shape) |
| **输入格式** | mono / stereo / binaural / FOA（first-order Ambisonics），同一场景等条件渲染以便跨格式对比 |
| **被测模型** | 13 个 encoder，跨 3 种训练范式（SSL / 监督 / codec；见 §三 表 1） |
| **数据** | 全合成：干信号 7 类事件（ESC-50/MUSAN/UrbanSound8K）×4,000，转 mono、24 kHz、RMS −24 dBFS、10 s；源级 RIR=AudibleLight+Gibson mesh；房间级 RIR=PyRoomAcoustics |
| **评分** | 连续=归一化 MAE `1−MAE/R`；类别=macro-F1；三随机种子平均；跨任务用基线归一化 φ(x;b) 聚合 |

## 一、动机（Motivation）

1. **空间音频正在变成通用表征的载体**：沉浸式媒体、机器人、具身 AI、声学场景理解都要靠多通道信号中的方向、距离、房间线索；近年涌现大量在 binaural 与 ambisonic 录音上预训练的 spatially-aware 模型。
2. **但这些模型"学没学到空间"没人说得清**：评估几乎都是 pipeline-dependent 且 end-to-end，无法把「表征质量」从「下游架构 / 监督信号 / 训练策略」里分离出来。
3. **现有基准的两个缺口**：
   - HEAR、SUPERB、X-ARES、MARBLE 等表征基准**主要针对单声道、语义任务**，空间信息覆盖有限；
   - DCASE multichannel、LOCATA、CHiME、REVERB 等空间/语音基准测的是**端到端系统精度**，把表征质量与下游组件混在一起，且对被测空间因素几乎没有控制。
4. **主张**：空间表征评估应从「task-centric benchmarking」转向「probing-based analysis」——冻结 embedding、只训轻量线性分类器，问「哪些属性是可解码的」，从而==架构无关==地跨 encoder 比较，隔离表征质量。

## 二、前人局限（Limitation → Gap）

| 方法/基准 | 能做 | 做不了 |
|------|------|--------|
| HEAR / SUPERB / X-ARES / MARBLE | 跨模型、冻结 backbone 的统一表征评测 | 单声道、语义任务为主，几乎不覆盖方向/距离/房间等空间因素 |
| DCASE multichannel / LOCATA / CHiME / REVERB | 在多通道真实设置下测定位/增强/去混响/识别 | 测端到端系统，混淆表征与下游架构/训练；对空间因素本身无独立控制 |
| 通用 probing（NLP/视觉等域，库外） | "哪些属性可恢复"的成熟方法论 | 缺少面向空间音频的定制版本（受控空间因素 + 源/房间分离） |

> **Gap**：缺一个「统一线性 probing 协议 + 独立可控的源/房间因素」的基准，来解耦「不同输入格式、不同训练范式学到的表征分别编码了什么空间信息」。这个 gap 至今没被补上，不是算力/数据卡住，而是==评测视角==的问题——大家习惯测下游精度，而不是测表征本身。

## 三、核心 trick（⭐ 分级）

**底线：这不是"叠十个 trick"的方法论文，而是"一个评测方法论 idea + 三个支撑设计"。**

### Trick 1（⭐⭐⭐ 最关键）：统一线性 probing 协议

```
训练好的 audio encoder（13 个）→ 冻结全部权重
     帧级/token embedding ——mean pooling——→ scene-level embedding z
     z → 单个线性分类器（Adam lr=1e-4 + cosine decay，20 epoch）
```

- 只训一个线性层，问「空间因素是否已**线性可访问**于冻结 embedding」。这是基准的灵魂：architecture-agnostic，把表征质量从下游容量/微调里彻底剥离，跨 encoder 排名才有意义。

### Trick 2（⭐⭐）：受控合成数据 + 源/房间因素独立控制

- **源级任务**用 AudibleLight（ray-traced）+ Gibson mesh 渲染 RIR，控制 azimuth ∈ [−180°,180°]、elevation ∈ [−60°,60°]、distance ∈ [0.5,2.5] m。
- **房间级任务**用 PyRoomAcoustics（image-source）渲染，RT60 ∈ [0.1,3.0] s、volume log-uniform ∈ [60,2500] m³、shape 4 类（cube/flat/corridor/rectangular）。
- 每条管线各产 **12,000/3,600/3,600** train/val/test RIR，且 **sources 与 rooms 都跨 split 分离**——测的是"泛化到未见声源/未见房间"，不是记忆。同一场景在 stereo/binaural/FOA 下**等条件渲染**，保证跨格式可比；采样确定性种子、标签近似均匀。
- 每 epoch 渲染 **15,000/3,000/3,000** 个 scene（干信号 + RIR 在线卷积配对），避免固定集合导致过拟合。

### Trick 3（⭐⭐）：分箱 + Gaussian soft label + 基线归一化

- 连续变量离散为线性等宽 bin：azimuth 36、elevation 12、distance 20、RT60 29；类别：class 7、volume 5 个 log bin、shape 4。连续变量用真 bin 为中心的 **Gaussian soft label**（比 one-hot 平滑），类别用 one-hot。
- 评分：连续 = `1−MAE/R`（R=变量全范围），类别 = macro-F1，三随机种子平均。
- 聚合：$\phi(x;b)=(x-b)/(1-b)$，b=随机预测器分数，把**随机基线映射到 0、完美映射到 1**——不这么做，"azimuth 的 0.6"和"shape 的 0.6"根本不可比。

### Trick 4（⭐）：配对扰动敏感度分析（probing 的几何补充）

- 固定其余因素、只改源或只改房间，得配对场景 $x,x'$，算 cosine $s=\cos(f(x),f(x'))$；经随机对基线 $\mu$（10,000 随机对估计）校正：$\Delta(x,x')=1-(s-\mu)/(1-\mu)$。
- 用途是刻画 embedding 对哪类变化"更敏感"，但它**不等于** probing 性能——作者自己用这个指标明确打了预防针：强模型的 $\Delta$ 未必大（见 §四）。

## 四、实验对照里哪个最关键（相当于消融）

> [!warning] 结论边界（务必先读）
> 这是**合成、单源**空间场景；**mean pooling** 可能抹掉时/频层的定位线索；**线性 probe** 只能测"线性可访问"的信息。以上任何一条都决定了：**不能拿图中的单一模型排序去外推成真实定位 SOTA，也不能直接据它选机器人 DOA 系统**。[PDF §5]

SARL 是基准不是方法，没有"去掉某个模块掉多少"的传统消融；最接近"消融"的是它对**输入格式**与**训练范式**的分组对照，以及**敏感度与 probing 的对齐性检验**。其中最关键、最可迁移的结论是第一条：

1. **源-房间 gap 系统性存在（最关键）**：在**每个** encoder 上，源级因素（localization + semantic）的归一化提升都高于房间级因素（Fig. 2）。作者的结构性解释：源因素在单次录音里局部、直接可见；而 volume/geometry 等全局房间属性需要多个 source-receiver 位置才能辨识。这是全文最稳健、最不依赖具体模型的诊断结论。
2. **输入格式**：binaural/FOA > mono/stereo；FOA 对 **elevation 和房间属性（RT60/volume/shape）** 优势最明显，提示球谐基是更 informative 的空间基；mono 的 A-MAE 在房间任务和多数源任务仍有竞争力，**唯独 azimuth 失败**——说明混响衰减/谱结构携带部分房间线索，但单声道无法恢复方位（Fig. 1 第 1 列、§4.1）。
3. **训练范式**：监督定位模型 azimuth 最强，但房间属性（尤其 SELD-S/SELD-F 的 RT60/volume/shape）弱——定位监督让表征偏重方向、丢弃全局声学上下文；SSL 在源/房间间更均衡；codec 整体最弱。SSL 内部：GRAM-B/F（在输入空间直接重建 masked spectrogram）强，W-JEPA（latent prediction）/SFD（spatial feature distillation）较弱或不稳定（Fig. 1 第 2 列、§4.2）。
4. **敏感度 ≠ 好性能（方法论护栏）**：几乎所有 encoder 的源扰动 $\Delta$ > 房间扰动 $\Delta$，与 probing 的源-房间 gap 对齐；但**敏感度大小不单调跟踪 probing**——强模型 GRAM-F、EINv2 总体敏感度反而更低，弱模型 SFD、BANC 反而变化更大。含义：更强模型把空间因素编码得更稳定结构化，而非靠大幅 embedding 抖动（Fig. 3、§4.4）。

## 五、Future Work / 遗留问题

### 论文自认（PDF §5）

1. 仅**合成、单源**环境，简化了真实声学复杂度。
2. 线性 probe 只测**线性可访问**信息；mean-pooled 抹平了各模型时序/频谱分辨率的差异——**pre-pooled（中间层）特征待补测**。
3. 模型在**偏离原训练分布**的条件下被测（其原训练集与 SARL 合成域不同）。
4. 扩到**真实录音、多源环境、替代 probing 策略**是重要方向。
5. 该框架可作为开发空间感知表征模型的**诊断工具**。

### 我读出的隐藏问题

- **负向结论要谨慎**：「线性 probe 解不出」≠「没编码」——可能编码了但需要非线性头、或信号停留在 mean pooling 抹掉的帧/频层。SARL 只证"线性可访问性"，不证"是否编码"。
- **分箱精度决定可解码上限**：azimuth 只有 36 bin（量级 ~10°/bin），probe 再强也不可能细于分箱粒度；Gaussian soft label 的宽度是未充分讨论的超参，会直接影响归一化分数。
- **合成 RIR 的域差**：AudibleLight 是 ray-traced（几何最忠实但仍仿真）、PyRoomAcoustics 是 image-source 近似；「房间因素比源因素难解码」的结论部分可能是**渲染模型本身的阶次/简化**造成的，未必完全迁移到真实房间。
- **脚本可复现性缺口**：原笔记已核实——论文未固定各被测模型 checkpoint、渲染实现 commit 或硬件/时长，复现需在仓库锁定版本（PDF footnote 1）。
- **"源-房间 gap"缺少因果归因**：它可能是数据（单源、单一 source-receiver 配置）造成的，也可能是优化目标造成的；作者给了结构解释，但没做消融来分离两者。

*SARL 的价值不在"谁排第一"，而在把"这个预训练模型学到了什么空间结构"从漫天端到端精度里剥离出来、做成可复现的评测协议。它是 probe 主义（同 NLP 的 probing 传统）在空间音频上最干净的当代表达；读它 = 学会区分"表征编码了什么"与"系统跑到了多少分"。*
