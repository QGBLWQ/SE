# 软体藤蔓机器人分布式声定位 — Distributed Acoustic Localization Array Deployed Using a Soft Everting Vine Robot

> Lorca Godoy, McFarland, Val, Alvarez Valdivia, Hanson & McGuinness (Notre Dame / MIT LL), IROS 2026。把软体藤蔓机器人（soft everting vine robot）生长过程变成一套**可重构、几何已知**的分布式麦克风阵列，用几何 SRP-PHAT 在远场 DOA 与近场位置之间切换。
> 原文与本地文件：[arXiv:2607.20392](https://arxiv.org/abs/2607.20392)｜本地 PDF：`outputs/reports/2026-09-08-frontier/localization/04_vine_robot_acoustic_localization_2607.20392v1.pdf`

```yaml
- 论文: 软体藤蔓机器人分布式声定位 (2026)
  ├── 要解决什么问题: 灾后狭小/无地图空间中，用可生长软体机器人沿身体部署并重构麦克风阵列来定位受害者声音（系统/部署实验，非新 DOA 算法）
  ├── 核心方法: 5 麦分布式阵列 + 几何 SRP-PHAT（近场球面波位置搜索 / 远场平面波角度搜索共用同一框架）
  ├── 属于哪个分支: 机器人听觉 × 软体机器人传感部署；SRP-PHAT 束扫描（beamforming 家族），纯解析、无学习
  ├── 输入/输出: 44.1 kHz 白噪声、2048 采样帧(~46.6 ms) / 远场方位 DOA 或近场 xy 二维位置(3×3 m、5 cm 网格 = 3600 候选点)
  ├── 关键trick: 生长式重构阵列 + 已知几何(PhaseSpace 光学追踪)的 TDOA 模型 + 远/近场只换候选集；算法本身零新意，创新在"部署与几何"
  ├── 数据集: 自采实验室数据（SoundCore2 白噪声源、标准实验室、恒定 45 dB(A) 底噪），无公开数据集
  ├── 对比了谁: 系统内自对比（3 安装位 × 4 几何 × SNR/距离/麦数扫描）；MUSIC/ESPRIT 仅定性排除，未数值对比
  ├── 性能上限: 圆阵远场平均方位误差 1.1°(±3.9)、近场 0.034 m(±0.042)；生长到 3 麦时位置误差降 91.0%
  ├── 参数量: 无学习参数（纯 DSP 几何方法；未报告运行时）
  ├── 消融关键发现: 圆阵 aperture 最优；共线单 fiber 前后镜像歧义是最大失效源(45.9°)；安装位在远/近场结论反转（体内 vs 外壁）
  ├── 遗留问题(你的机会): 白噪声+实验室二维，未验真人声/混响/自噪；必须实时知道麦位（非"免校准"）；形状感知与主动部署控制未闭环
  └── 跟哪篇像: 经典 SRP-PHAT(DiBiase 2000) 的直接应用 + 软体机器人分布式传感部署(Gruebele 2021 / 藤蔓机器人线)
```

## 一、研究任务与对象

| 维度           | 详情                                                       |
| ------------ | -------------------------------------------------------- |
| **任务**       | 声源定位（远场方位 DOA + 近场二维位置），目标灾后 USAR 受害者定位                  |
| **核心问题**     | 软体机器人身体柔顺、几何随生长改变，如何把"生长路径"变成可用且可量化的麦克风阵列                |
| **方法类型**     | 几何 SRP-PHAT（纯解析），无机器学习、无训练                               |
| **阵列**       | 5 麦 ICS43434（TDK InvenSense），Teensy 4.1；沿弧长每 30 cm 一个    |
| **机器人**      | 直径 20.3 cm 展平、LDPE（标称厚度 0.1 mm）everting vine robot       |
| **安装位（3 种）** | 增压体内 / 未翻出的 tail 内 / 外壁                                  |
| **几何（4 种）**  | 单 fiber（直线）、双 fiber（双线，横向 14 cm）、圆（半径 33 cm）、正弦（收缩率 80%） |
| **输出**       | 远场：均匀角度网格取峰 → 方位角；近场：3×3 m、5 cm 网格（3600 候选点/帧）取峰 → xy 位置 |
| **指标**       | 每条件 300 连续帧的 mean absolute angular/position error ± std  |
| **真值**       | PhaseSpace 光学运动捕捉（主动 LED 标记）测出每个麦与声源的三维位置                |

## 二、算法与系统（原文公式）

对每对麦 $(m_k, m_l)$，GCC-PHAT 为（Eq. 1）：

\[R_{m_k m_l}(\tau)=\int \frac{M_k(\omega)M_l^*(\omega)}{|M_k(\omega)M_l(\omega)|} e^{j\omega\tau} d\omega\]

候选位置 $x$ 的理论 TDOA（Eq. 2）：

\[\tau_{kl}(x)=\frac{\lVert x-x_k\rVert-\lVert x-x_l\rVert}{c}\]

其中 $x_k,x_l$ 是**已知的**麦克风位置，$c$ 为声速。SRP-PHAT functional 对所有非重复对累加（Eq. 3），源位置取其最大（Eq. 4）：

\[P'_n(x)=\sum_{k=1}^{M}\sum_{l=k+1}^{M} R_{m_k m_l}\!\left(\tau_{kl}(x)\right),\qquad x_s=\arg\max_{x\in G} P'_n(x)\]

> 以上即标准 SRP-PHAT（DiBiase 2000），论文无算法改动。详见 [[SRP-PHAT]]、[[GCC-PHAT 广义互相关]]、[[TDOA 到达时延差]]。

**远/近场共用同一框架的切换点在延迟模型与候选集**：远场退化为平面波，延迟只依赖 DOA（Eq. 5）：

\[\tau_{kl}(\theta)=\frac{(x_k-x_l)\cdot\hat u(\theta)}{c}\]

近场用 Eq. (2) 的球面波延迟，在 3×3 m 栅格上搜位置；远场在均匀角度网格上输出 DOA。这是"机器人趋近声源时可从方位判定无缝过渡到位姿估计"的关键设计。

**为什么选 SRP-PHAT 而非 MUSIC/ESPRIT**：SRP-PHAT 能处理不规则、随生长改变的阵列几何（只要每个麦位已知）；MUSIC 需要准确的阵列 manifold 与源数先验，软体柔性几何会造成 manifold 误差；ESPRIT 要求成对平移不变子阵（doublets），生长路径无法保证。代价是网格搜索随 $N_{cand}$ 线性增长。噪声由 A 加权声压算（Eq. 6）：$\mathrm{SNR}=10\log_{10}\!\big((P_{total}-N)/N\big)$，环境底噪恒定 45 dB(A)。

## 三、为什么这么做？（动机）

1. **现实需求**：USAR（urban search and rescue）塌方现场杂乱、危险、无已知地图；软体机器人可灵活穿行，而刚性传感器会抑制柔顺运动。可生长的藤蔓机器人"从尖端外翻生长"，天然能成为沿途铺开的连续传感器阵列。
2. **先前软体机器人的侦察盲区**：已有 active scope camera / RoBoa 等只把传感器放在尖端，关注的都是机械设计、运动和遥操作，**从未系统研究过"把麦克风沿身体分布式部署 + 机器人形变几何如何影响声定位"**。作者声称"没有工作研究过通过机器人来部署并重塑可转向麦克风阵列"。
3. **方法选型的工程根据**：软体阵列几何不可控、随生长而变，因此需要一种"知道几何就能定位、无需校准 manifold"的解析方法——SRP-PHAT 正是这类下限最低的选择，让本文能把注意力集中在部署几何的系统表征上。

## 四、之前的人怎么做不了？（Limitation → Gap）

作者的定位不是"提出比 SRP-PHAT 更准的算法"，而是"在软体机器人上把 SRP-PHAT 部署出来并搞清设计空间"。因此这里的"gap"是**系统/部署层面**的：

| 方法/路线 | 能做 | 做不了 / 不适配软体藤蔓阵列 |
|------|------|--------|
| 传统固定麦克风串（rubble 周围布麦） | 已有语音/敲击检测 | 阵列几何固定，无法随机器人延伸进入废墟深处 |
| SRP-PHAT | 任意几何、无训练、可解释、抗混响 | 网格搜索成本高（$O(N_{cand})$），且**依赖麦位已知** |
| MUSIC | 超分辨 DOA | 需要准确 manifold + 源数先验；柔性/被遮挡阵列 manifold 误差大 |
| ESPRIT | 闭式、无网格搜索 | 要求成对 doublets 平移不变子阵，生长几何无法保证 |
| 已有软体机器人（scope camera / vine robot） | 尖端传感、机械设计成熟 | 传感器只在尖端，未做分布式声阵列，也未量化几何/安装位/距离对定位的影响 |

> **Gap 为什么至今没解决**：软体机器人本身形状不确定 → manifold 难建模、doublets 难保证；同时"边生长边定位"需实时知道每个麦的空间位置，此前缺少把 shape sensing 与声定位联动的系统。本文绕开最难点——用 PhaseSpace 光学追踪离线得到麦位，只回答"截面 A：几何/安装/距离如何影响精度"。

## 五、核心 trick 是什么？

**底线：没有新算法 trick——这是一篇系统/部署实验论文。** 值得学的是"把部署变量当作第一公民来测"的思路，以及远/近场切换的框架复用。

### Trick 1（⭐⭐⭐）：生长式、几何已知的可重构阵列本身

核心贡献是把软体机器人的**身体长度当作可变孔径**：藤蔓边生长边多翻出麦克风，阵列从共线/小孔径逐渐逼近圆/正弦/双线几何。配合 PhaseSpace 光学追踪每个麦的位姿，Eq. (2)/(5) 的几何 TDOA 只要有坐标就能算，无需学习 manifold。真正"有用"的不是算法，而是**"部署 + 已测几何"**这点。注意反过来：这同时也框定了它**不是免校准**——没有麦位坐标，(2) 式就无从算起。

### Trick 2（⭐⭐）：远/近场只换候选集与延迟模型

同一个 $P'_n(\cdot)$ （Eq. 3-4），远场扫角度网格、近场扫 3×3 m 位置栅格。这使系统在接近声源时能从"方位判定"无缝滑到"位姿估计"，是面向搜救"先找到方向、再逼近定位"流程的自然抽象。

### Trick 3（⭐）：PHAT 白化 + 全对累加（拿来即用）

PHAT 白化幅度、只留相位，抗谱染色与混响；对所有 $\binom{M}{2}$ 对累加提升空间选择性。这些都是 SRP-PHAT 标准砖块，非本文贡献。

### Trick 4（⭐）：系统的多轴表征 + 生长闭环演示

用 300 帧/条件 + mean±std，系统扫过安装位 × 几何 × SNR × 距离，并在 §V 边生长边定位（半圆+末端线性化的真实外翻序列），证明 3 麦已够初步近场定位。这是把"无法归一化的设计空间"变成可比较实验的方法学贡献。

## 六、实验里哪个消融最关键？

本文无 NN 消融，"消融"等价于四组系统表征。按影响大小排序，**最关键的是阵列几何（圆 vs 共线）**：

| 实验（原图表） | 关键结果 | 判读 |
|------|------|------|
| **几何·远场**（Fig. 6，2 m、13 dB） | 单 fiber **45.9°±52.2** → 双 fiber 5.6°±27.0 → 正弦 2.9°±16.7 → 圆 **1.1°±3.9** | 共线的前后镜像 TDOA 歧义是最大失效源；圆阵均值和方差同时最低（std 比正弦小 4.3×） |
| **几何·近场**（Fig. 7，0.5 m、13 dB） | 圆 **0.034±0.042 m**；双 fiber 0.083±0.087；正弦 0.079±0.094 | 圆比双 fiber 好 58.8%、比正弦好 56.6%；aperture 是主导因素 |
| **安装位**（Fig. 4-5） | 远场（2 m，SNR>0 dB）增压体内 **0.51°** < 外壁 1.49° < tail 10.4°±4.6；近场（0.75 m）反转：外壁 **0.17±0.13 m** < 体内 1.012±0.788 < tail ≈2.3 m（网格边界饱和） | **同一安置在远/近场结论反转**：均匀 LDPE 衰减在远场保留相位差、在近场却抹掉波前曲率 |
| **距离**（Fig. 8，圆、60°） | 0.5 m→**0.03 m**(RMSE 0.056)、0.9 m→0.198(0.364)、1.4 m→0.279(0.423)；>1.5 m 后非单调 | 近场可用范围约 0.5–1 m（mean<0.4 m）；>1.5 m 时 mean 不再有意义（见 §七局限） |
| **生长演示**（Fig. 9） | 2/3/4/5 麦位置误差 **2.4 / 0.216 / 0.299 / 0.281 m** | 第 3 麦降误差 **91.0%**；4/5 麦边际且非单调（末端线性化抵消孔径收益） |

> [!note] 结论边界（务必写进任何引用）
> 全部结果出自**白噪声源 + 标准实验室 + 二维同高** + 光学追踪提供麦位。这是"部署可行性"证据，不是真实语音搜救的现场验证；也不等同于"免校准"定位（见 §七）。圆阵的 1.1°/0.034 m 只在这个特定设置内成立，不可外推到混响/人声/三维。

## 七、还剩什么问题没解决？（Future Work / 遗留）

**论文自认的局限**：

1. 当前只用了**解析方法**；学习/估计的 array manifold（含卷积法 Diaz-Guerra 2020 [27]）是"有希望的扩展"。
2. 受控评测**尚未覆盖真实搜救条件**：混响、clutter、自噪（电机/致动器）、非平稳信号（真实人声/敲击）。
3. **没有做主动部署控制**：作者设想未来用控制策略主动 steer 机器人去细化位置估计。
4. 均匀 30 cm 布麦在更长机器人上会撞上**数据/供电上限**；需定制"高频数据率 + 轻量"传感器 [28]。

**我读出的隐藏问题**（非论文自认，需读者自证）：

- ⚠️ **"uncalibrated/arbitrary geometry"的措辞与实测矛盾**：论文 Related Work 称 SRP-PHAT 优势是"任意、未校准阵列几何"，但 Eq. (2) 明确需要 $x_k,x_l$（已知麦位），实验全靠 PhaseSpace 光学追踪喂位置——这在塌方现场不可得，必须靠 shape sensing（论文族里有 IMU shape sensing [15]，但本文没有把 shape sensing 与声定位闭环）。**如实写应为"免 manifold 校准，但必须实时已知几何"**。库内 [[SRP-PHAT]] 页也记录"需要精确阵列几何（3 mm 扰动降 ~5%）"，可交叉印证。
- ⚠️ **30 cm 间距的高频空间混叠无人讨论**（我的推断，非论文结论）：白噪声为宽带，30 cm 间距的 λ/2 截止频率约 $c/(2d)\approx 572$ Hz，即几乎整个宽带频段都违反空间 Nyquist；圆阵孔径 33 cm 也意味着麦间距随对变化（0~66 cm）。论文把单 fiber 失效全归给前后歧义，未单独量化混叠随频率/几何的贡献。见 [[空间混叠 Spatial Aliasing]]。
- **生长演示后期帧数递减**（4/5 麦仅 343/278 帧），4 麦 vs 5 麦的差异在统计上不确定（论文自认），不宜据此读成"多麦单调有益"。
- **只报 mean±std，无逐帧分布/分位数**：tail 近场 ~2.3 m 与网格边界饱和、>1.5 m 的"均值下降"是截断/高方差伪影，需要分布图才能进一步诊断，但原文未给。

*这篇的价值不在算法，而在于把"软体机器人身体 = 可变孔径阵列"从想法做成可量化实验，并用圆阵/外壁/0.5–1 m 近场这些规律性发现框出了实际可行区间。读它的正确姿势：当作"部署几何如何吃掉定位精度"的一手实证，而不是一个新的定位器。理解这篇 = 理解为什么 [[SRP-PHAT]] 这种"知道几何就能干活"的解析法，恰恰是软体/形变阵列最短路径的上限——同时也正是它对实时 shape sensing 的隐性依赖所在。*
