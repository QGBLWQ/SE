# IPDnet — A Universal Direct-Path IPD Estimation Network for Sound Source Localization

> Wang, Yang & Li, TASLP 2024。IPDnet 不直接把混响语音映射成角度，而是从多通道复数 STFT 中估计每个声源的**直达路径通道间相位差（DP-IPD）**；之后结合已知阵列几何，与理论方向模板做内积匹配得到 DOA。其骨干是**全频带 BLSTM → 窄频带（B）LSTM 交替堆叠**的 Full-Narrow blocks，并扩展到多声源轨与未见麦克风阵列。
>
> 原文：[arXiv:2405.07021](https://arxiv.org/abs/2405.07021)｜本地 PDF：`raw/articles/2405.07021_IPDnet.pdf`｜本地 arXiv 源码：`raw/articles/2405.07021_IPDnet_source/bare_jrnl_new.tex`｜官方实现：[Audio-WestlakeU/FN-SSL](https://github.com/Audio-WestlakeU/FN-SSL)

```yaml
- 论文: IPDnet (2024)
  ├── 要解决什么问题: 噪声、混响、重叠且移动的多声源中，如何提取可靠空间线索；并让一个模型迁移到不同麦克风数和阵列拓扑
  ├── 核心方法: 直接输入多通道复数 STFT，以 Full-Narrow 交替 LSTM 网络回归多轨 DP-IPD；用几何模板内积把 DP-IPD 转成 DOA
  ├── 属于哪个分支: 深度 SSL 的“物理中间表征回归”路线（不是端到端角度分类，也不是传统 SRP 扫描）
  ├── 输入/输出: 多麦 STFT 的实部+虚部 / 每声源轨、每个参考麦对的 cos/sin(DP-IPD) 向量，再输出方向谱与 DOA
  ├── 关键trick: FB→NB 交替（频率相关性+每频点时序）；多轨 DP-IPD + 帧级 PIT；静音目标用 DP-IPD 流形均值而非零向量；可变阵列的麦对共享网络+均值池化通信
  ├── 数据集: gpuRIR+LibriSpeech+扩散噪声模拟；LOCATA Benchmark2/DICIT 真实录音（至多2声源）
  ├── 对比了谁: SRP-DNN、SALADNet、SALSA-Lite、SE-Resnet；LOCATA 另比 Cross3D、IcoDOA
  ├── 性能上限: 消融的2麦设置，IPDnet 在5°容差为 MDR/FAR/MAE=17.1%/16.8%/1.6°；LOCATA 未见12麦阵列可做方位+俯仰定位
  ├── 参数量: 原文该2麦消融配置 0.7M、19.4 G/s；参数少但帧/频率独立重复运行，计算并不低
  ├── 消融关键发现: 去 Full-band 最伤（5° MDR 17.1%→64.4%）；去 Narrow-band 也退化（→19.3%）；两者不可互替
  ├── 遗留问题(你的机会): 仅模拟训练，存在 sim-to-real；高 FLOPs；最多2源假设；可变阵列通信采用均值池化，有信息瓶颈；相位绕回/空间混叠不可由网络从根本消除
  └── 跟哪篇像: FN-SSL 2023 的多麦/多源/可变阵列扩展；借鉴 FullSubNet/SpatialNet 的全频带—窄频带建模思想
```

## 一、研究任务与对象

| 维度 | 详情 |
|---|---|
| **任务** | 0–2 个移动声源的帧级声源定位（在线或离线）；方位角为主，3D 阵列时也测俯仰角 |
| **核心对象** | 直达路径相位差 DP-IPD，而非带混响的观测 IPD，也不是直接回归 DOA |
| **固定阵列版** | 对训练/测试均固定的 (M) 麦阵列，直接联合处理所有通道 |
| **可变阵列版** | 训练时随机采样阵列，测试时可处理未见的麦数、间距及拓扑 |
| **最大活动源数** | 实验中 (K=2)；用两条输出轨容纳 0、1 或 2 个活跃声源 |
| **输入** | 16 kHz 音频的 STFT 实部/虚部；512 点窗（32 ms）、256 点 hop（16 ms） |
| **输出周期** | 每 12 帧，即约 192 ms 输出一次定位 |
| **DOA 解码** | 预测 DP-IPD 与每个候选方向的理论 DP-IPD 模板做内积，最大值对应 DOA |

## 二、数学主线：为什么“预测相位差，再匹配方向”可行？

以参考麦 $r$ 和另一支麦 $m$ 为例。远场自由声场中，方向 $\theta$ 对应的直达路径复数 DP-IPD 模板为：

$$
\widetilde B_{m}(f,\theta)=\exp\!\left(-j\,2\pi v_f\frac{d_m\cos\theta}{c}\right),
$$

其中 $v_f$ 是频率、$d_m$ 是该麦对间距、$c$ 为声速。它的实部和虚部就是
$\cos(\mathrm{DP\text{-}IPD})$ 与 $\sin(\mathrm{DP\text{-}IPD})$。

IPDnet 学习从含噪、混响、多源的复数 STFT 中预测这个向量。推理时，对每一个候选方向预先算好同样的模板；预测向量和哪一个模板内积最大，就选择哪一个方向：

$$
\hat\theta_k=\arg\max_{\theta_i}\frac{1}{M-1}\sum_{m=2}^{M}
\widehat{\mathbf q}_{1,m,k}^{\mathsf T}\mathbf q_{1,m}(\theta_i).
$$

**关键分工**：神经网络负责困难的“从污染信号恢复直达路径空间特征”；阵列几何负责简单且可解释的“特征 → 方向”映射。因此测试时只需重算新阵列的模板，网络本身不必为每个阵列重新学习角度坐标。

> [!example] 两麦直观例子
> 若同一方向在 1、2、3 kHz 对应一组相位模式，网络不必直接说“这是 30°”，而是先输出这组干净模式；已知 8 cm 麦距时，系统拿它与所有方向的理论模式逐一比较。这也解释了 IPDnet 为什么比直接角度回归更容易迁移到新阵列。

## 三、整体架构：确实是 FB→NB 的交替融合

```text
多通道复数 STFT（每通道实部+虚部）
                 │
                 ▼
       Full-Narrow Block × 2
       ┌─────────────────────────────────────────┐
       │ Full-band BLSTM：每一帧沿“频率轴”处理     │
       │   → 学跨频率相位相关性 / TDOA 的频率规律   │
       │                 ↓                       │
       │ Narrow-band (B)LSTM：每个频点沿“时间轴”处理│
       │   → 学该频点的空间线索与随时间的轨迹      │
       │                 ↓                       │
       │ Skip connection：拼回原始 STFT，防止另一轴│
       │                  的线索在变换时被冲淡      │
       └─────────────────────────────────────────┘
                 │
                 ▼
      3 层 2D Conv + 2 次时间平均池化（分离源/麦对）
                 │
                 ▼
每个源轨 × 每个参考麦对：实部+虚部 DP-IPD 向量
                 │
                 ▼
      与已知阵列、候选角度的 DP-IPD 模板内积 → DOA
```

### Full-band 与 Narrow-band 各自做什么？

![[语音定位+语音增强/wiki_array/assets/IPDnet-Full-Narrow-architecture.png]]

| 模块                      | 运算方向             | 捕捉的线索                                    | 为什么不可少                        |
| ----------------------- | ---------------- | ---------------------------------------- | ----------------------------- |
| **Full-band BLSTM**     | 固定一帧，沿频率序列       | 同一 TDOA 下 DP-IPD 随频率的关联；可借强直达声频点帮助弱直达声频点 | 单频点无法判断相位是否被混响污染，跨频率规律提供物理一致性 |
| **Narrow-band (B)LSTM** | 固定一频点，沿时间序列      | 单个频带的跨麦空间特征及移动声源的时间演化                    | 声源运动、活动/静音切换与局部时频可见性都需要时间上下文  |
| **Skip connection**     | 每层均拼接变换后的原始 STFT | 防止 FB 处理稀释局部窄带线索，或 NB 处理遗失跨频率模式          | 保留两种归纳偏置                      |

> [!example] 小数据流动：形状如何变化
> 取一个玩具输入：2 支麦克风、3 个时间帧、4 个频率 bin，即
> $X\in\mathbb{C}^{2\times3\times4}$。
> 对 Full-band 而言，每个时间帧取出长度为 4 的频率序列，因此得到 3 条序列；经过 Narrow-band 后，每个频率 bin 沿时间轴取长度为 3 的序列，因此得到 4 条序列。经过卷积与池化，假设输出 2 条声源轨、1 个麦克风对、4 个频点上的 $[\cos\phi,\sin\phi]$。例如某一频点输出 $[0.87,0.50]$，对应 $\phi\approx30^\circ$；与候选方向模板匹配后，该轨在 $30^\circ$ 处得分最高，最终解码为 $\hat\theta=30^\circ$。这里是形状级示例，真实网络使用更长的时间上下文和更多频点。

**顺序要点**：一个 Full-Narrow block 是 **Full-band BLSTM 后接 Narrow-band (B)LSTM**；原文配置级联 2 个 block。在线模式使用窄频带单向 LSTM 与因果卷积；离线模式把窄频带层换为 BLSTM、卷积改为非因果。全频带 BLSTM 虽是双向，但它只沿频率轴，不访问未来时间帧，因此不破坏在线时间因果性。

## 四、多个声源、静音与阵列泛化

### 1. 多轨 DP-IPD 与帧级 PIT

输出不是一条“混合相位差”，而是 (K) 条 DP-IPD 轨；每条在一帧可代表一个声源或非声源。训练用**帧级 PIT**，在该帧所有源—轨排列中选 MSE 最小者；所有麦对共享同一个源排列，避免不同麦对把同一人配到不同轨。

这让相近方向的两个源仍可由两条轨分离；代价是最大源数 (K) 必须预设，本文为 2。

### 2. 非声源目标不是零向量

普通做法把静音帧目标设为全零，但零向量不在“不同方向的 DP-IPD 流形”上，网络需在两个不连续区域之间快速跳转。IPDnet 将所有方向的理论 DP-IPD 做空间平均，得到与麦距、频率相关的非声源目标（对应各向同性扩散场相干性，实部是零阶 Bessel 函数 $J_0$，虚部为零）。这使静音—活动切换更平滑；是一个容易被忽略但有效的目标设计。

### 3. 可变阵列版

```text
参考麦 1 与每个其他麦分别组成一对
       │
       ├─ 每对输入 [Re(X1), Im(X1), Re(Xm), Im(Xm)]
       ├─ 共享同一组 Full-Narrow 权重
       ├─ 每个 FB / NB 层后：各麦对隐藏表示取均值
       └─ 将该均值广播回每个麦对并拼接
                    ↓
             每对输出它的 DP-IPD
```

这使网络输入/输出的麦对数随阵列变化，同时通过“均值池化 → 广播”让麦对交流信息。它不等于完全阵列无关：新阵列仍需要**已知几何**来生成方向模板；而均值池化比固定阵列直接联合建模的通道交互更弱。

## 五、为什么这么做？（Motivation）

1. **直接观测 IPD 不可靠**：混响、噪声与重叠说话人污染相位；直接把 noisy IPD 或 SRP 谱喂给网络，已丢失部分原始多通道统计信息。
2. **直接预测 DOA 不便跨阵列**：相位/波形到角度的映射取决于麦距和拓扑；换阵列便等于换任务。
3. **只做窄频带不够**：单频带空间线索丰富，但高频绕回、低能量频点和混响会让它不稳定；DP-IPD 的跨频率关联是强物理先验。
4. **传统“先估一个混合 DP-IPD，再迭代找多源”容易纠缠**：多轨输出直接为不同声源维持独立空间表征，减少近角度峰融合。

## 六、之前的人怎么做不了？（Limitation → Gap）

| 路线                                 | 能做               | 局限 / IPDnet 的回应                                |
| ---------------------------------- | ---------------- | ---------------------------------------------- |
| 观测 IPD + 幅度输入（如 SALSA-Lite）        | 轻量地利用显式相位特征      | 输入 IPD 已受混响/噪声污染；IPDnet 改为从复 STFT 学 DP-IPD     |
| SRP-PHAT 谱 → CNN（如 Cross3D/IcoDOA） | 可解释的方向谱，适合传统阵列   | 先形成的谱带有噪声与网格偏差；IPDnet 在特征层先去干扰，再用解析模板定位        |
| SRP-DNN                            | 学习 DP-IPD，可处理多源  | 先预测混合 DP-IPD，再迭代检测/定位；IPDnet 改为多轨 DP-IPD + PIT |
| 直接 DOA 分类/回归                       | 管线短              | 角度目标阵列相关、离散分类会有邻近格点非正交/峰模糊问题                   |
| FN-SSL 2023                        | 已有 FB/NB 融合、双麦单源 | IPDnet 将其扩展为多麦、多源、活动检测和未见阵列泛化                  |
|                                    |                  |                                                |

## 七、实验设置与关键结果

### 数据与训练

| 项目 | 设置 |
|---|---|
| 模拟语音 | LibriSpeech；gpuRIR 生成移动声源 RIR；两源片段重叠率随机 0–1 |
| 房间与干扰 | RT60 随机 0.2–1.3 s；房间 6×6×2.5 m 至 10×8×6 m；扩散噪声 SNR −5–15 dB |
| 阵列训练（可变版） | 线阵/非均匀线阵/圆阵/带中心圆阵/2D 与 3D ad-hoc 阵列；2–8 麦；任意两麦间距 3–25 cm |
| 测试阵列 | 2/4/6 麦线阵，4/6 麦圆阵；真实数据为 LOCATA 的 Benchmark2 与 DICIT 子阵列 |
| 训练规模 | 30 万 / 4 千 / 4 千 条 train/val/test 模拟语音；最多两名移动说话人，速度 0–1 m/s |
| 指标 | 5°/10° 容差下 MDR（漏检）、FAR（虚警）、成功定位帧的 MAE |

### 最关键消融：Full-band 不是装饰

原文 2 麦消融配置的结果如下（5° 容差）：

| 配置 | Params. | FLOPs | MDR↓ | FAR↓ | MAE↓ | 结论 |
|---|---:|---:|---:|---:|---:|---|
| **IPDnet** | 0.7 M | 19.4 G/s | **17.1%** | **16.8%** | **1.6°** | 完整 FB→NB + Conv |
| 去 Full-band BLSTM | 0.5 M | 12.7 G/s | 64.4% | 33.5% | 2.1° | **最大退化**：丢失跨频率关联 |
| 去 Narrow-band LSTM | 0.4 M | 10.6 G/s | 19.3% | 21.4% | 1.7° | 时间/窄带线索仍有明显贡献 |
| 去 Conv block | 0.4 M | 12.8 G/s | 20.3% | 17.5% | 1.7° | 源与局部特征分离也必要 |

10° 容差下，完整模型 MDR/FAR/MAE 为 8.3% / 7.7% / 2.1°；去 Full-band 后恶化至 51.9% / 21.0% / 3.6°。**论文最强的实验证据正是：FB 与 NB 是互补关系，而不是用其中一个替代另一个。**

### 真实 LOCATA 与阵列扩展

- 在 LOCATA 的在线评测中，固定阵列版总体优于其比较方法；可变阵列版虽略弱于固定版，仍可直接应用到未见 Benchmark2 与 DICIT 阵列。论文指出 DICIT 标注存在约 4° 的系统偏差，并在评估时作了校正。
- 将可变阵列模型从训练时最多 8 麦扩到 Benchmark2 的 12 麦：5° 容差下，4/8/12 麦的 MDR 分别为 37.1% / 25.1% / **23.1%**，FAR 为 36.1% / 22.7% / **21.6%**；8/12 麦阵列还能估计俯仰角（10°容差下 12 麦 elevation MAE 3.4°）。
- 论文实验的“0.7 M, 19.4 G/s”来自上述 2 麦消融配置。[[FA-Stateformer 2025]] 的复现实验报告 IPDnet 为 1.8 M、54.3 G/s、707.9 ms；两者任务、模型规模和测量设置不同，**不可把数字混为论文原始结果**。

## 八、优势、代价与未解决问题

### 优势

- **物理可解释**：神经网络不承担阵列几何映射；模板匹配可审计、可换阵列。
- **多声源自然分轨**：多轨 DP-IPD + 帧级 PIT 避免只输出一张空间谱时的近源峰合并。
- **适应未见阵列**：共享麦对网络与模板解码使麦数、拓扑可变。
- **全频带/窄频带互补**：以频率物理规律约束局部时序估计。

### 代价与边界

1. **不是显式解混响器**：网络仅以 DP-IPD 的监督目标学习抑制干扰，并不输出去混响波形；超出训练分布时没有解析保证。
2. **计算量高**：FB 对每帧沿频率重复运行，NB 对每频点沿时间重复运行；小参数量不代表低 FLOPs。原文明确把实时性列为后续问题。
3. **仍有相位/几何极限**：DP-IPD 本身按 $2\pi$ 周期绕回；麦距过大引发空间混叠。多频、多麦与网络先验可缓解，但不能恢复物理上不可辨的信息。
4. **最大源数固定**：实验最多 2 源；超过 (K) 的活跃源无法由这套固定轨输出完整表示。
5. **可变阵列不是“无需几何”**：它只让特征估计网络跨阵列；方向模板仍需阵列坐标、麦距与声速。均值池化的跨麦对通信也是潜在瓶颈。
6. **sim-to-real 尚未完全解决**：训练完全由模拟 RIR 与多通道噪声构成；虽在 LOCATA 上有效，但更复杂真实房间、设备失配仍可能退化。

| **传统参照** | [[GCC-PHAT 广义互相关]] / [[SRP-PHAT]] | 也依赖跨麦相位，但前者做相关/扫描；IPDnet 学习直达路径特征后再做几何模板匹配 |
| **增强侧同源思想** | [[FullSubNet 2021]] / [[TF-GridNet 2023]] | 全频带—窄频带交替/融合思想来自语音增强的时频双轴建模；目标从“干净语音”变为“干净空间相位特征” |
| **后续竞品** | [[FA-Stateformer 2025]] | 后者将 IPDnet 作为高精度、高 FLOPs 对照，转而追求更低计算量的纯 DOA 架构 |

## 十、江湖地位

```text
2023 FN-SSL：双麦、单源的 Full-band → Narrow-band DP-IPD 估计
        ↓
2024 IPDnet：多麦 + 多轨 DP-IPD + PIT + 可变阵列泛化
        → 关键思想：把“污染信号 → 直达空间表征”与“表征 → 几何定位”拆开
        → 证明 FB/NB 交替不是工程堆料：去 FB 时 5° MDR 从 17.1% 升至 64.4%
        → 代价：参数小但计算重，且仍依赖已知几何与模拟训练分布
        ↓
2025 FA-Stateformer：以 IPDnet 为精度参照，主攻精度—效率折中
```

---

*IPDnet 最值得迁移的并非“用 LSTM”，而是两层抽象：第一，把阵列相关的 DOA 映射拆成“阵列相对无关的 DP-IPD 估计 + 有解析解的模板匹配”；第二，用全频带层约束相位的跨频率物理规律、用窄频带层追踪其时间演化。它为复杂环境定位提供了一个兼具学习能力与物理可解释性的中间表征范式。*
