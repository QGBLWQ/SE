# 机械故障声源定位 — 用 U-Net 把 SRP-PHAT 伪峰谱复原成"干净源分布图"再插值搜索

> Yaohua Deng, Xiali Liu, Zilin Zhang & Daolong Zeng, 2024. **Mechanical Fault Sound Source Localization Estimation in a Multisource Strong Reverberation Environment.** *Shock and Vibration*, Article ID 6452897. DOI: [10.1155/2024/6452897](https://doi.org/10.1155/2024/6452897) · 本地 PDF: [raw/articles/6452897.pdf](../../../raw/articles/6452897.pdf)

```yaml
- 论文: Mechanical Fault SSL (U-Net + SRP-PHAT) — 2024
  ├── 要解决什么问题: 多声源强混响下 SRP-PHAT 响应功率谱出现大量伪峰、主瓣展宽混叠，直接峰值搜索会误判源数、误定位，机械故障源无法区分
  ├── 核心方法: SRP-PHAT 算出空间响应功率谱 → U-Net（图像到图像）去伪峰复原成"干净源分布图" → 局部极大值+插值搜索做亚网格定位
  ├── 属于哪个分支: SRP-PHAT 空间图复原 + 后处理定位（image-to-image 图去噪路线，非主流 DOA 分类/回归路线）
  ├── 输入/输出: 100×100 归一化 SRP-PHAT 响应功率谱（单通道图）/ 100×100 "干净"源分布图（单通道图），再经插值搜索输出各源 (x,y) 位置
  ├── 关键trick: 用"合成干净源分布图"（源位置+功率+衰减函数 φ(R)=α/R^N+β）做软标签；只保留最深层两级跳跃连接；膨胀卷积(rate=2)扩大感受野；插值搜索把离散图提升到亚网格精度

  ├── 对比了谁: 无定量 baseline（仅与"直接峰值搜索/传统阈值+平滑"定性对比；MUSIC/CNN-DOA/DAMAS 被列为 future work，未实测）
  ├── 性能上限: ≤4 源定位精度 >98.5%、RMSE <0.014 m；真实 4 源平均误差 <0.02 m；25 dB 时空间分辨率 0.08 m、0 dB 时 0.20 m
  ├── 参数量: 论文未报告（U-Net 编解码 1→512 通道，需自行复现统计）
  ├── 消融关键发现: 无正式消融；最有信息量的灵敏度结果是源数超出训练集（5 源）时精度从 98.5% 掉到 95.2%、RMSE 0.0123→0.0169

## 一、研究任务与对象

| 维度 | 详情 |
|------|------|
| **任务** | 机械故障声源定位（source localization）——多声源、强混响场景下，从麦克风阵列信号估计多个故障源在平面上的 (x,y) 位置 |
| **核心问题** | SRP-PHAT 响应功率谱在强混响 + 多声源下出现伪峰（spurious peaks），主瓣受噪声展宽后相邻源混叠，直接找峰会误判源数、误定位 |
| **方法类型** | 传统 DSP 前端（SRP-PHAT）+ 深度学习（U-Net 图复原）+ 后处理（插值搜索 interpolation search） |
| **阵列类型** | 8 元均匀圆阵（circular array，半径 r = 0.2 m），仿真与真机一致 |
| **声源数** | 训练 1–4 源，测试到 5 源；真实实验 4 源 |
| **声场假设** | 平面定位（源平面 z = 0.5 m 固定、已知），强混响 RT60 ∈ [0.2, 0.7] s |
| **输出格式** | 每帧输出一张 100×100 的"干净源分布图"，再经插值搜索输出各源的连续 (x,y) 坐标（亚网格精度） |
| **信号类型** | CHZ02-S-112LA2 继电器故障声（宽带信号，25 Hz 电磁激励下衔铁松动碰撞外壳发声） |
| **采样率** | 48 kHz |

## 二、整体架构

```
【训练阶段】
真实故障声信号 (500 只继电器, 消声室录制, 25 Hz 激励)
        │
        ▼
Pyroomacoustics image-source 模型加混响 + 加噪
(仿真房间 3×4×3 m; 8 元圆阵 r=0.2 m, 高 1 m; 源平面 z=0.5 m)
        │
        ├─────────────────────────────────────────┐
        ▼                                         ▼
SRP-PHAT → 响应功率谱 P (100×100, 归一化)     标签 B_T: 合成"干净源分布图"
        │                                  (源位置 + 功率 + 衰减函数 φ(R)=α/R^N+β)
        │                                         │
        ▼                                         ▼
              ┌─────────────────────────────┐
              │  U-Net  (损失 = 像素 MSE)    │
              └─────────────────────────────┘

【定位阶段】
阵列采集信号 (仿真或真实房间)
        │
        ▼
SRP-PHAT → 响应功率谱 P (100×100)
        │
        ▼
预训练 U-Net → 估计干净源分布图 B̂_T (100×100)
        │
        ▼
插值搜索: 全局极大值 + 超过静态阈值 B_min 的局部极大值 → 估计源数 & 粗位置
        → 以每个局部极大值为中心取 h×h 子区域、每格按 k×k 细分 → 逐子格用 (4) 重算功率
        → 与估计图做误差 → 误差最小子格 = 精确源位置 r_s^m
        │
        ▼
多故障源位置 (x, y)
```

U-Net 内部结构（Figure 3）：

```
输入: 1 × 100×100 响应功率谱
        │
        ▼
编码器 (4× 特征提取单元，每单元 = 2×膨胀卷积 3×3(d=2)+BN+ReLU → 2×2 maxpool)
  通道: 1 → 32 → 64 → 128 → 256 → 512
  空间: 100 → 50 → 25 → 12 → 6        (最深 6×6, 512 通道)
        │
        ▼
解码器 (4× 特征复原单元，每单元 = 转置卷积 2×2 → 2×普通卷积)
  通道: 512 → 256 → 128 → 64 → 32 → 1
  空间: 6 → 12 → 25 → 50 → 100
        ▲
        └── skip 连接仅在复原单元 1 和 2（最深的两个尺度，通道级拼接，256+256、128+128）
            （刻意不做全连接，避免对伪峰/噪声过拟合）
        │
        ▼
输出: 1 × 100×100 估计干净源分布图 B̂_T
```

> [!note] 空间尺寸 25→12 的说明
> 用 2×2 maxpool 连续 4 次降采样，100→50→25→12→6（25/2=12.5，向下取整为 12）。原文只强调"100×100 经 4 个单元降到 6×6、通道增至 512"，中间层的精确尺寸与通道标注来自 Figure 3 的版面文字，个别数值建议对照原 PDF 的 Figure 3 复核。

## 三、为什么这么做？（Motivation）

1. **SRP-PHAT 是主流但受伪峰困扰**：SRP-PHAT 无需源数、源/噪声先验（相比自适应波束成形），对噪声混响也比 TDOA 类鲁棒，是近年主流算法；但它在强混响 + 多声源下会产生大量**伪峰**，伪峰幅度与真实源峰接近——直接做局部极大值搜索会误判源数、把伪峰当源。
2. **噪声会让主瓣展宽 → 相邻源混叠**：噪声使主瓣（main flap/lobe）变宽，当两个源靠得近时谱峰混叠，无法区分相邻两源位置。
3. **神经网络在复杂声场有效，且 U-Net 擅长图像里的物体定位**：Chakrabarty（相位谱 + CNN）、Salvati（波束分量加权 + CNN）、Adavanne（CRNN）已证明神经定位对混响/噪声/多源更鲁棒；而 U-Net（Ronneberger 2015）在图像物体定位上表现卓越——于是把"声源定位"重铸为"图像去伪峰/复原"问题。

**一句话**：伪峰问题本质是"受污染的功率谱图 → 干净源图"的图像复原任务，正好是 U-Net 的主场。

## 四、之前的人怎么做不了？（Limitation → Gap）

| 方法 | 能做 | 不能做 |
|------|------|--------|
| TDOA 类 | 计算复杂度低、易实现、适合实时 | 对阵列硬件误差敏感，抗噪/抗混响差 |
| 子空间类（MUSIC 等） | 超高分辨率多源定位 | 需源数先验（未知源数不适用）；要求源不相关、噪声服从高斯假设 |
| 波束成形 / SRP-PHAT | 无需源/噪声先验，较鲁棒 | 强混响 + 多源下伪峰密集、主瓣展宽混叠，直接找峰失效 |
| NN 定位（Chakrabarty / Salvati / Adavanne） | 混响/低 SNR 鲁棒 | 多输出**方位（DOA）**估计为主，不是"平面栅格 + 干净图复原 + 亚网格插值"的二维位置定位 |

**Gap**：此前没有人把 SRP-PHAT 的伪峰问题当作一个**图复原（image-to-image）任务**来解决——即用 U-Net 学"受污染功率谱图 → 干净源分布图"的映射，再用插值搜索把栅格级（0.02 m）结果提升到亚网格精度。这篇论文填的就是这个空。

> [!note] 为什么能用 U-Net 而不必重造轮子
> 这篇论文的贡献不在网络创新，而在**问题重铸**：SSL 被建模为 pixel-level 回归（每像素 = 一个空间网格，像素值 = 该网格的响应功率/源分布功率），于是成熟的图像分割骨干（U-Net）可以直接搬过来用。

## 五、核心 trick：只有一个 idea，还是叠了十个？

**只有一个核心 idea**：把"SRP-PHAT 伪峰谱 → 干净源分布图"当作**图像到图像的复原任务**，用 U-Net 学习；标签用**合成干净源分布图**（不是真实 SRP 图，而是按源位置 + 功率 + 人为衰减函数合成的软高斯 blob）来"教"网络只保留真实主瓣、抹掉伪峰。

围绕这个 idea 的几个工程选择：

```
✓ 合成软标签 (式 4): 源分布图每个网格功率 B(r_l^grid) = Σ_m q_s^m · φ(R(l,m))
                    φ(R) = α/R^N + β  (随距离衰减, N 控制主瓣宽度)
   → 用合成扩散式标签而非 one-hot，避免极端稀疏，让网络有平滑梯度的目标
✓ 部分 skip 连接: 只在复原单元 1、2 (最深两层) 做 skip，而非原 U-Net 的全连接
   → 理由: 全连接会让网络对输入图的伪峰/噪声过拟合
✓ 膨胀卷积 (3×3, dilation rate K=2): 感受野扩大，跨更大距离捕捉空间结构
✓ 插值搜索: 先把输出图的局部极大值当"源数 + 粗位置"，再在每个极大值周围做 k×k 子网格
   → 用式(4) 逐子格重算功率并与估计图求最小误差 → 得到比网格分辨率更细的 (x,y)
```

**这条管线最"值钱"的其实是合成标签 + 插值搜索**：U-Net 负责"去伪峰 + 只留主瓣"，插值搜索负责"把离散响应变连续坐标"。两者拆开，定位误差才吃进 0.02 m 以内。

## 六、实验里哪个消融最关键？

> [!warning] 本文无正式消融实验（no ablation table）
> 这篇论文**没有**做"去掉 U-Net / 去掉膨胀卷积 / 去掉部分 skip / 直接峰值搜索"这类定量消融。文末也自认"未来计划与 MUSIC、CNN-DOA、DAMAS 等算法对比"——即定量 baseline 对比其实是缺失的。这是本文方法论上最大的短板。

因此"哪个设计决定最敏感"只能从**条件扫描**和**越界泛化**结果间接读出：

1. **声源数超出训练分布（最接近消融的结果）**：训练只用 1–4 源，测试 5 源时精度 98.5% → 95.2%、RMSE 0.0123 → 0.0169 m。说明 U-Net 学到的映射在源数上限处开始退化，这是刻画泛化的最关键数字。
2. **SNR 扫描（空间分辨率灵敏度）**：RT60=0.7 s 下，SNR 从 25 dB 降到 0 dB，可分辨最小源距从 0.08 m 恶化到 0.20 m——噪声对可分辨间距的影响是单调且明显的。
3. **RT60 扫描（鲁棒性）**：SNR=10 dB、三源下 RT60 从 0.2 s 提到 0.7 s，每个源误差始终 <0.02 m（0.012–0.019 m），说明 U-Net 去伪峰对混响时长不敏感。
4. **设计理由（定性，未量化）**：部分 skip（防过拟合伪峰）、膨胀卷积（扩感受野）、合成软标签主瓣宽度（由 N 控制）——三者都是作者陈述的设计动机，但没有数值支撑"敏感度"。

### 结果强度判断

- **客观指标强支持**：误差/RMSE/分辨率三张表都是可复现的定量数字，且仿真与真机（Table 4）结论一致。
- **未覆盖的维度**：没有与任何传统/神经 baseline 的定量对比表；没有报告参数量、推理耗时、训练收敛曲线。
- **结论的谨慎边界**："平均误差 <0.02 m"只在 8 元圆阵、≤4 源、继电器宽带声、已知源平面 z 的特定配置下成立。

## 八、还剩什么问题没解决？

1. **缺定量 baseline 对比（最严重）**：全文没有 MUSIC / CNN-DOA / DAMAS / 直接峰值搜索的量化对比，作者把它列为 future work——"伪峰消除能力"缺乏可验证的对照。
2. **不是端到端**：插值搜索是独立后处理（还需手设功率阈值 0.6、静态阈值 B_min、子区域 h、细分 k），训练目标（像素 MSE）与最终定位目标（(x,y) 误差）不统一。
3. **标签依赖人为设计的衰减函数**：φ(R)=α/R^N+β 中 N 决定主瓣宽度，直接影响网络能输出什么，属于手工先验，且 β/α 具体取值在 PDF 中符号残缺（见下方存疑）。
4. **应用域单一**：只验证 8 元圆阵、≤4 源、继电器单类信号；平面定位（z 固定已知），不做 3D、不做距离/深度估计。
5. **越界退化**：5 源（超训练分布）精度已明显下降，更多源未知。
6. **工程可复现性薄弱**：无开源代码、无预训练模型；参数量、推理耗时、数据可用性（"included within the article" 但未给链接）都缺失。
7. **源数估计依赖阈值**：局部极大值 + 阈值 B_min 决定源数，阈值不当仍会误判源数（这是它要解决的问题的一部分，但把难题从"找峰"转移成了"设阈值"）。

  Robust Sound Source Tracking (2021, SRP-PHAT 功率图 + 3D CNN 跟踪)
      ↓
  SSLIDE (2021, 空间 likelihood 图 + 双 decoder)
      ↓
  Icosahedral CNN DOA (2023, 球面 SRP-PHAT + icosahedral CNN)
      ↓
  Mechanical Fault SSL (2024, SRP-PHAT 图 → U-Net 去伪峰 → 插值搜索)   ← 本文
      ↓
  Beamformed 360 Sound Maps (2025, DAS 声学图 + U-Net 分割)
```

*一句话 takeaway：把"SRP-PHAT 伪峰定位"重铸成"图像去噪/复原 + 亚网格插值搜索"，是这篇论文的全部价值——U-Net 本身没有新意，真正聪明的是那个"用合成软标签的干净源分布图"作为监督目标，让网络只保留真实主瓣、抹掉伪峰；但它没做任何定量 baseline，性能数字漂亮却缺乏可对照的证明。*
