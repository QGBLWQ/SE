# PHASEN: A Phase-and-Harmonics-Aware Speech Enhancement Network

> Dacheng Yin, Chong Luo, Zhiwei Xiong, Wenjun Zeng, Microsoft Research / USTC, AAAI 2020 (Oral)

## 1. 动机：他们为什么这么做？

2020 年之前，语音增强领域有一个被广泛接受的"偷懒"做法：

```
带噪语音 → STFT → 网络预测幅度 mask → mask × |X| → 用带噪相位 φ_X 做 iSTFT → 增强语音
                                                    ↑
                                              相位直接用带噪的！
```

这个做法隐含了一个假设：**相位不重要**——只要幅度对了，用带噪相位重建的语音听起来不会太差。

PHASEN 的作者挑战了这个假设。他们的核心论证是：

| 问题 | 后果 |
|------|------|
| **相位失真降低感知质量** | 即使幅度完美，错误相位导致波形畸变 → 听感"发虚"、"有水声" |
| **幅度和相位存在信息互补** | 幅度流可以告诉相位流"哪些 T-F bin 有语音"，相位流可以告诉幅度流"谐波结构在哪里"——两者互相可以帮对方做得更好 |
| **相位不是不可预测的** | 语音的相位有结构（浊音的谐波导致相邻帧相位连续），不是纯随机噪声 |

这个动机和 Conv-TasNet 的"扔掉 STFT"形成有趣的对比：Conv-TasNet 的选择是**避开相位问题**（在时域工作，相位被隐式编码），PHASEN 的选择是**正面解决相位问题**（显式预测相位，让幅度和相位互相帮助）。

## 2. 前人局限：之前的人怎么做不了？

**Gap 的本质**：在 PHASEN 之前，没有人系统地证明"显式建模相位能稳定提升 SE 性能"。这个 gap 之所以存在，有三重原因：

1. **相位"不好看"**：相位值是卷绕的（wrapped, –π 到 π），在整个 T-F 平面上看起来像噪声。直接用 L1/L2 回归原始相位角度 → 梯度在 ±π 边界处爆炸，训练崩溃
2. **相位和幅度"不好搭"**：幅度是平滑的频谱包络（可以池化压缩），相位是精细的逐 bin 细节（池化就丢信息）。同一个网络很难同时处理好两者
3. **没有合适的跨流交互机制**：即使分别处理幅度和相位，如何让两个流互相传递有用信息？简单的 concat 或加和无法捕获频域和时域上的跨模态依赖

前人尝试过的路径：

| 方法 | 代表 | 问题 |
|------|------|------|
| **幅度-only + 带噪相位** | DCRN, 大多数 2019 前方法 | 相位失真成为性能天花板 |
| **复数网络** | 当时尚未成熟 | 复数域的统一处理虽然优雅，但训练不稳定、调参困难（DCCRN 同期但晚于 PHASEN） |
| **Griffin-Lim 类迭代相位重建** | 传统方法 | 迭代慢，且不利用数据驱动先验 |

PHASEN 的破局之道：**双流非对称设计 + 反卷绕相位损失 + FTB 跨流注意力**——三个设计各自解决一个上述障碍。

## 3. 核心 Trick：这个做法关键在哪？

PHASEN 是一个"精密设计的系统"，每个组件都有明确的分工：

| 优先级 | Trick | 作用 | 如果没有会怎样 |
|:---:|------|------|------|
| ⭐⭐⭐ | **双流非对称架构** | 幅度流做 F 维池化压缩 → 低分辨率粗粒度；相位流保持全 F 分辨率 → 精细相位细节不丢失 | 统一分辨率 → 要么丢相位细节，要么计算量爆炸 |
| ⭐⭐⭐ | **FTB 跨流注意力** | 频域 attention + 时域 attention + cross-fusion：幅度流告诉相位流"哪条频带有语音"，相位流告诉幅度流"谐波峰在哪里" | 两个流各自独立处理 → 没有信息互补 → PESQ –0.11 |
| ⭐⭐ | **反卷绕相位损失** | 用 e^{jP}（单位圆上的复数）替代原始角度做 L1 损失，天然处理 ±π 卷绕问题 | 直接用角度 L1 → ±π 边界梯度爆炸 → 训练不稳定 |
| ⭐⭐ | **三损失联合优化** | L_mag (L1 幅度) + L_phase (反卷绕) + L_com (复频谱联合) | 单一损失 → 优化目标不一致 |
| ⭐ | **幅度流指导相位预测** | 幅度流特征被注入相位流 → 相位流知道"哪里值得精细恢复" | 相位流在纯噪声区域做无用功 |

**最深层设计洞察：为什么幅度流做池化、相位流不做？**

```
幅度谱: 平滑的频谱包络，相邻频带高度相关 → 可以池化压缩，不丢信息
         ▂▃▅▆█▆▅▃▂  ← 低频到高频的缓变曲线

相位谱: 精细的谐波结构，每个 bin 的相位独立承载信息 → 池化 = 丢信息
        ░░▌░░░▌░░░▌  ← 谐波位置的相位连续性只在相邻帧，不在相邻 bin
```

这个不对称设计是 PHASEN 最被低估的贡献——它说明了对不同信号成分应该用**不同的特征分辨率**，而非一刀切。

## 4. 消融分析：哪个设计最敏感？

PHASEN 的消融实验清晰、结论可信：

| 消融项 | PESQ | Δ | 结论 |
|--------|:---:|:---:|------|
| **完整 PHASEN** | **2.99** | — | baseline |
| 去掉相位流（纯幅度） | 2.82 | **–0.17** | 相位流贡献最大 |
| 用带噪相位替代预测相位 | 2.85 | –0.14 | 证明"预测的相位"比"带噪相位"好——相位确实可预测 |
| 去掉 FTB（双流无交互） | 2.88 | –0.11 | 跨流交互显著但略低于相位流本身 |
| DCRN 基线（幅度-only CRN） | 2.82 | –0.17 | 作为外部参照，等于去掉相位流 |

**敏感度排序：**

1. **相位流的存在本身** — 最敏感（–0.17 PESQ）。说明在 2020 年的技术水平下，相位已经是幅度-only 方法的主要瓶颈
2. **FTB 跨流交互** — 中度敏感（–0.11）。有趣的是：FTB 的贡献（0.11）≈ 相位预测超越带噪相位的贡献（0.14）——两者量级相当，都是实打实的增益
3. **三损失联合 vs 单一损失** — 论文未做此消融，但根据各损失项的梯度流向推断：L_phase 对相位流最关键，L_com 对两流的协同最关键

**论文没有报告但值得追问的消融：**
- 相位流保持全分辨率 vs 也做池化的对比（验证非对称设计的必要性）
- FTB 的频域 attention vs 时域 attention 各自的贡献
- 不同 α, β 权重配比的敏感度
- 两阶段训练 vs 端到端联合训练的对比（论文用了两阶段）

## 5. 遗留问题：还剩什么没解决？

### 论文自己承认的局限

1. **代码未开源**：论文描述详细但无公开代码，复现存在不确定性
2. **16 kHz 窄带**：实验限于 Voice Bank+DEMAND（16 kHz），全频带（48 kHz）场景未验证
3. **仅测试了 seen noise conditions**：未见噪声的泛化性能未系统评估

### 读出来的隐藏问题

4. **计算量偏高**：相位流保持全 F 分辨率 → 相比幅度-only 方法，计算量显著增加。论文未报告 MACs 或推理时间，暗示这个数字不好看
5. **谐波建模是隐式的**：论文名字里有"Harmonics"，但实际对谐波结构的利用是通过 FTB 的注意力机制隐式完成的——网络可以学到"关注谐波峰"，但没有显式的谐波结构先验。对比 RNNoise 的显式 Pitch 滤波器，PHASEN 的谐波感知是"软"的
6. **双流 ≠ 实时**：两阶段训练 + 双流架构 + 全分辨率相位处理 → 几乎不可能实时部署。这是研究性方法，不是工程性方法
7. **"相位可预测"的边界不清晰**：实验证明了"在 seen noise 下相位可预测"，但未探索"在什么 SNR 以下相位变得不可预测"——这个边界决定了相位预测方法的适用范围
8. **与同期 DCCRN 的对比缺失**：DCCRN（同年 AAAI 之后）用复数网络统一处理幅度和相位，PESQ 更高（3.21 vs 2.99）。两种哲学（双流解耦 vs 复数统一）的正面比较从未发生过——这是文献中的一个遗憾

### 这些 gap 如何被后续工作填补

| Gap | 填补工作 | 年份 |
|-----|---------|------|
| 双流架构 → 更轻量 | [[MP-SENet 2023]] 用 Transformer + 并行解码，PESQ 2.99→3.50 | 2023 |
| 隐式谐波 → 显式建模 | 尚未有直接继承者（谐波感知这一支在 SE 中逐渐淡出） | — |
| 双流 vs 复数统一 | [[DCCRN 2020]] 用复数 CRNN 统一处理，PESQ 3.21 | 2020 |
| 跨流 attention | [[CRAFT 2022]] 用 T↔F cross-attention 类似思路 | 2022 |

## 二、技术路线

### 核心洞察

大多数 SE 方法只处理幅度谱，用带噪相位重建——这假设了相位不重要。但 PHASEN 证明：(1) 相位失真降低感知质量；(2) 幅度和相位的信息存在互补性，可以互相增强。

### 双流架构

```
                    ┌────────────────────────────┐
                    │  输入: 幅度谱 + 相位谱      │
                    └───────────┬────────────────┘
                                │
              ┌─────────────────┴─────────────────┐
              ▼                                    ▼
   ┌─────────────────────┐            ┌─────────────────────┐
   │   幅度流 (Mag Stream)│            │   相位流 (Phase Stream)│
   │                     │            │                      │
   │  Conv2D × N         │            │  Conv2D × N          │
   │  (F 方向 Pooling)    │            │  (保持 F 分辨率)      │
   └─────────┬───────────┘            └──────────┬────────────┘
              │                                    │
              └──────────┬─────────────────────────┘
                         ▼
              ┌─────────────────────┐
              │  FTB × L            │
              │ (Frequency-Time     │
              │  Attention Block)   │
              └──────────┬──────────┘
                         │
              ┌──────────┴──────────┐
              ▼                     ▼
   ┌──────────────────┐  ┌──────────────────────┐
   │ 幅度输出头        │  │ 相位输出头            │
   │ (FC, ReLU)       │  │ (FC, tanh→[-π,π])    │
   └──────────────────┘  └──────────────────────┘
```

### FTB (Frequency-Time Attention Block)

FTB 在两个流之间交换信息，使幅度流指导相位恢复，相位流指导幅度增强：

```
输入: 幅度特征 Mᵢ + 相位特征 Pᵢ
                  │
    ┌─────────────┴─────────────┐
    ▼                           ▼
 ┌─────────┐               ┌─────────┐
 │ 频率注意力 │               │ 时间注意力 │
 │ Attn(F)  │               │ Attn(T)  │
 └────┬────┘               └────┬────┘
      └────────┬───────────────┘
               ▼
     ┌─────────────────┐
     │  Cross Fusion    │
     │ M ← M + f(P)    │
     │ P ← P + g(M)    │
     └─────────────────┘
               │
    输出: 更新后的 Mᵢ₊₁ + Pᵢ₊₁
```

### 关键公式

幅度流损失（L1 on 幅度谱）：
$$\mathcal{L}_{\text{mag}} = \| \hat{M} - M_{\text{clean}} \|_1 \tag{1}$$

相位流损失（反卷绕感知相位损失）：
$$\mathcal{L}_{\text{phase}} = \| e^{j\hat{P}} - e^{jP_{\text{clean}}} \|_1 \tag{2}$$

复频谱损失（联合优化）：
$$\mathcal{L}_{\text{com}} = \| \hat{M} \odot e^{j\hat{P}} - M_{\text{clean}} \odot e^{jP_{\text{clean}}} \|_1 \tag{3}$$

总损失：
$$\mathcal{L} = \mathcal{L}_{\text{mag}} + \alpha \mathcal{L}_{\text{phase}} + \beta \mathcal{L}_{\text{com}} \tag{4}$$

### 消融实验发现

| 消融项 | PESQ |
|--------|:----:|
| 完整 PHASEN | **2.99** |
| 去掉相位流（纯幅度） | 2.82 |
| 去掉 FTB（双流无交互） | 2.88 |
| 用带噪相位替代预测相位 | 2.85 |

> **关键发现**：相位流贡献 +0.17 PESQ；FTB 跨流交互额外贡献 +0.11——证明相位确实可预测，且与幅度流互益。

## 六、一句话总结“江湖地位”

> **2020 | 语音增强 | 首次系统性证明"显式预测相位可稳定提升 SE"，双流非对称架构 → PESQ=2.99** → 以双流解耦 + 反卷绕相位损失 + FTB 跨流注意力的组合，证明相位不仅可预测，且与幅度流之间存在信息互补。和同年 [[DCCRN 2020]]（复数统一网络，PESQ=3.21）并列为**两种相位建模哲学**的代表作：PHASEN 选择"分而治之"（双流解耦 + 注意力融合），DCCRN 选择"统一表达"（复数网络一步到位）。
>
> **直接继承者**：[[MP-SENet 2023]] — 继承 PHASEN 的"幅相分离"思想，但将 backbone 升级为 Transformer（T-F 交替 MHSA），用并行解码替代串行双流，PESQ 从 2.99 跃升至 3.50。MP-SENet 本质上证明了"PHASEN 的幅相分离思路是对的，只是 2020 年的 backbone 不够强"。
>
> **历史定位**：PHASEN 不是性能最强的相位感知方法（被 DCCRN 和 MP-SENet 超越），但它是**第一个把"相位预测"从边缘话题变成主流方向**的工作。在它之前，大家说"相位不重要"；在它之后，大家问"你的方法有没有处理相位？"。它和 DCCRN 的共同作用，让相位感知成为 2021 年后 SE 论文的标配讨论点。
>
> **未竟之业**：PHASEN 名字里的"Harmonics"暗示了一个更宏大的愿景——不仅是相位感知，还要感知语音的谐波结构。但这个方向没有被充分展开（谐波建模是隐式的、通过 FTB 注意力完成的，而非显式的谐波先验）。将 PHASEN 的隐式谐波感知 + RNNoise 的显式 Pitch 滤波器融合，是一个尚未被探索的方向。
