# DCCRN: Deep Complex Convolution Recurrent Network for Phase-Aware Speech Enhancement

> Yanxin Hu, Yun Liu, Shubo Lv, Mengtao Xing, Shimin Zhang, Yihui Fu, Jian Wu, Bihong Zhang, Lei Xie, Northwestern Polytechnical University, INTERSPEECH 2020

## 1. 动机：他们为什么这么做？

DCCRN 的核心动机可以浓缩为一个数学事实和一个工程直觉：

**数学事实**：STFT 输出是复数。复数 $Z = X + iY$ 的幅度 $|Z|$ 和相位 $\angle Z$ 不是两个独立变量——它们是同一复数的两个投影。将它们分开处理（像大多数 SE 方法那样——网络只看 $|Z|$，相位用带噪的），等于**人为切断了实部-虚部之间的结构关系**。

**工程直觉**：如果网络的所有运算都在复数域进行，那么实部和虚部之间的结构关系会被**网络结构本身保留**——不需要额外的损失函数或注意力机制来"粘合"幅度和相位。

这个动机和 PHASEN 形成了鲜明的哲学对比：

| | DCCRN (复数统一) | PHASEN (双流解耦) |
|---|---|---|
| **哲学** | "分不如合"——直接在复数域运算 | "合不如分"——两个专用流 + 注意力融合 |
| **相位处理** | 网络结构隐式保留 | FTB 注意力显式交换 |
| **优点** | 数学优雅，参数量 ≈ 实值网络 | 每个流的架构可定制化 |
| **缺点** | 所有层被迫用相同复数范式 | 需要额外设计跨流交互机制 |

## 2. 前人局限：之前的人怎么做不了？

**Gap 的本质**：在 DCCRN 之前，没有人把复数网络**系统性地**应用到语音增强——从卷积、LSTM、归一化到激活函数，全链路复数化。这个 gap 有三个层面的原因：

1. **复数网络组件不全**：2017-2019 年已有复数 CNN（如 Trabelsi 2018）和复数 LSTM 的独立研究，但没有人把它们组装成一个**完整的 encoder-decoder 管线**——Conv + LSTM + BN + 激活函数 + 损失函数，全复数
2. **公平对比难做**：要证明"复数网络更好"，必须和**同等规模**的实值网络做消融。如果复数网络更深/更宽，就无法区分增益来自"复数"还是"更大"。DCCRN 做了严格的同架构对比（复数 CRN 3.7M vs 实值 CRN 3.6M → PESQ 3.01 vs 2.86）
3. **复数 BatchNorm 的理论空白**：标准 BN 假设数据服从单变量高斯分布，直接套到复数上需要推广到双变量复高斯——均值和方差的计算、归一化方式都需要重新推导

前人尝试过的路径及其问题：

| 方法 | 代表 | 问题 |
|------|------|------|
| 幅度-only + 带噪相位 | 大多数 2019 前方法 | 相位失真天花板 |
| 双流解耦（PHASEN 同期） | PHASEN 2020 | 需要额外设计跨流交互，架构复杂 |
| 复数 CNN only | Trabelsi 2018 | 没有时序建模（缺复数 LSTM），不适合语音 |
| 复数网络 for SAR/雷达 | 遥感领域 | 任务不同，不能直接迁移 |

## 3. 核心 Trick：这个做法关键在哪？

DCCRN 的方法论是"把 CRN 的每一块都复数化"，但不同组件的重要性差异显著：

| 优先级 | Trick | 作用 | 如果没有会怎样 |
|:---:|------|------|------|
| ⭐⭐⭐ | **复数卷积** (Eq.1-2) | 用 2×2 块结构 $[A,-B; B,A]$ 替代普通卷积——实部虚部的梯度通过块结构互相流通，隐式保留幅度-相位耦合 | 退回实值卷积 → 实部虚部独立处理 → 相当于只看幅度 — PESQ –0.15 |
| ⭐⭐ | **复数 LSTM** | 隐状态和细胞状态都是复数，但门控值保留实数（取模或实部）→ 时序建模同时保留相位连续性 | 退回实值 LSTM — PESQ –0.06 |
| ⭐⭐ | **cIRM 输出 + 混合损失** | 预测复数掩蔽（实部+虚部），可以同时旋转相位和缩放幅度；损失 = λ·L_ri + (1-λ)·L_mag | 预测标量 mask → 只能调幅度，不能改相位 |
| ⭐ | **复数 BatchNorm + PReLU** | BN 推广到双变量复高斯；PReLU 对实部虚部分别激活 | 去掉 → 训练可能不稳定，但性能影响小于卷积 |

**最关键的消融结论**：复数卷积 (+0.15 PESQ) 远大于复数 LSTM (+0.06)。这揭示了一个关于"相位信息到底藏在哪里"的深层事实：

**时间方向的相位差是常数，频率方向的相位差是声源的"指纹"。**

时间方向——同一频率 bin 的相邻帧相位差：

$$\Delta\phi_{\text{时间}} = 2\pi \cdot f \cdot \frac{H}{f_s}$$

只取决于频率 $f$ 和帧移 $H/f_s$，两者在整段音频中都是常数。440 Hz 在每一帧都精确前进同样的角度——这条信息在第 3 帧之后就再也没用了，只是在重复"这是个 440 Hz 的音"。

频率方向——同一帧内不同频率 bin 的相位关系：

$$\phi(k) = \phi_{\text{glottal}}(f_k) + \phi_{\text{tract}}(f_k)$$

编码了三个层次的信息：(1) 谐波处相位符合 $\phi(m \cdot f_0) \approx m \cdot \phi(f_0)$ 的倍数关系 → "这是浊音"；(2) 倍数关系反推出 $f_0$ → "基频是多少"；(3) 共振峰附近相位偏离线性 → "声道形状是什么"。频率方向的相位关系本质上就是语音的"指纹"。

**复数卷积在频率轴上滑动时，块结构 $[A,-B; B,A]$ 让相邻 bin 的实部和虚部互相混合——自动检测"谐波关系是否存在"。** 复数 LSTM 沿时间轴滑动，捕捉的只是"这个频率还在响"——信息量天然不如频域丰富。这就是为什么 +0.15 > +0.06。

## 4. 消融分析：哪个设计最敏感？

DCCRN 的消融实验做得干净，因为**每个复数组件都有对应的实值对照**：

| 消融项 | PESQ | Δ | 结论 |
|--------|:---:|:---:|------|
| **DCCRN (完整复数)** | **3.01** | — | baseline |
| 实值 CRN (同架构，全部实值) | 2.86 | **–0.15** | 复数化总增益 |
| 去掉 Complex LSTM → GRU | 2.92 | –0.09 | LSTM > GRU（但复数 LSTM 只贡献 +0.06，说明这是 LSTM vs GRU 的差异叠加复数化） |
| Complex Conv + 实值 LSTM | 2.95 | –0.06 | 上图的对偶消融：卷积复数化的独立贡献 |
| 因果版 DCCRN | 2.87 | –0.14 | 因果约束的代价（和 Conv-TasNet 的 –4.7 dB 相比，这里 –0.14 PESQ 算是小的） |

**敏感度排序：**

1. **复数 vs 实值** — 最敏感（+0.15 PESQ）。这是整个方法的立论基础
2. **非因果 vs 因果** — 中度敏感（–0.14 PESQ）。有趣的是 DCCRN 的因果版性能下降远小于 Conv-TasNet（–4.7 dB SI-SNRi）——可能因为 STFT 域的因果约束天然比时域更宽松
3. **复数卷积 vs 复数 LSTM** — 卷积贡献约是 LSTM 的 2.5 倍（+0.15 vs +0.06 ≈ +0.09 中 LSTM 的份额）

**论文没有报告但值得追问的消融：**
- 复数卷积的块结构 $[A,-B; B,A]$ 是否是唯一选择？如果用 $[A,B; -B,A]$ 或其他参数化会怎样？
- cIRM 输出 vs 直接预测复数干净频谱（span-based vs mask-based 在复数域的对比）
- 不同 λ 权重配比的敏感度
- 复数网络在更低 SNR 下的表现（Voice Bank+DEMAND 的 SNR 分布偏温和）

## 5. 遗留问题：还剩什么没解决？

### 论文自己承认的局限

1. **16 kHz 窄带**：实验限于 16 kHz，全频带（48 kHz）的复数网络训练和推理未验证
2. **复数 BatchNorm 的理论基础弱**：推广到双变量复高斯是工程近似，不是严格推导
3. **未见噪声泛化**：Voice Bank+DEMAND 的噪声类型有限，真实场景的泛化需要更多数据

### 读出来的隐藏问题

4. **复数网络的"不可解释性"比实值网络更严重**：实值网络的卷积核可以画频谱图（哪个频率被关注）；复数卷积核的幅度+相位两套参数，可视化更难——调试和诊断成本高
5. **"复数网络"本身不是银弹**：论文证明了复数 CRN > 实值 CRN，但没有证明复数 CRN > 实值 Transformer（当时尚未出现）或实值 Dual-Path RNN。复数化换来的增益（+0.15 PESQ）是否比换 backbone（如 CRN → Conformer）更大？这个比较从未做过
6. **cIRM 的值域问题**：cIRM 的实部和虚部理论上无界，而标准 IRM 天然在 [0,1]。cIRM 的训练稳定性依赖复杂的正则化技巧，论文未深入讨论
7. **与 PHASEN 的正面比较缺失**：同年（2020）同任务（SE on Voice Bank+DEMAND）、PESQ 差仅 0.02（DCCRN 3.01 vs PHASEN 2.99），但没有做 cIRM vs 双流的公平消融（同一训练配置、同一数据增强）——两种哲学的胜负至今没有定论
8. **复数网络在定位领域完全空白**：DOA/SELD 处理的是多通道复数 STFT，天然适合复数网络，但库中 17 篇定位论文零篇使用——这是一个比可学习编码器更直接的跨域迁移机会

### 这些 gap 如何被后续工作填补

| Gap | 填补工作 | 年份 |
|-----|---------|------|
| 复数 CRN → 双路径 | [[DPCRN 2021]] 将 DCCRN + DPRNN 融合：块内复数 Conv2D + 块间复数 LSTM | 2021 |
| 复数滤波替代 cIRM | [[DeepFilterNet 2023]] 用深度复数滤波替代单点 cIRM，更精细 | 2023 |
| 复数 vs 实值的系统对比 | 仍缺失——没有人在 SE 上做"复数 Transformer vs 实值 Transformer"的公平消融 | — |
| 复数网络 → 定位 | 完全空白 — \\⚠️ 跨域迁移机会 | — |

| 维度 | 详情 |
|---|---|
| **任务** | 相位感知单通道语音增强 |
| **输入** | STFT 复数频谱（实部 + 虚部） |

## 二、技术路线

### 核心洞察

STFT 是复数变换——幅度+相位是同一复数的不同投影。将它们解耦为独立通道处理丢失了实部-虚部之间的结构关系。复数网络在数学上保持这种关系。

### 复数卷积定义

标准复卷积：
$$W \ast Z = (A \ast x - B \ast y) + i(A \ast y + B \ast x) \tag{1}$$

其中 $W = A + iB$ 为复数卷积核，$Z = x + iy$ 为复数输入。

矩阵形式（实现方式）：
$$\begin{bmatrix} \Re(W \ast Z) \\ \Im(W \ast Z) \end{bmatrix} = \begin{bmatrix} A & -B \\ B & A \end{bmatrix} \ast \begin{bmatrix} x \\ y \end{bmatrix} \tag{2}$$

### 架构

```
┌─────────────────────────────────────────────────────────────────┐
│                   DCCRN —— 编码器-解码器                         │
│                                                                  │
│  复数频谱 (F×T×2)                                                 │
│      │                                                            │
│   ┌──▼──────────────────────────────────────────────────────┐   │
│   │  Complex Conv2D Encoder × 5                              │   │
│   │  各层: (2→16, 16→32, 32→64, 64→128, 128→256)             │   │
│   │  卷积核: (5,2)×(3,3)×(3,3)×(3,3)×(3,3)                  │   │
│   │  频率方向 stride: 2→2→2→2→(1,2)                           │   │
│   └──┬──────────────────────────────────────────────────────┘   │
│      │ 复数特征图                                                 │
│   ┌──▼──────────────────────────────────────────────────────┐   │
│   │  Complex LSTM × 2 (256 单元)                             │   │
│   │  PReLU + BatchNorm (复数版)                              │   │
│   └──┬──────────────────────────────────────────────────────┘   │
│      │                                                            │
│   ┌──▼──────────────────────────────────────────────────────┐   │
│   │  Complex Conv2D Decoder × 5 (对称于 Encoder)              │   │
│   │  + Skip connections from Encoder                          │   │
│   └──┬──────────────────────────────────────────────────────┘   │
│      │                                                            │
│  复数掩蔽: M_r + iM_i  →  C_enhanced = C_noisy × M               │
└─────────────────────────────────────────────────────────────────┘
```

### 复数 LSTM

标准 LSTM 门控公式的复数推广：
$$f_t = \sigma(W_f \ast [h_{t-1}, x_t] + b_f) \quad \text{(复数→实数映射)} \tag{3}$$

复数 LSTM 的隐状态 $h_t$ 和细胞状态 $c_t$ 都是复数向量，但门控值保持实数（通过取模或实部来做门控）。

### 损失函数

$$\mathcal{L} = \lambda \mathcal{L}_{\text{ri}} + (1-\lambda) \mathcal{L}_{\text{mag}} \tag{4}$$

其中：
$$\mathcal{L}_{\text{ri}} = \| \hat{S}_{\text{ri}} - S_{\text{ri}} \|_2^2 \quad \text{(实部+虚部 MSE)} \tag{5}$$
$$\mathcal{L}_{\text{mag}} = \| |\hat{S}| - |S| \|_2^2 \quad \text{(幅度 MSE)} \tag{6}$$

### 消融实验发现

| 消融项 | PESQ |
|--------|:----:|
| DCCRN (完整复数) | **3.01** |
| 实值 CRN (同一架构，实值卷积+LSTM) | 2.86 |
| 去掉 Complex LSTM → GRU | 2.92 |
| Complex Conv + 实值 LSTM | 2.95 |

> **关键发现**：复数卷积贡献 +0.15 PESQ，复数 LSTM 额外贡献 +0.06——复数卷积比复数 RNN 更重要。

> **2020 | 语音增强 | 首个全链路复数 CRNN for SE，PESQ=3.01 超越同年 [[PHASEN 2020]] (2.99)** → 证明复数网络能在同等参数规模下（3.7M vs 实值 3.6M）稳定超越实值网络，因为复数运算在数学结构上保留了幅度-相位的耦合关系。和 PHASEN 并列 2020 年语音增强的两大范式突破：PHASEN 说"幅度和相位要分开处理再融合"，DCCRN 说"幅度和相位从未分离——它们只是复数的两个投影，应该被统一处理"。
>
> **直接继承者**：[[DPCRN 2021]] — 将 DCCRN 的复数 CRNN + DPRNN 的双路径 RNN 融合，在复数域引入块内+块间建模，进一步提升了长序列上的相位连续性。
>
> **精神继承者**：[[DeepFilterNet 2023]] — 继承了"复数域操作"的思想，但将单点 cIRM 升级为深度复数滤波（用一个滤波器替代一个标量），在 ERB 感知尺度上做更精细的复数域修正。
>
> **历史定位**：DCCRN 是复数深度学习在语音增强中的**方法基准**——后续所有复数域 SE 方法（DPCRN, DeepFilterNet, 部分扩散模型）都直接或间接继承了它的复数 Conv/LSTM 定义。它是 PHASEN/DCCRN 这一对"2020 相位双子星"中更"工程化"的一方：PHASEN 提出了问题和双流思路，DCCRN 给出了一个更优雅、更统一的实现方案。
>
> **未竟之业**：复数网络的理论优势（保留实虚部结构）恰好对应 DOA/SELD 的核心需求（跨通道相位差 = 空间信息）——但复数网络在定位领域**零篇使用**。PHASEN 的双流 + DCCRN 的复数统一，两种哲学都没有被移植到定位任务。这是一个比 TCN 更直接的跨域空白。
