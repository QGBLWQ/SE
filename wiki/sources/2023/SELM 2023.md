# SELM: Speech Enhancement using Discrete Tokens and Language Models

> Nguyen et al., Meta AI / CMU, 2023。

## 1. 动机：他们为什么这么做？（motivation）

传统语音增强大多直接预测连续谱或连续波形，容易出现过平滑、细节缺失或感知失真。随着神经音频编解码器和语音语言模型发展，一个新思路出现：如果语音可以被离散 token 表示，那么增强可以变成“从带噪 token 恢复干净 token”的序列建模问题。

SELM 的动机是把语音增强从信号回归转成语言模型擅长的离散序列预测。

## 2. 前人局限：之前的人怎么做不了？（limitation → gap）

连续域方法的局限：

- MSE/SI-SNR 回归可能平均化细节；
- GAN/扩散模型能生成细节但训练或推理成本高；
- 时域模型需要直接处理长序列，长上下文代价大；
- 频域模型受 STFT 表示和相位处理限制。

SELM 填补的 gap 是：利用离散 codec 压缩声学空间，让 LM 在更短、更语义化的 token 序列上做增强。

## 3. 核心 Trick：这个做法关键在哪？

旧笔记记录的方法：

```text
带噪语音
  → EnCodec / neural audio codec
  → 离散 token
  → 预训练或训练的 LM 预测干净 token
  → codec decoder
  → 干净波形
```

关键 trick 是**任务重定义**：不是估计 mask，也不是逐点回归波形，而是把增强变成 token-level restoration。

## 4. 实验里哪个消融最关键？

当前旧笔记没有记录消融。规范化后应重点补：

- codec 码率/码本数量对增强质量的影响；
- LM 上下文长度和参数量；
- 是否使用预训练 LM；
- token 预测损失 vs 波形/频谱辅助损失；
- 与扩散模型和 Conv-TasNet 类模型的主观听感对比。

## 5. 这个方向还剩什么问题没解决？（future work / limitation）

- 实时性和流式生成困难；
- codec 本身的信息瓶颈会限制上限；
- token 错误可能产生离散伪影；
- 对低资源语言、强噪声和非语音噪声的泛化仍不清楚；
- 该范式适合离线高质量增强，但短期内不适合 RNNoise/DeepFilterNet 式端侧场景。
