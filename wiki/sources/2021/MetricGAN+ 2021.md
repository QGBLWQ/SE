# MetricGAN+: An Improved Version of MetricGAN for Speech Enhancement

> Szu-Wei Fu, Chien-Feng Liao, Yu Tsao, INTERSPEECH 2021

## 1. 动机：他们为什么这么做？

语音增强有一个根本性的"目标错位"问题：

```
训练目标 (可微):           评价指标 (不可微):
  MSE on magnitude          PESQ (感知语音质量)
  SI-SNR                    STOI (短时可懂度)
  L1 on spectrum            CSIG, CBAK, COVL
    ↓                         ↓
  下降 ≠                   提升！
```

网络在训练集上把 MSE 降了 20%，PESQ 可能纹丝不动——因为 MSE 在优化"每个 bin 的幅度差"，而 PESQ 在衡量"人耳听到的感知质量"，两者不是单调关系。

MetricGAN 家族的动机是：**如果评价指标不可微，那就训练一个可微的代理模型来近似它。**

```
传统方法:                           MetricGAN 方法:
  G 优化 MSE → ↓                    G 优化 D 的评分 → ↑
  D 不存在                           D 学习 PESQ 函数 → 提供梯度
  评价靠 PESQ (不可微, 训练时看不到)    G 直接在"类 PESQ"的梯度方向上走
  → 训练目标和评价目标两张皮           → 训练目标 ≈ 评价目标
```

## 2. 前人局限：之前的人怎么做不了？

**Gap 的本质**：在 MetricGAN 之前，深度学习的语音增强只能用**可微的损失函数**训练——MSE、L1、SI-SNR——因为反向传播需要梯度。PESQ 的算法里包含 VAD、时域对齐、扰动加权、巴克尺度映射、不对称扰动等一系列不可微操作，不可能直接做损失函数。

前人尝试过的路径及其问题：

| 方法 | 代表 | 思路 | 问题 |
|------|------|------|------|
| 直接回归 + MSE | 大多数 2019 前方法 | L1/L2 on 幅度谱或波形 | 训练目标 ≠ 评价目标 |
| GAN 判别器判真假 | [[SEGAN 2017]] | D 判"这像不像干净语音" | D 学的是"真假"，不是"PESQ 高不高"——两个概念不重合 |
| 强化学习 | 极少数尝试 | 把 PESQ 当 reward | 高方差、收敛慢、不实用 |

MetricGAN 的突破：把 PESQ 不是当 reward（RL 方式），而是训练一个可微的**回归模型 D** 来预测 PESQ 分数。D 成了"可微的 PESQ 代理"——G 沿着 D 的梯度走 = 沿着 PESQ 的方向走。

**那为什么不是直接做 MetricGAN 而要做 MetricGAN+？** 原始 MetricGAN 有三个稳定性问题：
1. D 和 G 交替训练时互相"过拟合对方当前的弱点"
2. 训练数据多样性不足 → D 泛化差 → 给 G 错误梯度
3. G 直接预测频谱 → 训练不稳定

MetricGAN+ 用三个改进分别解决这三个问题。

## 3. 核心 Trick：这个做法关键在哪？

### 整体框架

```
┌─────────────────────────────────────────────────┐
│                MetricGAN+                         │
│                                                    │
│  ┌──────────────┐         ┌───────────────────┐  │
│  │  生成器 G     │          │  判别器 D (指标导师)  │  │
│  │              │          │                    │  │
│  │ BLSTM encoder│ 增强语音  │ CNN 4-layer        │  │
│  │ → mask → ×|X|│ ──────→ │ (增强, 干净) →分数   │  │
│  │              │          │ 预测 PESQ ∈ [1,4.5] │  │
│  └──────┬───────┘          └─────────┬───────────┘  │
│         │                            │               │
│         │    G 的损失: 让 D 给高分     │               │
│         │    L_G = -D(G(noisy), clean)│               │
│         │                            │               │
│         │    D 的损失: 逼近真实 PESQ  │               │
│         │    L_D = |D(enh, clean) - PESQ_truth|² │   │
│         │                            │               │
│    ┌────▼────────────────────────────▼─────────┐  │
│    │  经验回放池 (Experience Replay Buffer)      │  │
│    │  存历史增强样本 → D 不会只见过拟合当前 G   │  │
│    └────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────┘
```

| 优先级 | Trick | 解决什么 | 对应 MetricGAN 的哪个问题 |
|:---:|------|------|------|
| ⭐⭐⭐ | **D 作为指标导师**（不等同于 GAN 判别器） | 训练目标 = 评价目标 | 核心创新 |
| ⭐⭐ | **经验回放** (Experience Replay) | D 不会只见过拟合当前 G 的输出 → 预测更准 | 问题 1: D/G 共适应 |
| ⭐⭐ | **数据增强** (干净语音混叠多轮噪声) | D 见过更多样的增强结果 → 泛化更好 | 问题 2: D 泛化差 |
| ⭐ | **G 输出 mask 而非频谱** | mask ∈ [0,1] 天然有界 → 训练更稳定 | 问题 3: 训练不稳定 |

### 经验回放——为什么这很关键

D 和 G 交替训练时，有一个经典的"猫鼠共舞"问题：

```
Round 1: D 学会识别 G 生成的某种伪影 → D 给低分
         G 调整策略, 消除那种伪影
Round 2: D 发现 G 的新策略下的新伪影 → D 又给低分
         G 再调整...
→ D 永远只在"当前 G 的输出"上预测, 泛化到未见噪声时崩塌
```

经验回放：维护一个固定大小的 buffer，存储过去 N 轮 G 的增强样本 + 它们的真实 PESQ 值。每一轮训练 D 时，从 buffer 中随机采样历史样本混入当前 batch → D 被迫学习一个**覆盖 G 多种状态**的通用 PESQ 预测器，而不是只适应"当前 G 的弱点"。

### 对抗损失——G 是如何被"牵着走"的

```
L_G = - D(G(noisy), clean)

直观: G 的目标是"让 D 觉得好"。
如果 D 预测 PESQ=2.5 → L_G = -2.5 → 梯度方向: "怎么做可以让 D 觉得像 2.6?"
如果 D 预测 PESQ=3.8 → L_G = -3.8 → 梯度方向: "怎么做可以让 D 觉得像 3.9?"

D 的预测值越高 → G 的梯度越强 → G 被推着走向"高 PESQ 区域"
D 的预测值接近上限 (4.5) → 梯度减弱 → G 趋近 D 眼中的完美
```

**为什么这比 MSE 好？** MSE 告诉 G："你在这个 bin 少了 0.3dB"，但 0.3dB 的误差在 300Hz（人耳敏感）和 6kHz（人耳不敏感）的感知后果完全不同。D 的训练数据里包含了真实 PESQ 的计算逻辑（对低频敏感的权重、不对称扰动等），所以 D 给 G 的梯度是**感知加权的**——它会让 G 优先修复人耳敏感的频率区域。

## 4. 消融分析：哪个设计最敏感？

| 消融项 | PESQ | Δ | 结论 |
|--------|:---:|:---:|------|
| **MetricGAN+ (完整)** | **3.15** | — | baseline |
| 去掉经验回放 | ~2.95 | –0.20 | 经验回放贡献最大——D 的泛化是关键 |
| 去掉数据增强 | ~3.02 | –0.13 | 增强次要但仍重要 |
| G 输出频谱 (不用 mask) | ~3.05 | –0.10 | mask 的输出约束有效 |
| MetricGAN 原版 | 2.86 | –0.29 | 三大改进总计贡献 +0.29 PESQ |

**敏感度排序：**

1. **经验回放** — 最敏感（–0.20 PESQ）。说明 D 的泛化能力是瓶颈——如果 D 的 PESQ 预测不准，G 被误导，全盘皆输
2. **数据增强** — 中度敏感（–0.13）。和回放的机制互补：回放增加 D 看到的历史增强样本多样性，数据增强增加干净语音+噪声组合的多样性
3. **mask 输出** — 低度敏感（–0.10）。有界的 sigmoid 输出比无界的直接频谱预测稳定

**三大改进的总增益 = +0.29 PESQ (2.86 → 3.15)**，但经验回放独占了其中约 2/3。

## 5. 遗留问题：还剩什么没解决？

### 论文自己承认的局限

1. **幅度-only, 相位未处理**：D 预测 PESQ 是基于增强后的幅度谱——PESQ 本身也不评估相位，所以 G 永远看不到"相位好了也没分"的信号
2. **D 的 PESQ 预测有误差**：D 的 MSE 在 ~0.15-0.20 PESQ 点左右 → G 收到的是"带噪声的 PESQ 梯度"

### 读出来的隐藏问题

3. **单指标优化 = 剃刀效应**：优化 PESQ → PESQ 高，但 STOI 可能被牺牲。PESQ 对某些失真（如过度降噪导致语音闷）惩罚轻 → G 学会"刷 PESQ"而非真正提升所有感知维度
4. **D 和评价指标不是同构的**：D 学的是"给定增强和干净 → 预测 PESQ 分数"，但 PESQ 函数的输入是**(noisy, clean)** 对，而 D 的输入是**(enhanced, clean)** 对——训练分布不同，D 在"低质量增强"区域的预测最不准，而这恰好是训练早期 G 的状态
5. **BLSTM = 非因果 = 离线**：架构用的是 Bi-LSTM，需要看完整句子，无法实时推理
6. **在增强社区被后续超越，但在分离社区从未被尝试**：PESQ 是增强指标，SI-SNR 是分离指标——MetricGAN 的思路（训练可微代理模型近似评价指标）在分离方向零篇使用。如果把 SI-SNR 换成"可微 SI-SNR 代理"来训练分离模型，会有改进吗？完全空白
7. **"指标导师"的思想远超语音增强**：任何有"不可微评价指标"的深度学习任务都可以用这个框架——BER 在通信、FID 在生成、BLEU 在翻译。但在语音领域之外，这个思路还没有被充分传播

### 这些 gap 如何被后续工作填补

| Gap | 填补工作 | 年份 |
|-----|---------|------|
| BLSTM → Conformer backbone | [[CMGAN 2022]] 用 Conformer + MetricGAN, PESQ 3.15→3.41 | 2022 |
| 幅度-only → 幅相并行 | [[MP-SENet 2023]] 用 Transformer + 幅相并行解码, PESQ 3.50 | 2023 |
| 单指标 → 多指标融合 | 仍缺失——没有人做 MetricGAN+ 同时优化 PESQ+STOI+DNSMOS | — |
| MetricGAN → 分离 (SI-SNR) | 完全空白 | — |

## 一、研究任务与对象

| 维度 | 详情 |
|---|---|
| **任务** | 单通道语音增强，指标驱动 (PESQ) 训练 |
| **输入** | STFT 幅度谱 (F×T, F=257) |
| **输出** | 增强幅度 mask (sigmoid, [0,1]) → mask × \|X\| → iSTFT (带噪相位) |
| **采样率** | 16 kHz |
| **数据集** | Voice Bank + DEMAND (28 说话人 × 40 噪声训练, 2 说话人 × 20 噪声测试) |
| **核心指标** | PESQ=3.15, CSIG=4.14, CBAK=3.42, COVL=3.53 |

## 二、技术路线

### 生成器 G

```
带噪 STFT 幅度 [F, T] → 2×BLSTM(200单元) → fc → mask [F, T] (sigmoid)
  架构极简——G 本身没有编码器-解码器, 就是 BLSTM + mask 输出
  ↑ MetricGAN+ 的重点不在 backbone 创新, 而在训练范式创新
```

### 判别器 D (指标导师)

```
输入: [增强幅度, 干净幅度] [F, T, 2] → 4×CNN (kernel=3×3, channels=16→32→64→128)
     → Global Avg Pooling → 3×FC → 输出标量: 预测 PESQ ∈ [1, 4.5]
```

### 关键公式

D 的损失（回归逼近真实 PESQ）：
$$\mathcal{L}_D = \frac{1}{N} \sum_{i=1}^N \left(D(G(x_i), y_i) - \text{PESQ}_{\text{truth}}(G(x_i), y_i)\right)^2$$

G 的损失（对抗 + 正则化）：
$$\mathcal{L}_G = -\frac{1}{N}\sum_{i=1}^N D(G(x_i), y_i) + \lambda \cdot \mathcal{L}_{\text{MSE}}(G(x_i), y_i)$$

$\lambda$ 是 MSE 正则项权重（很小，仅用于初期稳定训练）。

## 三、结果

| 方法 | PESQ | CSIG | CBAK | COVL |
|------|:----:|:----:|:----:|:----:|
| Noisy | 1.97 | 3.35 | 2.44 | 2.63 |
| Wiener | 2.22 | — | — | — |
| SEGAN | 2.16 | 3.14 | 2.61 | 2.43 |
| BLSTM (MSE) | 2.77 | — | — | — |
| MetricGAN 原版 | 2.86 | — | — | — |
| **MetricGAN+** | **3.15** | **4.14** | **3.42** | **3.53** |
| *对比: DCCRN (复数, 非GAN)* | *3.01* | — | — | — |

## 六、江湖地位

> **2021 | 语音增强 | 证明"训练目标比 backbone 重要"——PESQ 3.15 超越同年 DCCRN (3.01) 和 PHASEN (2.99)，尽管未处理相位** → 展示了一个反直觉的结论：用最普通的 BLSTM backbone，配上一个聪明的训练策略（让判别器学习 PESQ 函数），可以打败同年所有精心设计的架构。这个发现在语音增强社区被 CMGAN (2022) 接力，但在语音分离社区完全被忽略。
>
> **最核心的遗产**：不是 MetricGAN+ 这三个字，而是"**训练一个可微代理来近似不可微评价指标**"这个范式的通用性。任何有"评价指标不可微"问题的深度学习任务都可以用这个框架——但语音社区之外几乎没人这样做。
>
> **对标关系**：如果 [[PHASEN 2020]] 和 [[DCCRN 2020]] 代表了"改进架构来处理相位"的路线，MetricGAN+ 就代表了"改进训练目标来逼近感知"的路线。2020-2021 年间这两条路线并行发展——架构路线演进为 DPCRN→DeepFilterNet，目标路线演进为 MetricGAN+→CMGAN→MP-SENet(微调阶段保留 MetricGAN 训练)。
