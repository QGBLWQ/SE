# 时序卷积网络 (Temporal Convolutional Network, TCN)

## 一句话记忆点

> TCN = 堆叠的扩张卷积块，用**指数增长的扩张率**覆盖秒级感受野，用**残差 + 跳跃连接**保证梯度流动。它是 RNN/LSTM 的卷积替代品——并行更快、梯度更稳、感受野可控。

## 定义

**时序卷积网络 (TCN)** 是一种用卷积操作处理序列数据的架构。与 RNN 的"逐帧循环"不同，TCN 用**堆叠的扩张卷积层**在一次前向传播中覆盖整个序列。在 Conv-TasNet 中，TCN 作为分离模块（separator）的核心，替代了此前占主导地位的 LSTM。

核心公式：
$$y = \text{TCN}(w) = \text{Stack}_{r=1}^R \left[ \text{Block}_M \circ \cdots \circ \text{Block}_1 \right](w)$$

其中 $w$ 是编码器的输出特征序列，每个 Block 是**一个扩张卷积块**。

## 架构全景

```
TCN = R 组 × (M 个扩张卷积块)

┌─────────────────────────────────────────────────────┐
│                    TCN (R=3, M=8)                      │
│                                                       │
│  输入 w ─→ [组1] ─→ [组2] ─→ [组3] ─→ 输出            │
│              │        │        │                      │
│              ├── skip ├── skip ├── skip               │
│              ↓        ↓        ↓                      │
│              求和 ─→ 1×1 conv ─→ mask                  │
│                                                       │
│  每组内部 (M=8 块):                                    │
│  ┌────┐  ┌────┐  ┌────┐       ┌──────┐               │
│  │d=1 │─→│d=2 │─→│d=4 │─→ ...─→│d=128 │               │
│  └──┬─┘  └──┬─┘  └──┬─┘       └──┬───┘               │
│     │ skip  │ skip │ skip       │ skip                │
│     └───────┴──────┴────────────┘                     │
└─────────────────────────────────────────────────────┘
```

## 单个扩张卷积块内部

```
输入 ─→ 1×1-conv ─→ PReLU ─→ Norm ─→ D-conv ─→ PReLU ─→ Norm ─→ 1×1-conv
  │        ↑                          ↑                          │
  │        └── 通道混合 ──────────────┘                          │
  │                                                              │
  ├──────── residual connection (加法) ──────────────────────────┤ → 下一块
  │                                                              │
  └──────── skip connection ─────────────────────────────────────┘ → 最终求和
```

三个关键设计：

| 设计                         | 作用                        | 没有会怎样               |
| -------------------------- | ------------------------- | ------------------- |
| **扩张卷积 (D-conv)**          | 指数级扩展感受野（d=1,2,4,...,128） | 需要 O(1000) 层才能覆盖同范围 |
| **残差连接 (residual)**        | 让梯度直接穿过每一块，缓解退化           | 深层网络无法训练            |
| **跳跃连接 (skip connection)** | 每一块的特征都收集起来做最终预测          | 只用到最后一层的信息，浅层细节丢失   |

## 归一化：gLN vs cLN

TCN 中的 Norm 层有两种选择，对应非因果和因果模式：

| | gLN (Global Layer Norm) | cLN (Cumulative Layer Norm) |
|---|---|---|
| **适用** | 非因果（离线） | 因果（实时/在线） |
| **计算** | 全序列的均值和方差 | 仅当前及过去帧的累积均值/方差 |
| **公式** | $\hat{F} = \frac{F - \mu_{global}}{\sigma_{global}}$ | $\hat{f}_k = \frac{f_k - \mu_{1:k}}{\sigma_{1:k}}$ |
| **性能** | 更好 | 略差（–4.7 dB SI-SNRi，但这是因果性的代价） |
| **能否实时** | ❌ 需要整句 | ✅ 逐帧处理 |

> cLN 是 Conv-TasNet 的原创设计——让因果 TCN 也能用层归一化，而不用偷偷看未来帧。

## TCN vs LSTM：为什么 TCN 在语音分离中完胜

Conv-TasNet 消融实验的对照（同架构，只换 separator）：

| | LSTM-TasNet | Conv-TasNet (TCN) |
|---|---|---|
| **参数量** | 23.6M | **5.1M** (小 4.6×) |
| **SI-SNRi** | 13.2 dB | **15.3 dB** (高 2.1 dB) |
| **CPU 推理** | 4.3 ms/帧 | **0.4 ms/帧** (快 10×) |
| **帧长要求** | 需 ≥5ms | **2ms 即可** |
| **并行化** | ❌ | ✅ |

**TCN 为什么比 LSTM 更适合语音分离？**

1. **短帧友好**：LSTM 的隐状态每步更新，帧太短 → 计算开销爆炸。TCN 的卷积操作是并行的，帧长不影响计算量
2. **精确的感受野控制**：TCN 告诉你"我能看到过去 3.8 秒"，LSTM 只能说"理论上记得，实际上看运气"
3. **梯度路径短且稳定**：残差连接让每个块都能直接从 loss 获取梯度，不像 LSTM 的 BPTT 要穿越数千步

## TCN 的泛化：不仅仅是 Conv-TasNet

TCN 的设计模式（扩张卷积块 + 残差 + skip）在语音领域有广泛应用：

| 模型 | 年份 | 如何使用 TCN |
|------|:---:|------|
| **Conv-TasNet** | 2019 | separator 主体：3 组 × 8 块 |
| **DPRNN** | 2020 | 用双路径 RNN 替代 TCN（但保留了 TCN 的思想做帧内处理） |
| **Demucs** | 2019 | 时域 U-Net，扩张卷积做下采样路径 |
| **DeepFilterNet** | 2023 | 深度滤波器的时序建模用 TCN 风格 |

## 局限

1. **固定感受野**：3.8 秒不够 → 改架构重新训练，无法动态调整。停顿 >3.8 秒的场景完全丢失上下文 → [[DPRNN 2020]] 用双路径 RNN 解决
2. **不是真正的"记忆"**：TCN 只有有限的滑动窗口，不能像 LSTM 那样理论上无限记忆
3. **大感受野 = 大扩张率 = 稀疏采样**：d=128 时，每 128 帧才采样一次，对快速变化的事件可能遗漏
