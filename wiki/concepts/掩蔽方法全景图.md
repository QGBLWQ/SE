# 掩蔽方法全景图 — IBM, IRM, cIRM 以及频谱映射

## 语音增强的两种范式

```
                        ┌─→ [神经网络] ─→ 增强语音

    带噪语音 ─→ STFT ─→ 频谱图 (复数矩阵)
                        │
                        └─→ [神经网络] ─→ 掩蔽矩阵 ─→ × 频谱图 ─→ 增强语音
```

| 范式 | 英文名 | 做法 | 代表 |
|------|--------|------|------|
| **频谱映射** | Spectral Mapping | 网络直接预测干净语音的频谱 | Maas 2012, Xu 2015 |
| **掩蔽 (Masking)** | Mask-based | 网络预测 0~1 的掩蔽，乘以带噪频谱 | RNNoise, Conv-TasNet, DPRNN |

掩蔽方法几乎成了主流，因为：
- 输出值域有界 [0,1]，天然稳定
- 即使预测错了，也只是"某个频带没擦干净"而不是"频谱全乱"
- 可以融合进信号处理的物理直觉

## 掩蔽方法的进化史

### 第一代：IBM (Ideal Binary Mask) — 2000s

$$\text{IBM}(t,f) = \begin{cases} 1, & \text{SNR}(t,f) > \text{threshold} \\ 0, & \text{otherwise} \end{cases}$$

- 每个 T-F bin 非 0 即 1
- 最早提出 (Wang, 2005)
- 问题：太粗糙。"0.6 语音 + 0.4 噪声"的 bin，你说它是 0 还是 1？

> 就像用"黑白"描述一张彩色照片——信息损失太大。

### 第二代：IRM (Ideal Ratio Mask) — 2010s

$$\text{IRM}(t,f) = \left(\frac{S^2(t,f)}{S^2(t,f) + N^2(t,f)}\right)^\beta$$

- 连续值 [0,1]，保留软决策
- \beta 控制压缩程度
- → 详见 [[理想比率掩蔽 IRM]]

> 从"黑白"变成"灰度"——好多了。

### 第三代：cIRM (Complex IRM) — 2018+

$$\text{cIRM} = M_r + j M_i$$

- 既有实部也有虚部 → 可同时修正**幅度和相位**
- DCCRN 就是用法之一
- 挑战：复数的 [0,1] 边界不好定义，训练难度增大

> 从"灰度"变成"彩色"——可以修复相位了。

### 现在：时域掩蔽 (Time-Domain Masking) — 2019+

Conv-TasNet 等不再在频谱图操作，而是让网络自己学习一个"可训练的变换域"：

```
带噪波形 → [可训练的编码器] → [隐空间特征] × [估计的掩蔽] → [可训练的解码器] → 增强波形
```

掩蔽作用在**网络自己学出来的特征空间**，而不是人为定义的 STFT 频谱图。

## 掩蔽方法的层级对比

```
方法          操作域         输出维度     相位处理？    复杂度
─────────────────────────────────────────────────────────
IBM          STFT 频谱      每个 bin    ❌ 不管       极低
IRM          STFT 频谱      每个 bin    ❌ 不管       低
sqrt-IRM     STFT 频谱      每个 bin    ❌ 不管       低
RNNoise      Bark 频带       22 个      ❌ 不管       极低 ★
cIRM         STFT 频谱      每个 bin    ✅ 可处理     中等
时域掩蔽     学习到的空间    自定        ✅ 隐式处理   高
```

> RNNoise 的独特之处：掩蔽粒度是 22 个 Bark 频带而不是 960 个频率 bin。这是它做到极低复杂度的关键。代价是粗粒度 → 需要 pitch filter 来补偿。

## 频谱映射 vs 掩蔽：一张表说清楚

|  | 频谱映射 | 掩蔽方法 |
|---|---------|---------|
| 网络输出 | 干净频谱的幅度（无界） | 0~1 之间的增益（有界） |
| 输出维度 | N 个频率 bin | N 个频率 bin（或更少） |
| 训练稳定性 | 较差（无界输出） | 好（sigmoid 天然匹配） |
| 误差敏感性 | 一个 bin 预测错 → 失真明显 | 一个 bin 预测错 → 局部增益不准 |
| 对未见噪声的泛化 | 较差 | 更好（掩蔽操作本身有物理约束） |
| 代表工作 | Xu 2015, Maas 2012 | RNNoise, Conv-TasNet, DPRNN |
