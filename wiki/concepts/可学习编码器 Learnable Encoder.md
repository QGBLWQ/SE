# 可学习编码器 (Learnable Encoder / 1-D Convolutional Encoder)

## 一句话记忆点

> 可学习编码器 = 让神经网络自己学习"如何把波形切碎并变成有用的特征"，而不是用固定的 STFT 正弦窗。STFT 的基函数是固定的正弦波，可学习编码器的基函数是**为分离任务优化出来的**。

## 定义

Conv-TasNet 的可学习编码器是一个**一维卷积层** (1-D Conv)，以原始波形为输入，输出一个特征序列：

$$ \mathbf{w} = \mathbf{x} * \mathbf{U} $$

等价于将波形切成长度为 $L$ 的小段，每段用 $N$ 个可学习基函数做线性变换：

$$ \mathbf{w} = \mathbf{xU} $$

| 符号 | 含义 | Conv-TasNet 设置 |
|------|------|:---:|
| $\mathbf{x} \in \mathbb{R}^{1 \times L}$ | 一段长度为 L 的波形片段 | L = 16 采样点 = **2ms** |
| $\mathbf{U} \in \mathbb{R}^{N \times L}$ | 可学习的编码基函数矩阵，模型参数 | N = 512 |
| $\mathbf{w} \in \mathbb{R}^{N}$ | 编码后的特征向量 | 512 维 |

## STFT 编码器 vs 可学习编码器

```
STFT 编码器 (固定):
                 πn      2πn      3πn
  基函数 = sin(──), sin(───), ..., cos(...)
                 N        N
  └── 永远是正弦/余弦，不管任务是啥

可学习编码器 (可训练):
  基函数 = U[0], U[1], ..., U[511] 
  └── 从随机初始化开始，通过反向传播逐步调整
       → 最终 512 个基函数 = 网络自己"发明"的最优编码
```

### STFT 的两重限制

1. **基函数固定**：正弦波是通用的，不是为"区分两个说话人"设计的。无论你做什么任务（语音分离、去噪、定位），STFT 给的编码方式一模一样
2. **相位和幅度拆开了**：STFT 把复数信号拆成 |X| 和 φ，但分离网络通常只看 |X|——相位信息被丢弃

### 可学习编码器做了什么

| | STFT 编码器 | 可学习编码器 |
|---|---|---|
| **基函数** | 固定正弦/余弦 | **可训练**的 $N$ 个滤波器 |
| **相位信息** | 解耦为幅度+相位 → 相位常被丢弃 | **隐式编码**在特征维度中 |
| **任务适配** | 任何任务都一样 | 针对**分离任务**优化 |
| **N=512 时的覆盖** | 256 个频率 bin | 可能有多个滤波器覆盖同一频率但不同相位 |
| **是否正交** | 正弦/余弦天然正交 | 不强制正交（但网络自己学出近似正交） |

## 它与一维卷积的关系

可学习编码器 = 一个**步长 = L/2=8 的一维卷积**：

```
输入波形: [s₀, s₁, s₂, s₃, s₄, s₅, s₆, s₇, s₈, s₉, ...]
            ↑ 编码器卷积核 k=16, stride=8  → 50% 重叠
               ↓
每段 16 个采样点，用 N=512 个卷积核做卷积
输出形状: [帧数 × 512]
```

这和 STFT 的 50% 重叠加窗做法完全一样——只是窗函数从正弦变成了**可学习的权重**。

## 它学出来的基函数长什么样？

Conv-TasNet 论文把训练好的 512 个基函数做 FFT 分析，发现了两个惊人的规律：

```python
# 伪代码示意
滤波器组 = trained_model.encoder.weight  # shape [512, 16]
for f in 滤波器组:
    freq = FFT(f)  # 看每个滤波器的频率响应

# 发现 1: >60% 的滤波器能量集中在 <1 kHz
# 发现 2: 多个滤波器调谐到同一频率，但相位不同
```

### 发现 1：低频偏置

```
滤波器分布示意（非准确统计）:
频率      0──1kHz──2kHz──3kHz──4kHz（8kHz 奈奎斯特）
滤波器数  ▓▓▓▓▓▓▓▓▓▓░░░░░░░░░░░░░░░
          ~330 个        ~180 个
```

网络自动学会了"语音信息集中在低频"的先验——和人耳的 mel 尺度、语音压缩编码的比特分配本质一致，但网络不是靠工程师设定，而是**靠自己从数据中学到的**。

### 发现 2：多相位编码——这才是关键

```
假设频率 f = 400 Hz:
  STFT:    只有 1 个正弦 bin + 1 个余弦 bin → 1 个幅度 + 1 个相位
  Conv-TasNet: 可能学出 5 个滤波器，都响应 400 Hz

滤波器 A:  ←→  相位 0°
滤波器 B:  ←→  相位 45°
滤波器 C:  ←→  相位 90°
滤波器 D:  ←→  相位 135°
滤波器 E:  ←→  相位 180°

合成信号在编码器的表示 w = [w_A, w_B, w_C, w_D, w_E]
  └── 这 5 个值隐含了完整的瞬时相位信息！
```

**这就是为什么 Conv-TasNet 能超越 oracle WFM**——STFT 中同一个频率只有 1 个幅度值，而可学习编码器把同一频率的**相位信息展开到了多个特征维度**中。mask 虽然是标量（只能缩放不能旋转），但作用于这 5 个维度时，可以"重新组合"出任意相位——隐式地解决了相位问题。

## 可学习编码器的"代价"

| 好处 | 代价 |
|------|------|
| 基函数针对任务优化 | 需要更多训练数据（STFT 零数据训练） |
| 隐式编码相位 | 失去了 STFT 的物理可解释性 |
| 可以很精细（512 维） | 参数量增加了（$512 \times 16 = 8192$，但很小） |
| 可配合超短帧（2ms） | LSTM 无法处理这么短的帧，但 TCN 可以 |
