# 扩张卷积 (Dilated Convolution / À trous Convolution)

## 一句话记忆点

> 扩张卷积 = 在卷积核的采样点之间"留空隙"，用**同样多的参数**覆盖**指数级更大的感受野**。三个参数：卷积核尺寸 $k$、扩张率 $d$、输入长度 $L$ → 感受野 = $(k-1) \times d + 1$。

## 定义

**扩张卷积** (dilated convolution, 又名 à trous convolution) 是一种在卷积核的采样点之间插入"空洞"(holes) 的卷积操作。它在不增加参数量的前提下，让每个输出单元"看到"更大的输入范围。

对于 1-D 信号 $x[n]$，扩张率为 $d$、卷积核大小为 $k$ 的扩张卷积：

$$y[n] = \sum_{i=0}^{k-1} w[i] \cdot x[n - i \cdot d]$$

- $d=1$：普通卷积（相邻采样）
- $d=2$：每隔一个采样（感受野翻倍）
- $d=4$：每隔三个采样（感受野 ×4）

## 直观图示

```
普通卷积 (dilation=1, k=3, 感受野=3):
输入:  ●  ●  ●  ●  ●  ●  ●
       └──┬──┘
       核 [w₀ w₁ w₂] 覆盖相邻 3 个

扩张卷积 (dilation=2, k=3, 感受野=5):
输入:  ●  ●  ●  ●  ●  ●  ●
       └─────┬─────┘
       核 [w₀ w₁ w₂] 每隔一个采样，覆盖 5 个

扩张卷积 (dilation=4, k=3, 感受野=9):
输入:  ●  ●  ●  ●  ●  ●  ●  ●  ●
       └───────────┬───────────┘
       核 [w₀ w₁ w₂] 每隔三个采样，覆盖 9 个
```

**关键点**：参数量始终是 $k$（3 个权重），但感受野从 3 → 5 → 9，成倍增长。

## 为什么语音处理需要扩张卷积

### 感受野需求

语音信号的时间跨度很大：

| 结构 | 时长 | 需要多大的感受野 |
|------|:---:|------|
| 音素 (phoneme) | ~50-100 ms | 几十帧 |
| 音节 | ~100-300 ms | 几百帧 |
| 单词 | ~300-1000 ms | 上千帧 |
| **句子 + 停顿** | **1-5 秒** | **数千至数万帧** |

在 Conv-TasNet 中，帧长 2ms → 要覆盖 2 秒的停顿，需要感受野 ≈ 1000 帧。用普通卷积需要堆 1000 层，而用扩张卷积：

$$d = 1, 2, 4, 8, \ldots, 2^{M-1}$$

只需 $M = \log_2(1000) \approx 10$ 层即可。

### vs RNN/LSTM

| | RNN (RNNoise) | 扩张卷积 TCN (Conv-TasNet) |
|---|---|---|
| **长程依赖** | 隐状态一步步传递，理论无限但实际有限 | 通过扩张率直接跳跃访问，固定但可很大 |
| **并行化** | ❌ 必须逐帧计算 | ✅ 所有时间步可并行卷积 |
| **梯度传播** | 容易消失/爆炸（BPTT 链长） | 更稳定的梯度流（每层直接从输入拉梯度） |
| **对起始点** | 敏感（错误累积） | 不敏感（每帧独立处理） |
| **感受野控制** | 间接（通过隐状态维度调节） | 直接（扩张率 × 层数 = 精确感受野） |

## 扩张卷积的堆叠策略（TCN 的根基）

单层扩张卷积的感受野有限。要覆盖秒级上下文，需要堆叠多层并以**指数级增长**扩张率：

```
第 1 层: d=1   → 感受野 3     (局部: 音素级别)
第 2 层: d=2   → 感受野 7     (合并两帧)
第 3 层: d=4   → 感受野 15    (半音节)
第 4 层: d=8   → 感受野 31    (音节)
第 5 层: d=16  → 感受野 63    (多个音节)
...
第 M 层: d=2^(M-1) → 感受野 O(2^M)
```

这种堆叠 + 指数扩张的设计，直接构成了 [[时序卷积网络 TCN]] 的核心。

## 深度可分离扩张卷积

Conv-TasNet 还在扩张卷积上叠加了**深度可分离卷积 (Depthwise Separable Convolution)** 来进一步压缩参数：

```
标准扩张卷积:
  输入 C 通道 → 扩张卷积核 K×C×C' → 输出 C' 通道
  参数量: K × C × C'

深度可分离扩张卷积:
  输入 C 通道 → Depthwise: 扩张卷积 K×1×C (每通道独立) → Pointwise: 1×1×C×C' → 输出 C' 通道
  参数量: K × C + C × C'  (≈ 原来的 1/C')

在 Conv-TasNet 中 (K=3, C≈512):
  标准: 3 × 512 × 512 ≈ 786K
  深度可分离: 3 × 512 + 512 × 512 ≈ 264K  → 省了 ~3×
```

## 感受野公式

对于 $R$ 组、每组 $M$ 个扩张卷积块（扩张率 $1, 2, 4, \ldots, 2^{M-1}$，核大小 $P$）：

$$\text{Receptive Field} = R \times \left[(P-1) \times \sum_{m=0}^{M-1} 2^m + 1\right] = R \times \left[(P-1) \times (2^M - 1) + 1\right]$$

Conv-TasNet 最佳配置：$R=3, M=8, P=3$ → 感受野 ≈ 3.8 秒。

## 局限

1. **固定感受野**：一旦训练好，感受野无法动态调整。如果输入比预期长，超出感受野的信息被完全忽略 → 这正是 [[DPRNN 2020]] 用双路径 RNN 解决的动机
2. **指数增长的"空洞"**：大扩张率意味着采样点非常稀疏 → 对高频细节的建模能力下降。在音频中这个问题不大（语音是低频占优），但在其他领域可能致命
3. **不是万能替代**：对于需要**真正无限记忆**的任务（如语言建模），Transformer 的自注意力或 RNN 更合适
