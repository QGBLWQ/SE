# 语音信号与噪声的数学模型

## 最基本的假设

语音增强领域的几乎所有工作，都从一个简单的加法模型出发：

$$x(t) = s(t) + n(t)$$

| 符号 | 含义 | 物理直觉 |
|------|------|----------|
| $x(t)$ | 麦克风录到的混合信号 | 你实际拿到的东西 |
| $s(t)$ | 干净的语音（目标） | 你想要的东西 |
| $n(t)$ | 噪声（干扰） | 你不想要的东西 |

> 这是**单通道**模型。如果有多麦克风，还会引入空间信息，这里不谈。

## 在时频域（频谱图）上

做完 STFT 后，加法变到复数域：

$$X(t, f) = S(t, f) + N(t, f)$$

关键洞察：**语音和噪声在时频域上的分布模式不同**。

```
想象频谱图是一个二维的热力图：

语音的特点：                     噪声的特点：
频率↑                           频率↑
│ ░░██░░░░░░██░░░  ← 谐波结构   │ ░▓▓░░▓░░▓░▓▓░░   ← 散乱
│ ░███░░░███████░  （平行的横线）  │ ░▓░░▓░▓░▓░░▓░▓   （无规律）
│ ████░██████████                 │ ▓░▓░░▓░░▓▓░▓░░
│ ██████████████                  │ ░░▓▓▓░░░▓▓░░▓▓
└──────────────→ 时间            └──────────────→ 时间
```

语音在频谱图上有**结构**：
- **谐波 (harmonics)**：基频的整数倍，呈平行横线排列
- **共振峰 (formants)**：声道共振，集中在特定频率区域
- **时间稀疏性**：能量集中在少数 T-F bin 上

噪声在频谱图上有不同模式：
- **稳态噪声**（如风扇、空调）：每个频率能量恒定 ≈ 白噪声/粉噪声
- **非稳态噪声**（如键盘声、狗叫、babble）：突然出现、短暂
- **结构化噪声**（如背景音乐、其他说话人）：有结构但和目标语音不同

## 噪声类型图谱

```
噪声类型                      传统DSP方法    DL方法
──────────────────────────────────────────────────
稳态 (风扇、空调嗡嗡声)        ✅ 好        ✅ 好
─────────────────────────────────────────────────
准稳态 (街道、车噪)            ⚠️ 可以      ✅ 好
─────────────────────────────────────────────────
非稳态 (键盘、关门、狗叫)      ❌ 差        ✅ 好       ← DL 的主要优势
─────────────────────────────────────────────────
结构化噪声 (babble、其他说话人) ❌ 很差      ⚠️ 依赖数据
─────────────────────────────────────────────────
```

这就是为什么深度学习能碾压传统信号处理：**它学到的是"语音长什么样"，而不是"噪声长什么样"**。前者泛化能力远超后者。

## 语音的特殊性：谐波结构

人类发声的本质：声带振动产生基频 $F_0$，然后由于声道（口腔鼻腔）的共振，产生 $F_0$ 的整数倍频率——这就是谐波。

```
幅度
 │ ┃              ← F₀ (基频, ~100-300Hz)
 │ ┃ ┃            ← 2F₀
 │ ┃ ┃ ┃          ← 3F₀
 │ ┃ ┃ ┃ ┃        ← 4F₀
 │ ┃ ┃ ┃ ┃ ┃ ┃ ┃ ...
 └──────────────────→ 频率
  ░░░░░░░░░░░░░░░░ = 谐波之间的"山谷"——噪声藏在这里！
```

RNNoise 的基音滤波器就精确利用了这个结构：**只擦除谐波之间的"山谷"里的噪声**，而不碰谐波本身的能量。

## 混响 (Reverberation) 的简化模型

实际场景中，声音还会被墙壁反射：

$$x(t) = s(t) + h(t) * s(t) + n(t)$$

其中 $h(t)$ 是房间冲激响应（RIR），$h(t) * s(t)$ 就是混响。

> RNNoise 没有显式建模混响——它的"增益平滑"只是用了一个简单技巧（让增益衰减慢一点）来避免声音听起来太干。
