# FTB 频时注意力块 (Frequency-Time Attention Block)

## 一句话记忆点

> FTB = 频率 attention + 时间 attention **分开做**（O(F+T) 而非 O(FT)²），然后把幅度流和相位流**互相给对方注入信息**——幅度告诉相位"语音在哪个 T-F bin"，相位告诉幅度"谐波结构在哪里"。

## 定义

FTB (Frequency-Time Attention Block) 是 PHASEN (2020) 提出的**跨模态注意力模块**，用于双流语音增强架构中幅度流和相位流之间的信息交换。它的三个设计原则：

1. **频率和时间分开做 attention**：降低复杂度（O(F+T) vs O(F×T)²）
2. **每个模态先自己理清**（频率 attention → 时间 attention），再**跨模态交流**（cross fusion）
3. **信息双向流动**：幅度 → 相位，相位 → 幅度

## 为什么需要 FTB

PHASEN 的双流架构中，幅度流和相位流各有各的编码器，如果不交互，相当于两个独立的增强网络各自输出结果。但幅度和相位之间存在天然的互补关系：

```
幅度流知道:                     相位流知道:
  "这个 T-F bin 能量高 →           "500Hz 附近相位连续 →
   大概率是语音"                   这里有谐波结构"
          ↓                              ↓
    应该告诉相位流:                  应该告诉幅度流:
    "认真恢复这个 bin 的相位"        "在这个频率给你多加一点增益"
```

FTB 就是实现这个"互相告诉"的机制。

## 架构详解

### 输入和输出

| 符号 | 含义 | 形状 |
|------|------|:---:|
| $M_i$ | 第 i 个 FTB 的输入幅度特征 | $[C, F, T]$ |
| $P_i$ | 第 i 个 FTB 的输入相位特征 | $[C, F, T]$ |
| $M_{i+1}$ | 更新后的幅度特征 | $[C, F, T]$ |
| $P_{i+1}$ | 更新后的相位特征 | $[C, F, T]$ |

其中 $C$ = 通道数, $F$ = 频率 bin 数, $T$ = 时间帧数。

### 完整数据流

```
输入: M_i [C,F,T]                    P_i [C,F,T]
       │                                  │
  ┌────▼──────────────┐          ┌────────▼─────────────┐
  │ Step 1: 频率注意力  │          │ Step 1: 频率注意力     │
  │                   │          │                      │
  │ 对每个时间帧 t:    │          │ 对每个时间帧 t:        │
  │ 沿 F 轴做 Conv1D   │          │ 沿 F 轴做 Conv1D      │
  │ → softmax → 加权   │          │ → softmax → 加权      │
  └────┬──────────────┘          └────────┬─────────────┘
       │ M_f_attn                       │ P_f_attn
  ┌────▼──────────────┐          ┌────────▼─────────────┐
  │ Step 2: 时间注意力  │          │ Step 2: 时间注意力     │
  │                   │          │                      │
  │ 对每个频率 bin f:  │          │ 对每个频率 bin f:      │
  │ 沿 T 轴做 Conv1D   │          │ 沿 T 轴做 Conv1D      │
  │ → softmax → 加权   │          │ → softmax → 加权      │
  └────┬──────────────┘          └────────┬─────────────┘
       │ M_ft_attn                      │ P_ft_attn
       └──────────┬─────────────────────┘
                  │
         ┌────────▼──────────────────────────┐
         │ Step 3: 跨流融合 (Cross Fusion)     │
         │                                    │
         │  M_{i+1} = M_i + f(P_i_processed) │  ← 相位告诉幅度
         │  P_{i+1} = P_i + g(M_i_processed) │  ← 幅度告诉相位
         │                                    │
         │  f(·), g(·) = 可学习变换 (1×1 Conv) │
         └────────┬──────────────────────────┘
                  │
       ┌──────────┴──────────┐
       ▼                     ▼
  M_{i+1} [C,F,T]      P_{i+1} [C,F,T]
```

### Step 1: 频率注意力

对每个时间帧 $t$，沿频率轴计算每个频带的重要性：

$$A_f(t) = \text{softmax}\left(\text{Conv1D}_F(M_i[:,:,t])\right)$$

$$M_{f\_attn} = M_i \odot A_f$$

**物理直觉**：语音的频谱包络是稀疏的——能量集中在共振峰和基频谐波上。一个 257-bin 的频谱中，真正"有用"的可能只有 20-30 个 bin。频率注意力让网络自动聚焦到这些 bin 上。

```
频谱:  ▁▂▃▅▆██▆▅▃▂▁▁▁▁▁▁...
频率注意力权重:  ▁▁▁▅█▆▂▁▁▁▁▁▁▁▁...
                  ↑ 聚焦在共振峰区域
```

### Step 2: 时间注意力

对每个频率 bin $f$，沿时间轴计算每个时刻的重要性：

$$A_t(f) = \text{softmax}\left(\text{Conv1D}_T(M_{f\_attn}[f,:,:])\right)$$

$$M_{ft\_attn} = M_{f\_attn} \odot A_t$$

**物理直觉**：语音在时间上是稀疏的——300ms 的语音后面可能有 500ms 的停顿。时间注意力让网络的感受野自动聚焦在有声音的区域。

```
时间轴:  ▓▓▓▓░░░░░▓▓░░░░░░▓▓▓▓...
         语音  停顿  语音 停顿   语音
时间注意力权重:  ████▁▁▁▁▁██▁▁▁▁▁████...
                  ↑ 聚焦在有语音的时刻
```

### Step 3: 跨流融合

这是 FTB 的灵魂。前两步在每个流**内部**做，第三步在两个流**之间**交换信息：

$$M_{i+1} = M_i + f(P_i^{\text{processed}})$$

$$P_{i+1} = P_i + g(M_i^{\text{processed}})$$

其中 $f(\cdot)$ 和 $g(\cdot)$ 是轻量可学习变换（通常 1×1 卷积，做通道对齐）。

**信息的流向：**

```
幅度 → 相位（f(·) 路径）:
  "这个 bin 的幅度很高 → 肯定是语音 → 认真恢复相位"
  "这个 bin 的幅度很低 → 纯噪声 → 相位随便填"
  → 相位流避免在噪声区域浪费算力

相位 → 幅度（g(·) 路径）:
  "这些频率 bin 的相位很连续 → 有谐波 → 增强力度加码"
  "这些频率 bin 的相位是随机的 → 清音或噪声 → 别过度增强"
  → 幅度流在谐波位置做精细增益
```

## 复杂度：为什么 "F-T 分离" 是精髓

| 方案 | 复杂度 | F=256, T=256 时 |
|------|:------:|:---:|
| 不做 attention（盲 concat） | O(C²FT) | ~1M |
| F×T 联合 self-attention | **O((FT)²)** | **~4B** ❌ 爆炸 |
| FTB: F-attn + T-attn 分离 | **O(F+T)** | ~512 ✅ |

FTB 的核心设计智慧：**频率维度和时间维度的 attention 不需要耦合**。

- 频率 attention 关心的是"这个时刻哪个频带有语音"——跨频率，不跨时间
- 时间 attention 关心的是"这个频带哪个时刻有语音"——跨时间，不跨频率
- 两者各自做线性复杂度的 attention，合起来仍然线性

这和后来视频理解领域的 TimeSformer (2021) 以及 SELD 领域的 DST Attention (2023) 共享同一设计哲学——**维度分解注意力**。

## 多个 FTB 的堆叠

PHASEN 堆叠了 $L$ 个 FTB（论文中 L=4-8），每个 FTB 的幅度和相位特征逐渐变得更精确：

```
初始特征 (编码器输出):
  M₀ ← 编码器看到的原始幅度谱
  P₀ ← 编码器看到的原始相位谱

经过 FTB₁:
  M₁ ← M₀ + 相位流告诉幅度流"语音在高频也有能量"
  P₁ ← P₀ + 幅度流告诉相位流"低频需要精细恢复"

经过 FTB₂:
  M₂ ← M₁ + "不只高频，500Hz 附近也有关键的谐波"
  P₂ ← P₁ + "不只低频，2kHz 共振峰的相位也要保留"

... 逐步精细化 ...

经过 FTB_L:
  M_L, P_L → 解码器 → 增强的幅度谱 + 相位谱
```

## 和其他跨模态注意力机制的对比

| 方法 | 跨什么模态 | 注意力轴 | 复杂度 | 代表 |
|------|-----------|---------|:---:|------|
| **FTB (PHASEN 2020)** | 幅度 ↔ 相位 | F, T 分离 + cross fusion | O(F+T) | PHASEN |
| Cross-Attention (CRAFT 2022) | 编码器 ↔ 解码器特征 | T↔F 交替 cross-attention | O(T²) | CRAFT |
| T-F MHSA (MP-SENet 2023) | 同模态（自注意力） | T, F 交替自注意力 | O(T²+F²) | MP-SENet |
| S+T Divided MHSA (DST 2023) | 同模态（自注意力） | S, T 分离 | O(F'+T) | DST Attention (SELD) |
| C+S+T MHSA (CST 2025) | 同模态（自注意力） | C, S, T 三维独立 | O(C²+F²+T²) | CST-former (SELD) |
