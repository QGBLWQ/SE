# 全带与子带模型 (Full-Band & Sub-Band)

## 一句话记忆点

> 全带 = 看整条频谱的"形状"（全局结构：哪个频段有语音），子带 = 看局部邻域的"纹理"（局部细节：这个 bin 是谐波的峰还是谷）。级联使用：全带先看清"哪片森林"，告诉子带"去哪砍树"。

## 定义

全带和子带是语音增强中一对互补的频率建模策略，由 FullSubNet (2021) 首次系统性地融合：

| | 全带模型 (Full-Band) | 子带模型 (Sub-Band) |
|---|---|---|
| **输入** | 完整幅度谱 [F×T]（如 F=257） | 单个频率 f 左右 K 个邻域 [2K+1, T]（如 K=15） |
| **频率分辨率** | 低（池化后 F'=33） | 高（逐 bin 处理） |
| **看到什么** | 全局频谱包络：共振峰位置、噪声类型 | 局部频谱纹理：谐波峰/谷、邻频连续性 |
| **知道什么** | "语音在 300-3400 Hz，高频是白噪声" | "第 47 个 bin 是谐波峰，该保留" |
| **不知道什么** | "第 47 个 bin 是该留还是该砍" | "第 47 个 bin 在哪个共振峰里" |
| **参数量** | 低（一次前向处理所有频率） | 高（每个频率独立调用 LSTM，参数共享后约 4M） |
| **与 DPCRN 类比** | ≈ 块间（看全局） | ≈ 块内（看局部） |

## 为什么需要分开？

如果只用一个模型同时处理全局频谱结构和局部谐波细节，会遇到分辨率矛盾：

```
要看清全局频谱结构 → 需要频率维降采样（池化）
  → F=257 降到 F'=33 → 每个 bin 覆盖 ~8 个原始频率 bin
  → 第 47 个 bin 的谐波细节被"平均"掉了

要保留局部谐波细节 → 需要保持频率分辨率
  → 但保持 F=257 → 参数量和计算量爆炸
  → 且单模型难以同时学习"整条频谱长什么样"和"每个 bin 该不该留"
```

**分开 = 分工**。这和 DPCRN 的"块内+块间"在时间维上的分工，是同一个洞察的两个正交实现。

## 全带模型 (Full-Band Model)

### 做什么

输入完整的幅度谱 `[F=257, T]`，通过**两个阶段**处理：

**阶段 1 — Conv2D 频率降采样（时间维 T 保持不动）**

```
[F=257, T] ──Conv2D(s=2)──→ [129, T, 16]
                           ──Conv2D(s=2)──→ [65, T, 32]
                           ──Conv2D(s=2)──→ [33, T, 64]
                           ──Conv2D(s=1)──→ [33, T, 64]
    ↑                          ↑
  每一帧都是完整的频谱          降采样只压频率 F，不压时间 T
```

Conv2D 的 stride=2 只在**频率方向**生效。经过 3 次降采样后 F 从 257 压缩到 33（≈8×），但 T 帧数原封不动。通道数 C 从 1 逐步扩充到 64。

**阶段 2 — 逐帧 fc 升维 + 因果 LSTM（沿 T 轴串行）**

```
                    ┌── fc(64→256) 作用于每个频率位置 ──┐
                    │    [33, 64] → [33, 256]           │
                    │    同一组 fc 权重在 33 个频带间共享  │
                    └───────────────────────────────────┘

t=1: [33,64] → fc → [33,256] ──┐
t=2: [33,64] → fc → [33,256] ──┤
t=3: [33,64] → fc → [33,256] ──┤  uni-LSTM(256)，因果，不偷看未来
  ...                           ├── 每个时间步输出 h_t [33, 256]
t=T: [33,64] → fc → [33,256] ──┘
                                 ↑
                             隐藏状态 h_{t-1} 沿时间轴传递
                             第 t 帧的 LSTM 输出 = f(当前帧特征, 前 t-1 帧的记忆)
```

**为什么需要 LSTM 而非 FC？**
- fc 升维后已经是 `[33, 256]`，如果只看"维度变化"确实不需要 LSTM
- 但 LSTM 做的事情不是升维，而是**记住时间线上的变化**：同样的频谱形状在语音开始时 vs 语音中间 vs 语音结束，物理含义完全不同。FC 看一帧无法区分，LSTM 的隐藏状态携带了前文信息
- 全带模型要输出"全局语境"——而**时间连续性本身就是语境**："前面 20 帧都很安静，这一帧突然在 300-3400 Hz 有能量 → 语音开始了"

**阶段 3 — 频率维插值回原始分辨率**

```
                      每个原始频率 f 的插值位置
                          ↓    ↓    ↓
h_full [33, T, 256]  ·   ·   ·   ·   ·
                      ·   ·   ·   ·   ·    ← 33 个降采样频率点
                        ·   ·   ·   ·   ·   ← 线性插值到 257 个点
                      插值后: h_global [257, T, 256]
```

```
h_global[f, t, :] = [0.8, -0.3, 0.1, ..., 0.5]  ← 256 维
                                                    ↑
                      第 t 帧、频率 f 的全局语境向量——
                      编码了"频率 f 在整条频谱的 t 时刻处于什么位置"：
                      "你在高频区+当前是语音段 → 这里是摩擦音和噪声边界"
```

> LSTM 的存在使得这个语境向量**不只是"在哪个频段"**，还包含了**"现在是什么时刻/阶段"**——语音刚开始时全带特征可能偏保守，语音中间则更确定。

### 直觉

全带模型像一位**指挥官**——站在高处看整个战场（频谱），知道"左翼是语音、右翼是噪声、中间是共振峰区域"。但他看不到每个士兵（频率 bin）的具体处境。

## 子带模型 (Sub-Band Model)

### 做什么

对**每一个**频率 bin $f$（$f=0,1,...,256$），在**所有 T 帧上**做三步处理。257 个频率位置共享同一组子带 LSTM 权重，但逐个串行调用。

**Step 1 — 取局部邻域（同一频率窗口，覆盖所有时间帧）**

```
从幅度谱 [F=257, T] 中，固定取第 f-K 到 f+K 行：

       t=1  t=2  t=3  ...  t=T
f=32:  ·    ·    ·         ·    ─┐
 ...                              ├── 共 31 行 (K=15)
f=47:  ·    ·    ·         ·      │   目标频率 f
 ...                              │
f=62:  ·    ·    ·         ·    ─┘

→ X_f [T, 31]

第 t 帧的局部特征: X_f[t, :] = [幅值_f-K(t), ..., 幅值_f+K(t)]
                    ↑ 31 维 —— "t 时刻，频率 f 周围 969 Hz 内的频谱纹理"
```

> 频率窗口 [f-K, f+K] 在所有 T 帧上是**同一组频率 bin**——不随时间变化。对每一帧来说，取的是"这个时刻这些频率的值"。

**Step 2 — 注入全带特征（帧对齐拼接）**

```
                第 t 帧

  局部特征        全带语境
  X_f[t, :]      h_global[f, t, :]
   [31]              [256]
     │                 │
     └────────┬────────┘
              ⊕  concat
              │
         input[t] [287]

含义拆解:
  X_f[t, :]     → "t 时刻，我周围的 31 个 bin 具体是多少 dB"
  h_global[f,t,:] → "t 时刻，全带 LSTM 说: 你在 F2 共振峰区、语音段进行中"
                   ↑ 这 256 维已经携带了全带 LSTM 沿时间轴积累的历史记忆
```

> 局部特征和全局特征在**同一时间帧 t** 上对齐。h_global 不是静态标签——它每一帧都在变，因为全带 LSTM 的隐藏状态在随时间更新。

**Step 3 — 子带 LSTM 逐帧决策**

```
t=1: [287] → fc → [128] ──┐
t=2: [287] → fc → [128] ──┤
t=3: [287] → fc → [128] ──┤  uni-LSTM(128), 因果
  ...                      ├── 隐藏状态跨帧传递
t=T: [287] → fc → [128] ──┘
                              ↓ 每帧输出 → fc(128→1) → sigmoid
                           ĝ_f [T]
                    频率 f 在所有 T 帧上的增益序列
                    ĝ_f[t] ∈ [0,1]: 该留 (≈1) 还是该砍 (≈0)
```

**两重时序的叠加**：子带 LSTM 看到的输入已经包含全带 LSTM 的时序记忆（h_global），再加上自己的隐藏状态——相当于**"全带在时间维上粗加工过的信息，子带再精细加工一遍"**。

### 直觉

子带模型像一个个**士兵**——只看到周围几米（31 个 bin ≈ 0.97 kHz），但视角极其精细。他能判断"这个 bin 是谐波峰还是噪声谷"，但不知道自己在战场的哪个位置。指挥官通过 h_global 告诉他："t 时刻你在 F3 共振峰区、语音段刚开始"——他就知道该认真对待还是随便应付。

全带 LSTM 的隐藏状态回答了 **"现在是什么时刻"**，子带 LSTM 在此基础上回答 **"这个 bin 在这一刻该不该留"**。

## 级联 vs 并行

FullSubNet 做了这个消融：把全带特征"注入子带输入"改成"两个分支各自独立预测增益、最后融合"。结果：**级联 > 并行**。

### 两种方案的具体结构

```
═══════════════════════════════════════════════════════════════
级联 (Cascade) — FullSubNet 实际方案
═══════════════════════════════════════════════════════════════

  幅度谱 [257, T]
       │
  ┌────▼──────────────────────┐
  │  全带分支                    │
  │  Conv2D → LSTM(256)        │
  │  输出: h_global [257,T,256] │  ← 全局语境，含时序记忆
  └────────────────┬───────────┘
                   │ 注入
                   ▼
  ┌────────────────────────────┐
  │  子带分支 (对每个 f)         │
  │  输入: [局部31 ⊕ 全局256]    │  ← 子带 LSTM 每一步都看到全局
  │  fc → LSTM(128) → fc → σ   │     可以"根据语境调整判断"
  └────────────────┬───────────┘
                   ▼
              ĝ [257, T]       ← 每个 bin 的输出都是"有语境"的决策


═══════════════════════════════════════════════════════════════
并行 (Parallel) — 消融对照组
═══════════════════════════════════════════════════════════════

  幅度谱 [257, T]
       │
  ┌────▼──────────────────────┐    ┌─────────────────────┐
  │  全带分支                    │    │  子带分支 (对每个 f)    │
  │  Conv2D → LSTM → fc → σ   │    │  输入: [局部31]  ONLY  │
  │  输出: ĝ_full [257, T]     │    │  fc → LSTM → fc → σ  │
  └────────────────┬───────────┘    │  输出: ĝ_sub [257, T] │
                   │                └──────────┬──────────┘
                   │     融合 (如逐元素平均)     │
                   └──────────┬─────────────────┘
                              ▼
                         ĝ [257, T]       ← 两个"瞎子"的意见被平均
```

### 为什么级联更好？

核心差别在于**决策链路中有没有全局信息**：

| | 级联 | 并行 |
|---|---|---|
| 子带 LSTM 看到全局吗？ | ✅ 每一步输入里都有 | ❌ 自始至终看不到 |
| 子带如何做决定？ | "我在 F2 区+语音段 → 这个谐波该保留" | "31 个邻居的频谱纹理长这样 → 猜一下" |
| 全局信息作用时机 | **决策中**（参与推理） | **决策后**（只参与投票） |

一个具体场景说明差异：

```
频率 f=47 处，某一帧的局部频谱看起来像"弱谐波叠加在噪声上"

级联: h_global 告诉子带 LSTM "你在 F2 共振峰区、语音刚开始"
      → LSTM 判断: "语音初期共振峰弱是正常的 → 保留"
      → ✅ 正确

并行: 子带 LSTM 只看到 31 个邻居 → "像是噪声，但也可能是语音"
      → 给出一个模棱两可的 0.55 (犹豫)
      → 全带分支独立给出 0.7 (从全局看觉得该留)
      → 融合 = (0.55+0.7)/2 = 0.625 → ❌ 偏保守，语音被部分误削
```

**本质**：级联让全局信息成为子带 LSTM **推理过程的一部分**——子带 LSTM 可以学会"在共振峰区大胆保留，在高频噪声区激进削除"。并行只能让两个盲人投票——谁也无法纠正对方的误判。

> 这也解释了为什么全带特征是 concat 而不是 attention 注入——concat 让 LSTM 自己学"怎么用这个语境"，而不是预设一个固定的融合公式。

## 和"时间维双路径"的对比

| | 频率分治 (FullSubNet) | 时间分治 (DPRNN/DPCRN) |
|---|---|---|
| **分解轴** | 频率 (F) | 时间 (T) |
| **全局分支** | 全带模型（降采样后的完整频谱） | 块间 RNN（跨分块序列） |
| **局部分支** | 子带模型（频率 f 的局部邻域） | 块内 RNN（单个分块内部） |
| **信息流向** | 全带 → 子带（单向级联） | 块内 ↔ 块间（双向迭代） |
| **复杂度** | O(F × 子带LSTM) | O(TK + K²) |
| **代表** | FullSubNet (2021) | DPRNN (2020), DPCRN (2021) |

**两者的叠加是空白领域**——全带+子带（频率维分解）× 块内+块间（时间维分解）= 四路协同建模。

## 子带窗口大小 K 的选择

| K | 覆盖范围 (@16kHz, Δf=31.25Hz) | 效果 |
|:---:|------|------|
| 5 | 11 bin ≈ 344 Hz | 太窄——看不到完整谐波结构（基频 150Hz 的话只看到 2 个谐波） |
| 15 | 31 bin ≈ 969 Hz | ✅ 甜点——覆盖 6-7 个基频周期的谐波，足以识别局部谐波模式 |
| 30 | 61 bin ≈ 1.9 kHz | 计算量翻倍，收益递减——更宽的视野已经进入全带模型的管辖范围 |
